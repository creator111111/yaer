## 沟通摘要

### ① 结论一句话

**进 BOSS 图、读档进村屋/西境、进出树桥揭幕时，镜头应贴在人身上，不再闪一下再滑；林恩门口运镜不动。**

### ② 原因（通俗）

- **BOSS 图 / 读档**：和龙宫下楼一样——人已在落点，镜头还在慢慢追，黑幕（读档甚至没有 hold）揭开就看见闪滑。  
- **树桥**：同场景切边界/尺寸后立刻揭幕，只压了 Y，X 还在追，和进场 `smoothTime` 无关。

### ③ 用户检查清单

| # | 操作 | 通过判据 |
|---|------|----------|
| 1 | 东郊→WestRappRoad；西境→东郊 | 揭幕无平移/闪屏 |
| 2 | Hierarchy：`WestRappRoad` / 村屋 / Chief / OutSide / night / Shop → Camera | `smoothTime = 0` |
| 3 | `ForestScene` → Camera | **仍为 0.3**（林恩运镜） |
| 4 | 东郊进/出树桥（左右口） | 揭幕无乱滑；洞内贴底；爬行晃动可保留 |
| 5 | 西境 / 走廊 / 村里 / 树桥洞内各存一档再读 | 揭幕机位贴玩家 |
| 6 | 东郊↔走廊；龙宫 Stairs；出店回村 | 仍定格 |
| 7 | Forest 林恩门口 | 可见运镜未被误伤 |

## 为什么这样改

- 逐场景 `smoothTime=0` 与 Stairs/出店先例一致，盖 blackFade 与读档进场。  
- A2 仅限 `archiveStart`，盖漏网 0.3 / 未序列化默认，且读档本身无 hold。  
- 树桥不靠再改东郊字段；揭幕前全轴贴齐 + 去掉出洞拽 (0,0)。
