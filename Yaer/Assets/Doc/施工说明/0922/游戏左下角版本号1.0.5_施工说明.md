## 沟通摘要

### ① 结论一句话

**主菜单与局内左下角常驻显示 `1.0.5`（读 `Application.version`），换场/读档不会丢、不会叠多份。**

### ② 原因（通俗）

工程原先没有版本角标，Player Settings 还是 `0.1`。新建 System 组轻量窗贴左下；清屏时把版本窗过滤并 Ensure 重开，避免跟黑幕一起被关掉。

### ③ 用户检查清单

| # | 步骤 | 期望 |
|---|------|------|
| 1 | Play → 主菜单 | 左下 **`1.0.5`**（一份） |
| 2 | 进村 / 村长家 / 换场 | 仍可见，不叠多个 |
| 3 | 菜单、对话、地图点击 | 不被挡住 |
| 4 | Player Settings | bundleVersion = **1.0.5** |
| 5 | 战斗 / 黑幕 | 黑幕盖住可接受；揭幕后仍在 |

### ④ 程序补充

见下文。

## 改动清单

| 路径 | 改动 |
|------|------|
| `ProjectSettings.asset` | `bundleVersion` 0.1 → **1.0.5** |
| `VersionFormLogic.cs` + `VersionPanel.prefab` | 新建；TMP=`Application.version`；Raycast 关；锚左下 +16px |
| `UIPrefabPath.cs` | 常量 `VersionPanel` |

## 为什么这样改

只挂主菜单会进局消失；塞战斗 HUD 会随 HUD 关。System Form + CloseAll 过滤是现网最小抗清屏。
