## 沟通摘要

### ① 结论一句话

**这次不改卵和虫子：把洞内再降脚取消，并把洞顶 `GroundUp` 略下移，避免身体楔进顶板。**

### ② 原因（通俗）

上一版已经关了碎壳、把小虫放到身后，你还是过不去，是因为人被洞顶那块实心板卡住了——身体插进顶板，方向键怎么按都像坏了。所以本票只动脚高偏移和顶板位置。

### ③ 用户检查清单

| # | 操作 | 通过判据 |
|---|------|----------|
| 1 | 等编译；若场景开着，确认 `GroundUp` Y≈**−7.85**（勿被编辑器盖回 −7.35） | |
| 2 | Console | 碎卵必有 `[WormEggBreak]`；进洞有 `[TreeBridgePlayerY]` 且 before≈after（offset=0） |
| 3 | 新档左口 → 碎第一卵 → **不按 E** | **能越过碎壳** |
| 4 | 第二卵 | 仍挡路、可砸 |
| 5 | 出洞 | 脚高与进洞前一致 |
| 6 | 若仍卡 | Pause 看 `GroundUp` 是否仍与 Body 相交；前方平台虫是否 Stay 刹（R3）→ 再开票，禁止再猜叠补丁 |

## 剩余风险

- 本机未 Play；须你本地越过第一碎壳才算过。  
- 若 Console 无 `[WormEggBreak]` → 先编译进包（R4），不是再改顶板。  
- 下移 `GroundUp` 可能影响洞内怪物分层手感，发现穿帮记 OPEN。
