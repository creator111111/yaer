# 对话结束停干净语音 — 施工说明

**文档版本**：v1.0（2026-09-11）  
**文档性质**：【施工员】按侦探报告方案 **A** 最小落地  
**Unity**：2020.3.48f1  
**侦探报告**：`Assets/Doc/执行文档/0911/对话结束重复最后一句语音_架构溯源报告.md`  
**根因**：H1 — VO 打在对话框 `localSource`（默认 `playOnAwake=true`）；结束只 `Stop()` 不清 `clip`；关壳再开 → Unity 自动复播最后一句

---

## 沟通摘要

### ① 结论一句话

**对白结束（及开场防御）统一 Stop + 清 clip + 关 playOnAwake；再点 NPC/开新戏不应复读旧最后一句。**

### ② 原因（通俗）

人声挂在对话框喇叭上，戏散了只按暂停、磁带没抽出来，喇叭还开着「一亮就自动播」。  
再开对话框壳 → 最后那句又响一遍。不是文件坏了，是没收拾干净。

### ③ 用户检查清单

| # | 操作 | 通过判据 |
|---|------|----------|
| 1 | 收尾句 **有** Audio 的对白，正常点完 | Hierarchy：`DialogueTMPUGUI` 上 AudioSource `clip=None`，`Play On Awake` 关 |
| 2 | 立刻点 NPC / 物体 / 新演出 / 转场后再开对白 | **不**复读上一段最后一句 |
| 3 | 新对白首句有 VO | 首句正确，不是旧句 |
| 4 | 收尾句 **无** VO 对照 | 仍不该冒出人声 |
| 5 | BGM | 不被误停 |

## 改动清单

| 项 | 路径 | 说明 |
|----|------|------|
| **A1** | `DialogueTMPUGUI.cs` | `localSource` 创建时 `playOnAwake=false` |
| **A2** | 同上 | `StopDialogueVoiceClean()`：本场登记源 + playSource + localSource → Stop / clip=null / playOnAwake=false |
| **A3** | 同上 | `OnDialogueFinished` / `OnDialoguePaused` 调清理 |
| **A4** | 同上 | 播 VO 时 `RegisterVoiceSource`；播前关 playOnAwake |
| **A5** | `NormalDialogueFormNewLogic.cs` | `StartDialogue` 开头防御清理；`OnDialogueEnd` 关壳前再兜一层 |

### 未改（禁止项）

- 各 NPC / 门 / 交互入口打 Stop 补丁  
- 全局 `FindObjectsOfType<AudioSource>`  
- 重导音频 / 改台本  
- SoundComponentGM BGM 通道（VO 不走该路）  
- StoryComponentGSM 大改（VO 停在 UI 层即可；End 已兜）

---

## 清理时序

```
树结束 → OnDialogueFinished → StopDialogueVoiceClean（真源）
  → 字幕淡出 → OnDialogueEnd → 再兜清理 → OnStoryEnd → CloseForm
再开戏 → StartDialogue 开头防御清理 → 新树 StartDialogue
```

---

## 剩余风险

| 风险 | 说明 |
|------|------|
| 强制切场绕过 Finished | 靠下次 StartDialogue / 异常路径；若纯转场无再开壳仍复读，再查其它源 |
| UniTask.Forget 未取消 | 二期可加取消令牌；本期清 clip 后误 Play 也无磁带 |
| PlayOneShot 键音 | 与 localSource 共用；结束清 clip 不影响 OneShot |
