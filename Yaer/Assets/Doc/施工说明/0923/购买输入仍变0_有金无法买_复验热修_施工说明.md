## 沟通摘要

### ① 结论一句话

**不是读不到 800 金，是生命球堆叠已满（10/10）导致可买上限为 0；腾出空位后应能输入 1～4。**

### ② 原因（通俗）

钱够买 4 个，但背包里同种道具已经装满，商店不允许再买进，所以敲什么都变成 0。这是堆叠规则，不是输入框坏了。

### ③ 用户检查清单

| # | 步骤 | 期望 |
|---|------|------|
| 0 | **验收前置**：先把 HpBall 用掉/调试减到 held≤6 | 否则满堆叠变 0 属预期，勿判 UI 坏 |
| 1 | 菜单 ~800；Console `[MenuMoney] gold=800` | 与 `[ShopBuyMax] gold=800` 一致 |
| 2 | held≤6、空位≥4，输入 1～4 | DigitStrip 稳定该数；日志 `max≥1` |
| 3 | 输入 5（钱够 4 时） | 钳到 4 |
| 4 | held=10 再输 | 仍变 0；`stackRoom=0 max=0` + `[ShopDebug] 堆叠已满无法再买` |
| 5 | 有空位点决定 | 扣款入包成功 |
| 6 | 贩卖 | 不回归 |
