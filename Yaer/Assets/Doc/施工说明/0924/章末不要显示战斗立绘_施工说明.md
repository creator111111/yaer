**文档性质**：【施工员】  
**Unity**：2020.3.48f1  
**报告**：`Assets/Doc/执行文档/0924/章末不要显示战斗立绘_架构溯源报告.md`

## 沟通摘要

### ① 结论一句话

**章末大标题→地图→字幕全程不再露出铠甲战斗立绘；设置「显示战斗立绘」开着也不露。**

### ② 原因（通俗）

章末故事一结束，系统会按设置约 0.4 秒后再把战斗立绘打开；章末面板开在上层，底层立绘会从淡入/黑幕缝里透出来。现改成章末打开就关立绘，并在章末期间拦住这次恢复。

### ③ 用户检查清单

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 设置「显示战斗立绘」=开，跑 `ChapterEndStory_0` | 大标题→地图→字幕**全程无**铠甲立绘 |
| 2 | ESC 跳过大标题 / 字幕 / outro | 同样不露 |
| 3 | 普通林战 / 战斗中 | 立绘仍可按设置显示 |
| 4 | 国王演出→紧接教学对话 | 延迟仍在，**不闪**立绘 |

Console 可过滤 `[ChapterEnd]` 核对 Suppress / 拦截 / Restore。

### ④ 程序补充

| 路径 | 改动 |
|------|------|
| `ChapterEndFormLogic.cs` | 静态拦截旗；OnOpen `CancelPending`+强制关；OnClose 按设置+`homeDoorStoryComplete` 恢复 |
| `FightingFormLogic.cs` | `CancelPending` 公开；延迟协程 / Apply / OnStoryEnd 排程前查章末旗；**保留** `_storyEndBattleImageDelay` |
| `StoryComponentGSM.cs` | OnStoryEnd 恢复前双保险：章末开则强制关 |

**禁做**：delay 改 0；设置默认关 `showBattleImage`；章末 Close 整个 FightingPanel。
