## 沟通摘要

### ① 结论一句话

**左下 `1.0.5` 只在主菜单出现；进局、ESC 菜单、地图、对话、章末都没有；回主菜单再出现。**

### ② 原因（通俗）

以前清屏时故意留着版本号又补开一份，所以进游戏还在。现改成清屏时一起关掉，只有进主菜单才再打开。

### ③ 用户检查清单

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 主菜单 | 左下纯 `1.0.5`，一份 |
| 2 | 开始游戏 / 读档进村或林 | **无**版本号 |
| 3 | ESC 菜单、地图、对话、章末 | **无** |
| 4 | 返回主菜单 | 版本号**再出现** |
| 5 | 局内换场 | **不会**再冒出版本号 |

### ④ 程序补充

| 路径 | 改动 |
|------|------|
| `UIComponentGM.CloseAllUIForm` | 去掉 Version 跳过与末尾 `EnsureVersionForm` |
| `UIComponentGM.EnsureVersionForm` | 保留；仅主菜单用 |
| `ProcedureComponentGM.OpenMainMenu` | 保留 Ensure；注释改为 0924 |
| `VersionFormLogic` / `UIPrefabPath` | 注释改为「仅主界面」 |

**未改**：`bundleVersion` / Prefab / 显示字符串（仍 `Application.version`）。
