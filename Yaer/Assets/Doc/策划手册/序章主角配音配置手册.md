# 序章 · 主角（雅尔）配音配置手册

**读者**：策划 / 配音统筹  
**版本**：2026-07-05  
**Unity**：2020.3.48f1  

---

## 这份手册是干什么的

教你在 **不改动程序** 的前提下，给 **序章里雅尔（主角）说的每一句对白** 配上语音，并在游戏里试播听效果。

**一句话**：每句对白在对话图里有一个 **「Audio File」** 槽；把录好的 `.wav` / `.ogg` 拖进去即可。

---

## 序章里，雅尔的配音出现在哪里

序章相关、**雅尔会开口** 的主要对话资源如下（按玩家游玩顺序）：

| 顺序 | 内容 | 对话 Prefab（工程内路径） | 说明 |
|------|------|---------------------------|------|
| 1 | 新游戏开场 · 父女对话 | `Assets/GameRes/Prefabs/Dialogue/NewGameStory.prefab` | 漫画结束后自动播放；Actor **「雅尔」** |
| 2 | 进村 · 与古莎同行 | `Assets/GameRes/Prefabs/Dialogue/Village_KenMuNiStart.prefab` | 肯姆尼进村；Actor **「雅尔」** |
| （可选） | 村内长开场台本 | 由 CSV 导入后合并进 Prefab | 源稿：`Assets/Dialog/Village_村内雅古开场对白台本.csv` |

**CSV 里怎么认雅尔**：`Speaker` 列写 **`雅`**（简称），导入后会映射成图里的 **`雅尔`**。  
只给 **Speaker = 雅** 的行配主角音；古莎、旁白、国王等另配。

台本全文可参考：

- `Assets/Doc/技术文档/精灵村Village_KenMuNi_对话台本.md`
- `Assets/Doc/执行文档/0601/Village_村内雅古开场对白台本_执行说明.md`

## 游戏里配音是怎么播的（了解即可）

1. 某句对白节点上绑了 **Audio File** → 出字时 **直接播这段语音**，播完（或玩家按键）才跳下一句。  
2. **没绑 Audio File** → 只有 **打字机效果 + 按键声**，没有人声。  
3. 语音从对话 UI 上的 **AudioSource** 播放；**旁白（Speaker = —）不要绑配音**，否则可能报错。

## 配置流程总览

```
① 录好 / 收到音频
      ↓
② 按命名规则放进 Unity 工程文件夹
      ↓
③ 打开对应对话 Prefab → 编辑对话图 → 每句「雅尔」SayEx 节点拖 Audio File
      ↓
④ DialogDebug 场景试播 → 实机新游戏 / 进村验收
```

---

## 第一步：准备音频文件

| 项 | 建议 |
|----|------|
| **格式** | **`.wav`**（优先）或 **`.ogg`**；Unity 也支持 `.mp3` |
| **内容** | 与该行 **中文 `Text` 完全一致** 的朗读（英/日版另录或暂不配） |
| **长度** | 一句一条，不要多条台词拼在一个文件里 |
| **采样** | 常见 44100Hz / 16bit 单声道即可 |

---

## 第二步：把音频放进 Unity 工程

### 推荐目录（请整组策划统一）

```
Assets/ArtRes/Audio/Voice/Yaer/Prologue/
```

可按场次分子文件夹，例如：

```
Prologue/
├── NewGameStory/          ← 新游戏开场（雅尔+王）
│   ├── NG_Yaer_001.wav
│   └── …
└── KenMuNiStart/          ← 进村与古莎
    ├── KM_Yaer_001.wav
    └── …
```

**操作**：

1. 在资源管理器里把音频 **复制** 到上述文件夹（文件夹不存在就新建）。  
2. 回到 Unity，等右下角 **导入完成**。  
3. 在 Project 窗口 **点一下** 音频，Inspector 里确认 **Load Type** 一般为 `Decompress On Load` 或默认即可（有特殊需求再和程序说）。

> 音频 **不必** 文件名和节点一一自动对应；**最终以你在节点里拖的那条为准**。文件名只是方便自己管理。

---

## 第三步：在对白节点上绑定配音（核心）

### 3.1 打开对话 Prefab

1. 在 Unity **Project** 窗口找到 Prefab，例如：  
   `GameRes/Prefabs/Dialogue/Village_KenMuNiStart.prefab`  
2. **双击** 打开 Prefab 编辑模式（或选中后 Inspector 点 **Open**）。

### 3.2 打开对话图（NodeCanvas）

1. 在 Hierarchy 里选中带 **Dialogue Tree Controller** 的物体（通常是对话根节点）。  
2. 在 Inspector 里找到 **Edit Graph** / **Open Graph** 按钮，打开 **对话节点图**。

### 3.3 找到「雅尔」说的每一句

- 节点类型一般是 **`SayEx`**（或 Say）。  
- 节点上会显示 **说话人 + 台词摘要**；找 **`雅尔`** 的节点。  
- 顺序一般与台本 ID 一致，从上到下读图最稳。

### 3.4 绑定 Audio File

1. **单击** 该 `SayEx` 节点。  
2. 在右侧 Inspector 找到 **Statement** 区域。  
3. 找到 **Audio File**（或 **Audio Clip**）一栏。  
4. 从 Project 里把对应 `.wav` **拖进** 这一栏。  
5. **Ctrl+S** 保存 Prefab。

对 **每一句雅尔台词** 重复 3.3～3.4。

### 3.5 两种常见维护方式

| 方式 | 适合谁 | 做法 |
|------|--------|------|
| **A · 直接在 Prefab 里绑（当前推荐）** | 配音已齐、Prefab 已是最终版 | 按 §3.3～3.4 逐节点拖 Audio |
| **B · 先写 CSV，再导入生成图** | 台本还在改 | CSV 写好台词 + `FaceType`；**Voice 列可先填文件名备档**（见下文「关于 CSV Voice 列」） |

## 第四步：试播验收

### 4.1 用 DialogDebug 快速听（推荐）

1. 打开场景：`Assets/GameRes/Scenes/DialogDebug.unity`  
2. 选中场景里的 **DialogDebugPlayground**（或同类测试物体）。  
3. Inspector 里 **Dialogue Prefab** 拖入你要测的 Prefab（如 `Village_KenMuNiStart`）。  
4. 点 **Play**。  
5. 游戏视图里对话开始后，听 **雅尔每句是否有人声**、是否与字幕同步。

详细说明见：`Assets/Doc/执行文档/0525/DialogDebug对话测试场景_施工执行说明.md`

### 4.2 实机序章流程听

| 测什么 | 怎么进 |
|--------|--------|
| 新游戏开场 | 主菜单新游戏 → 漫画播完 → `NewGameStory` 对话 |
| 进村 | 流程进入肯姆尼 → 触发 `Village_KenMuNiStart` |

### 4.3 验收清单（策划自用）

- [ ] 每一句 **雅尔** 台词都有 Audio File（未录完的可先空，但要列表标注）  
- [ ] 播放时 **先出声、字幕同时显示**；播完或按键能跳下一句  
- [ ] **古莎 / 国王 / 旁白** 未误绑到雅尔音频  
- [ ] 无「只有打字声、明明已绑却无声」（见 FAQ）

## 命名建议（方便对台本）

与 **台本 ID** 或 **场次** 对齐，例如：

| 场次 | 文件名示例 | 对应台本 |
|------|------------|----------|
| 进村 | `KM_Yaer_001.wav` | 村内开场 ID=1「好漂亮的村子。」 |
| 进村 | `KM_Yaer_003.wav` | ID=3「我挺好奇的。」 |
| 新游戏 | `NG_Yaer_001.wav` | NewGameStory 第一句雅尔台词 |

在 Excel / CSV 的 **Voice** 列写 **同一文件名（不含路径）**，方便和程序对表，例如：

```csv
ID,Type,Speaker,Text,...,Voice
1,Dialogue,雅,好漂亮的村子。,...,KM_Yaer_001
```

## 关于 CSV 的 Voice 列（重要）

新版 CSV 表头可以带 **`Voice`** 列（见埃吉尔等台本）。  

| 现状 | 说明 |
|------|------|
| **台本里可以写 Voice** | 方便策划备档、和音频文件名对齐 |
| **自动导入绑 Audio** | **尚未完全接通**；导入后仍可能要在图里 **手动拖 Audio File** |
| **当前可靠做法** | **以 Prefab 里 SayEx 节点的 Audio File 为准** |

若你只用 CSV 导入生成了新的 `.asset` / 合并进 Prefab，绑配音步骤仍是 **§第三步**。

## 常见问题 FAQ

**Q：绑了音频但没声音？**  
- 检查 Project 里该音频能否在 Inspector 点 **Play** 预览。  
- 确认绑在 **雅尔那句 SayEx** 上，不是别的节点。  
- DialogDebug 场景是否已 **Play** 且 Prefab 拖对。

**Q：有语音但字幕对不上？**  
- 音频内容应与 **Statement → Text（中文）** 同一句；换音频或改文案保持一致。

**Q：旁白行能绑配音吗？**  
- **不要**。Speaker 为 **—** 的行仅字幕，绑音频可能出错。

**Q：英/日语言也要配音吗？**  
- 程序按当前语言显示 `text` / `text_en` / `text_jp`，但 **Audio File 只有一条**。  
- 首版通常 **只配中文**；多语需另定方案（不同 Audio 或多 Prefab）。

**Q：和立绘、表情有关系吗？**  
- **无直接关系**。配音绑在 **SayEx → Audio File**；表情填 **FaceType**，见 `对话立绘表情与图片名称对照_执行说明.md`。
