## 沟通摘要

### ① 结论一句话

**不是「没生成尸体」**：死亡链会进 `SlimeDeadState` 并最终 `ShowDropItem`；根因是 **Dead 没冻刚体 + `canGravity` 仍开**，脚变 Trigger / GroundCld 关掉后一旦 `IsGrounded=false`，`MoveComponent` 用 **Gravity.y=-100** 把整只怪（含子物体 `dropItem`）瞬间拽出镜头。体感「无尸体无掉落」= **飞出屏外**（0912 Sprite 案是另一回事）。

### ② 原因（通俗）

藤蔓 / 木虫一死就把刚体冻死、改成 Kinematic，尸体钉在原地。史莱姆这两行**被注释掉了**，死后还按「活着」吃重力。站在地上打死时脚底射线往往还认得到地，看起来多数正常；跳起来、掉树半空、或刚体 Y 没冻住时，一旦脚下判定丢了，重力特别大，尸体连同脚下掉落一起掉进井里——所以你会觉得「有时有尸体、有时脚下一空」。

### ③ 用户需要做什么（检查清单）

| # | 操作 | 现网预期（未修） |
|---|------|------------------|
| 1 | ForestEast：地面史莱姆 **Idle 站桩** 普攻打死 ≥3 | 多数：尸体留在脚下；偶发若残速/离地则仍掉 |
| 2 | 同一只：**JumpAtk 升空中**打死 ≥3 | **高概率** Y 快速下降、出屏；Hierarchy 物体仍在、Y 极低 |
| 3 | 死后立刻暂停：看 `Rigidbody2D.constraints` / `velocity` / `MoveComponent.canGravity` | Dead 期间多为 `FreezeRotation`（非 FreezeAll）；`canGravity=true` |
| 4 | Hierarchy 展开尸体：找 `dropItem` | 动画末应 `active=true`；若父物体已出屏 → **有掉落但看不见** |
| 5 | 对照打死 TenWan / WoodWorm 同情境 | 应稳定留尸（Dead 有 FreezeAll + kinematic） |
| 6 | 确认 Sprite：`dropItem` Inspector | 若有图仍掉屏 → **不是** 0912 Missing；若 Missing → 另案残留 |

## 1. 结论（程序向）

| 项 | 裁定 |
|----|------|
| **「无尸体」真实形态** | **进了 Dead，但 Transform 被重力拖出可见区**；非立刻 Destroy / 非对象池吞掉 |
| **「无掉落」真实形态** | **连带**：`dropItem` 挂怪下，父物体出屏 → 以为没刷；`ShowDropItem` 链本身通（与 0912 Sprite 断链正交） |
| **主因（嫌疑 A）** | `SlimeDeadState.Enter` 中 `FreezeAll` **整行注释**；`Slime.OnDead` 中 `canGravity=false` **整行注释**；死后仍走 `MoveComponent.OnFixedUpdate` 重力 |
| **为何「有概率」** | 非 RNG：取决于死时 **是否仍被判定落地** + **Y 是否已解冻**。地面 Idle/Attack + Raycast 仍命中 → 常留住；JumpAtk / BornFall 空中 / 离地瞬间 → 必掉或高概率掉 |
| **与 TenWan/WoodWorm** | 二者 Dead 均 `FreezeAll` + `isKinematic=true`；WoodWorm 同样注释了关重力却不掉 → **只差 FreezeAll（+ kinematic）即足以解释** |
| **0912 同轴案** | **非根因**（FreezeAll 注释是旧状）；但 Idle 冻 Y、JumpAtk 解冻 Y **放大了「站着死稳 / 跳着死掉」的对比面** |
| **Dead 是否误 Snap** | **否** — `SnapToCombatAxisY` 仅 BornDown / JumpAtkDown / Idle / Move Enter；Dead 未调 |
| **推荐修复** | **方案 A**：对齐藤蔓/木虫 — `SlimeDeadState.Enter` 恢复 `FreezeAll` + `isKinematic=true`，并清竖直速度；可选顺带 `canGravity=false`（双保险） |

## 2. 调用链（击杀 → 物理 → 掉落）

```
HP=0 → HealthComponent.onHpIsZero
  → ★ Slime.OnDead()
       → base.OnDead()
            isDead=true；isProtect=true
            bodyCld/footCld.isTrigger = true
            groundCld.enabled = false          ← 0723 防站上卡；死后无实心支撑
            StopMoveOnPosX()                   ← 只停 X，不清 Y
            recordMonsterHasDead / Quest …
       → // canGravity=false  ★现网注释
       → bodyCld/footCld.isTrigger = true（再写一次）
       → 若 isJumpAttacking && isFallDownAtk:   ← 现网几乎不成立（见 §3 E8）
            ExitCurrentSubStateMachine → ChangeState<SlimeDeadState>
         else:
            csAnimator.ChangeState<SlimeDeadState>
       → CldController.SetActiveAll(false)

  → ★ SlimeDeadState.Enter
       isProtect=false
       CldController.SetActiveAll(true)        ← 尸体期再开碰撞节点
       // BodyRg.constraints = FreezeAll       ← ★现网注释（断点）
       // 无 isKinematic=true
       // 无 StopMove / 清 Velocity.y

  →（前态 Exit 可能已解冻 Y）
       SlimeIdleState.Exit → constraints = FreezeRotation  ← Idle 打死也会先解冻 Y

  → ★ 每帧 MoveComponent.OnFixedUpdate（死后仍跑）
       GroundCheck() → CapsuleGroundChecker 向下 Raycast（不依赖脚实心）
       if (!IsGrounded && canGravity)
            Velocity += fixedDeltaTime * Gravity   // Prefab Gravity.y = -100
       rg.velocity = Velocity
       → Y 暴跌出屏（断点：物理）

  → Dead.anim 末帧 time=1
       AnimaEventTrigger → RemoveMonsterOnDead:Slime
       → MonsterDeadEndEvent → ShowDropItem（dropItem 子物体跟父 Transform）
       → 若此时父已在屏外 → 「看不见掉落」

  →（无掉落或捡完）MonsterDelayRemove → 淡出 → Destroy
```

**断点标注**

| 环节 | 状态 |
|------|------|
| 进 Dead / Dead.anim 事件 | ✅ `Assets/Animation/Object/Monster/Slime/Dead.anim` 仍有 `RemoveMonsterOnDead:Slime` |
| `ShowDropItem` 逻辑 | ✅ 与 0912 相同；本案不在此断 |
| Dead 冻刚体 | ❌ `SlimeDeadState` 注释掉 |
| 关重力 | ❌ `Slime.OnDead` 注释掉 |
| 死后写 Velocity.y | ❌ `MoveComponent` 仍施加 Gravity=-100 |
| Snap 误伤 Dead | ✅ 排除（Dead 不调 Snap） |

## 5. 修复方案对比

### 方案 A（推荐 · 最小对齐）

在 `SlimeDeadState.Enter` 恢复与藤蔓/木虫一致：

```csharp
// 伪代码意图（本阶段不施工）
moveCpn.StopMove();                 // 可选：清 Velocity
moveCpn.canGravity = false;         // 可选双保险
bodyRg.velocity = Vector2.zero;
bodyRg.constraints = RigidbodyConstraints2D.FreezeAll;
bodyRg.isKinematic = true;
```

| 利 | 弊 |
|----|-----|
| 改动面仅 DeadState（+可选 OnDead 一行）；与现网其它怪一致 | 尸体期完全不动（产品本就要留尸） |
| Idle/Move/跳/树 全覆盖 | 须确认引导剧情 `FirstMeetSlimeGuide` 仍靠 Dead `IsFinished` 回调（现逻辑不依赖下落） |
| 不碰 MoveComponent 全局、不碰 GroundCld、不碰 Snap | `isKinematic` 后碰撞表现需抽测「踩尸体」不卡（0723） |

**最小改动面**：优先只改 `SlimeDeadState.cs`；若仍偶发，再恢复 `Slime.OnDead` 的 `canGravity=false`。

### 方案 B（仅冻 Y + 清竖直速度）

`FreezePositionY`（或 `FreezePositionX|Y`）+ `velocity.y=0` + `canGravity=false`；不设 kinematic。

| 利 | 弊 |
|----|-----|
| 保留 Dynamic，理论上可被轻推 | 与其它怪不一致；若漏清速度或漏关重力仍可能抖 |
| | Idle.Exit 已解冻，必须在 Dead.Enter 立刻冻回，时序更脆 |

**不优先**：不如 A 对齐对照实现。

### 方案 C（死亡瞬间 Snap 到当前 Y 再冻）

Dead.Enter 先把 `transform/rg.position.y` 钉在**死亡当帧 Y**（勿 Snap 到玩家轴——空中死会「瞬移落地」），再 FreezeAll。

| 利 | 弊 |
|----|-----|
| 空中死尸停在空中「合理」 | 多一步；产品若接受空中留尸可叠加在 A 上 |
| | 单独 Snap 不冻仍会掉 → **不能只做 C** |

**可选叠加**：若产品要「空中死尸停空中」，A + 不 Snap 到玩家即可（冻在当前 Y）；**禁止** Dead 调 `SnapToCombatAxisY()`（会把跳杀尸体拽到玩家高度，破坏验收观感）。

### 推荐与禁止

| 项 | 内容 |
|----|------|
| **推荐** | **方案 A**（DeadState FreezeAll + kinematic；建议同时清速度；可选 `canGravity=false`） |
| **不要动** | 0912 `SnapToCombatAxisY` 调用点；0723 `groundCld` Trigger/关 enabled 策略；`MoveComponent` 全局重力公式；掉落 Sprite / Prefab 重绑；TenWan/WoodWorm（除非验收证明也坏）；村庄 `TownPlayerLocomotion` |
| **可选后续** | 修正 OnDead 特判：`isJumpAttacking`（不必 `&& isFallDownAtk`）时 `ExitCurrentSubStateMachine` 再进 Dead（时序整洁，非本期留尸必需） |

### 回归风险

| 风险 | 说明 | 验收 |
|------|------|------|
| 0912 同轴 | Dead 冻死后不应再走 Idle/Move Snap；活体 Snap 路径不动 | 落地/Move 后 Y 与玩家差 ≤0.2 |
| 0723 站上卡住 | 保持 GroundCld 死后 disabled / 生前 Trigger；勿改回实心挡脚 | 人踩史莱姆壳不卡死 |
| 掉落拾取 | 尸体留屏内后 `dropItem` 可点、距≤4 进 `SlimeCore` | 常驻有掉落史莱姆 ≥3 |
| 引导剧情 | `FirstMeetSlimeGuideStoryMgr` 在 Dead `IsFinished` 回调 | 引导关抽测一次 |
| 击退/伤口 | 击飞途中致死：A 应钉在致死瞬间位置 | JumpAtk/击退各 ≥3 |

### 验收标准（施工后）

1. Idle / Move / JumpAtk 空中 / 树上掉落后击杀 **各 ≥3**：尸体屏内可见，Y 不持续下降。  
2. 有掉落常驻史莱姆：`dropItem` 可见可捡进包。  
3. 抽测 0912：落地与 Move 同轴仍成立。  
4. 抽测 0723：人踩壳不卡死。  
5.（可选 Debug）`[SlimeDeadFallDebug]`：OnDead / Dead.Enter 打 `pos.y`、`velocity`、`constraints`、`canGravity`、`IsGrounded`、来源状态。

## 7. 给施工员的一句话

**只修史莱姆死亡定格**：在 `SlimeDeadState.Enter` 对齐 `TenWanDeadState` / `WoodWormDeadState` 的 `FreezeAll` + `isKinematic`；不要重绑掉落图，不要动同轴 Snap 与 GroundCld。
