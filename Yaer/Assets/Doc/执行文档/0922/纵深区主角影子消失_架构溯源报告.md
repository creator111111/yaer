## ① 结论一句话

**本案是脚底 Blob（`ShadowAnimator` / `showdowArea`），不是 EnvironmentShadow 身上压暗。**  
主因两刀、常叠加：

| 刀 | 机制 | 与「走纵深才没」吻合度 |
|----|------|------------------------|
| **A. 显隐** | `OnUnIsGround` → `showdowArea.SetActive(false)`；纵深时 Town 用 **`velocity.y` 追权威 Y**，易令 `GroundCheck` 抖成空中 → 影子被关 | **极高**（纯左右少写 vy → 影子仍在） |
| **B. 排序** | `ApplyDepthSortingFromWorldPosition` **只写** `spriteForDepthSort`（身体）；影子 Prefab 钉死 `sortingOrder: -1`，不跟 Y；怪物则是 `order-2` 跟身 | **高**（Active 仍 true 时被草地/合层盖住 =「消失」） |

推荐 **A+B**：村/2.5D 下影子显隐与落地解耦（或纵深模式视为贴地显示）+ Town 排序同时写影子 Order（对齐怪物 `bodyOrder-2`）。**否决**改 EnvironmentShadow / 关纵深 / 大挪 Sorting Layer。

截图「白发蓝角持剑」偏 **古莎造型**；若为场景贴纸/NPC 无 `ShadowAnimator`，与 Controllable 雅尔分表验收（方案 D），**勿混成同一 Prefab 缺影子**。

## ④ 调用链

### 显隐（假说 A）

```
MoveComponent.GroundCheck()
  → IsGrounded 变 false → UnGroundedEvent
BaseEntityLogic.OnUnIsGround
  → showdowArea.SetActive(false)

Town 纵深：WriteRoot 在 depthVelocity≠0 时设 rb.velocity.y = clamp(dy/dt)
  → 易导致 GroundCheck 失败 → 影子关掉
纯左右：depthVelocity≈0，清 vy、吸权威 Y → 更易保持 Grounded
```

```29:43:Assets/Scripts/Game/GameRuntime/Entities/Base/BaseEntityLogic.cs
    public virtual void OnUnIsGround()
    {
        if (showdowArea != null && showdowArea.activeSelf)
            showdowArea.SetActive(false);
    }
    public virtual void OnGroundedEvent()
    {
        if (showdowArea != null && !showdowArea.activeSelf)
            showdowArea.SetActive(true);
    }
```

### 排序（假说 B）

```
TownPlayerLocomotion.OnFixedUpdate / OnUpdate
  → ApplyDepthSortingFromWorldPosition()
       → 仅 spriteForDepthSort.sortingOrder = Round(-(y * 100))
影子 SR：Prefab 钉死 Order=-1；DepthZone 可能改 Layer，但 Order 不跟 Y
怪物：showdowArea.sortingOrder = spriteSortIndex - 2  ★ 跟身
```

```1098:1108:Assets/Scripts/Game/GameRuntime/Entities/Player/Components/TownPlayerLocomotion.cs
        private void ApplyDepthSortingFromWorldPosition()
        {
            if (spriteForDepthSort == null) { return; }
            int order = Mathf.RoundToInt(-(w.y * depthSortingFactorY));
            spriteForDepthSort.sortingOrder = order;
            // 无影子
        }
```

### 跟随

`ShadowComponent`：拷身体 Sprite；可选只跟 X。子节点随根 Y 走，**位置一般不是主因**；优先 Active/Order。

### 与 EnvironmentShadow 无关

压暗 = 专用相机 RT + `_ShadowTex` 画在人身上；**不是**脚下椭圆。技术文档已分清；本票不修该链。

## ⑤ 方案对比与路径

| 方案 | 做法 | 何时选 | 裁决 |
|------|------|--------|------|
| **A** | 村/2.5D：影子显隐不跟 `OnUnIsGround`，或纵深模式强制贴地显示；可选修 GroundCheck | Active 被打 false | **主修之一** |
| **B** | `ApplyDepthSorting` 同时写影子 Order = 身体 Order − 2（对拍怪物） | Active true 仍「没」 | **主修之一** |
| **C** | 影子本地 Y / 跟脚点 | 飞离脚底 | 次选 |
| **D** | 古莎/换装补 ShadowAnimator 与曲线 | 特定角色从未有 | 分表 |
| **E** | EnvironmentShadow | 用户要压暗才做 | **否决为主因** |

### 必答

1. **主因**：纵深下 **落地门闩藏影子** 与/或 **深度排序漏影子被地片盖住**；非缺实时光、非压暗相机。  
2. **截图角色**：先确认是否 Controllable 雅尔；古莎贴纸另 D。雅尔修 A+B 即可覆盖「纵深区主角」。  
3. **最小文件**：`BaseEntityLogic`/`PlayerLogic`（显隐策略）、`TownPlayerLocomotion.ApplyDepthSortingFromWorldPosition`（影子 Order）；可选 `ShadowComponent`。  
4. **验收**：纵深来回走 Blob 不消失；非纵深不回潮。

## ⑧ 风险与回滚

| 风险 | 处置 |
|------|------|
| 影子 Order 过大盖脚 | 用 body−2，对拍怪物 |
| DepthZone 锁 Order | 与 Listener 合成策略一致；影子跟同一主 Renderer |
| 空中跳仍显示影子 | A 可限「仅 Village2_5D」或「非跳跃态」 |
| 误改 EnvironmentShadow | 禁止 |
| 古莎贴纸当玩家修 | 先分身份再 D |

**回滚**：还原显隐与 ApplyDepthSorting；保留纵深移动逻辑。
