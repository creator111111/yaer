## ① 结论一句话

三类主诉**不全同源**：**BOSS 战图进出**与 **读档进仍 `smoothTime=0.3` 的场景** = Stairs 同款「`SetFollow(forceSnap)` 手推 + 早揭幕」；**树桥进出**在东郊已 `smoothTime=0` 后仍可能闪/滑 = **另缝**（同场景黑幕内 `ChangeCamera` 切 Bound/Size + 只 Snap Y，且 **立刻** `CloseFormFade`，不靠进场手推字段）。优先：**P0** 改 `WestRappRoad.smoothTime=0` + 读档路径对齐（场景字段批改和/或读档强制当帧定格）；**P1** 树桥时序/全轴 Force；**禁止**动 `ForestScene` 整场景 `smoothTime`（林恩可见运镜）。

## ③ 三类主诉分节

### 3.1 BOSS 战图（`WestRappRoad`）

**调用链（进图）**

```
ForestEastScene Door（NextSceneName: WestRappRoad, TriggerWhenMoveIn: 1）
  → LoadSceneComponentGSM.LoadScene(blackFade:true)
  → InitPlayer → SetPlayerPos(lastScene=ForestEast → LeftBorn)
  → SetFollow(forceSnap)  // WestRappRoad.smoothTime=0.3 → 手推
  → Ready → hold≈0.3s → CloseFormFade
  → 揭幕手推未完 → 闪/滑
```

**出图**：`LeftDoor` → `ForestEastScene`；落点 `EnterPosConfig lastScene:WestRappRoad` ≈ **(372.99, −6.61)**。目标东郊 **已 smoothTime=0** → 当帧定格，**进西境修完后回东郊应已 OK**。

**CameraBossArea**：场景内 Polygon（世界约 x∈[65,145.5]），挂在 Camera 下作区域盒；Boss 剧情现网见 **Impulse**（`WestRappRoadGoblinAndGusha`），**不是**进场 `SetFollow` 主因。开战切镜/震屏标 **加重或另缝**，勿与进图闪滑混修。

| 项 | 裁定 |
|----|------|
| 同源？ | **是**（进西境） |
| 最小修 | **方案 A**：`WestRappRoad.unity` `CameraComponent.smoothTime: 0.3 → 0` |
| 只改西境能否盖「进 BOSS 图」？ | **能** |
| 出西境回东郊？ | **已因东郊=0 定格**；本票不必再改东郊 |
| 误伤 | 日常跟拍仍靠 CM Damping；Impulse 不读 smoothTime |

### 3.2 桥图（TreeBridge，东郊同场景）

**调用链**

```
ForestEastTreeEnterTrigger
  → Sign/超时 → AutoMove → 1s 后
  → BlackPanel FadeShow
  → 瞬移玩家 X（Y 用当前脚高 + offset0）
  → ForestEastTreeBridgeStoryMgr.ChangeCamera(isEnter)
       ChangeCameraBoundingArea(树内/树外 Polygon)
       进洞：OrthoSize=5 + SnapLiveOrthoYToConfinerFloor（只 Force Y）
       出洞：Reset Size=7.9
       OuterSpriteFade
  → CloseFormFade（**无 hold**，且未再 SetFollow / 未 Force X）
```

读档洞内：`archiveStart` 落档内坐标 → `SetFollow`（东郊 smoothTime=0 → 当帧）→ `CheckPlayerHasInSpcArea` → 同一 `ChangeCamera(true)`。与 0914 贴底同源写入点；本票主诉是闪/滑，贴底仍背景。

| 项 | 裁定 |
|----|------|
| 同源 Stairs？ | **否**。东郊已 0 后若仍闪/滑，**证明不靠进场 smoothTime** |
| 主因候选 | ① 黑幕内切 Bound/Size 后 CM Framing 多帧追 X；② Snap 只改 Y；③ **立刻揭幕**；④ 出洞前 `StopCameraAction` 曾 DOMove **MainCamera→(0,0)**（与 Brain 抢位，可加重） |
| 最小修 | **策略 T**：黑幕内 `ChangeCamera` 后 **全轴对齐**（`SetFollow(forceSnap)` 或 `ApplyFollowWithCinemachineStateAligned` / Force XY）再 `CloseFormFade`；或短 hold 等一帧 Brain。**勿**指望再改东郊 smoothTime |
| 误伤 | 勿关洞内 `CameraAction` 爬行晃动；勿挪 CameraTreeInArea；勿全局 hold |

### 3.3 读取存档

**调用链**（`ProcedureComponentGM.LoadGame`；死亡面板 / LoadGame 面板同绑 `onLoadGameAction`）

```
BlackPanel FadeShow
  → ExitGame / OnExit / OnShutDown（若已在局中）
  → LoadArchive(guid)
  → onGameSceneManagerReady:
       CloseFormFade(...)   // ⚠️ 无 mapTransitionBlackHoldSeconds
       archiveStart=false; StartGame
  → ChangeSceneComponentGM.LoadScene(PlayerSceneData.sceneName)
  → 新场景 InitPlayer:
       archiveStart==true → SetPos(档内 pos)   // 不用 EnterPosConfig
       SetFollow(forceSnap)                   // 读目标场景 smoothTime
       CheckPlayerHasInSpcArea（洞内再 ChangeCamera）
```

| 项 | 裁定 |
|----|------|
| 同源？ | **机制同源**（forceSnap 手推 + 揭幕早）；读档 **hold=0**，比门换场 **更早露景** |
| 是否所有 0.3 场景都中招？ | **是**（只要 Δ 足够大就会看见）；已 0 的场景读档应定格（洞内另叠加 ChangeCamera） |
| 是否缺 lastScene？ | 读档走档内坐标，**不依赖** LastScene EnterPos；Δ 来自「默认 VCam ↔ 存档坐标」 |
| 最小修 | **P0**：① 策略 A 把读档常达且 blackFade 进场的场景改 0（西境 + 村屋等）；② 可选 **A2**：`archiveStart` 期间强制当帧对齐（临时 smoothTime=0 或 InitPlayer 分支忽略 smoothTime）——覆盖漏网场景；③ **不推荐**只拉长读档黑幕作主修 |
| 误伤 | A2 若写太宽会波及「故意软推」路径；宜限定 `archiveStart` / 读档 Ready 窗口 |

## ④ 方案对比与推荐优先级

| 策略 | 适用 | 禁忌 |
|------|------|------|
| **A 场景 smoothTime=0** | blackFade 跨场景 / 读档进场定格 | ForestScene 门口可见运镜；产品要软推的演出 |
| **A2 读档强制当帧对齐** | 读档无 hold + 漏网 0.3 场景 | 不要只拉长黑幕；勿无条件改一切 SetFollow |
| **T 树桥** | Bound/Size/Snap 后揭幕前全轴贴齐 | 勿用东郊 smoothTime 解释洞内切镜 |
| **B 拉长 hold** | 仅不能动字段时 | 不作默认主修 |

### 必答

1. **只改 `WestRappRoad.smoothTime=0` 能否覆盖「进 BOSS 战图」？** 能。出西境回东郊已因东郊=0 定格。  
2. **树桥在东郊已 0 后仍闪/滑证明什么？** 不同源——洞内切镜 + 即揭幕，不是进场手推字段。  
3. **读档闪滑范围？** 所有仍 0.3（或未序列化默认 0.3）且 Δ 大的场景都会中招；读档路径 **少了 hold**，不是缺 lastScene。  
4. **公共层补丁 vs 逐场景？**  
   - **逐场景 A**：与 Stairs/出店先例一致、回归面可控；漏改会再漏票。  
   - **A2（仅 archiveStart）**：一次盖读档；须破「不改公共契约」先例，但读档 **无 hold** 是额外证据。建议 **P0 先 A 西境 + 村常用图，A2 作 P0/P1 补强**，勿一上来改所有 SetFollow。

### 优先级

| 级 | 内容 |
|----|------|
| **P0** | `WestRappRoad.smoothTime→0`；读档：西境 + 已 0 场景验收；规划村屋/Chief/OutSide/night 批改或上 A2 |
| **P1** | 树桥策略 T；Village_Home* / Chief / OutSide / KenMuNi_night →0 |
| **P2** | Village_Shop / Village.unity / 流程场景按需；Boss Impulse **不改** |
| **禁止** | `ForestScene.smoothTime→0`；全局无差别一刀切；用拉长 hold 当主修 |
