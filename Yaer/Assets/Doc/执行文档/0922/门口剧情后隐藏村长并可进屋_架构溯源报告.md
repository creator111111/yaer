# 门口剧情后隐藏村长并可进屋 · 架构溯源报告

> 日期：2026-09-22  
> 角色：架构侦探（**只读**，未改代码 / 场景 / Prefab）  
> Unity：2020.3.48f1  
> 现象：`Village_村长家门口初次对话` 播完后，门口仍摆着村长、门「进不去」  
> 场景：`Village_KenMuNi1` · `Npc_Chief` / 合层 `村长` / `House_Chief` → `Village_Chief_House`  
> 提示词：`Assets/Doc/提示词/0922/门口剧情后隐藏村长并可进屋_架构侦探提示词.md`

## ① 结论一句话

**从未实现「播完藏村长」**：`OnStoryFinished` 只做自动黑幕进屋，不关人；`Village_KenMuNiSceneManager` 进村也不按门口戏已用藏人。合层 `村长`（装饰 SR）与 `Npc_Chief`（交互体）播完后仍 Active → 回村/留门外必见人。

**门**：`House_Chief` 仍在、指向 `Village_Chief_House`、`ShowLoadingUI=0`（黑幕）；**未被删**。主诉「进不去」优先归 **人仍挡观感** + **回村残留**；次因：`House_Chief` 场景**未覆写** `TriggerWhenMoveIn` → Prefab 默认 **0（点交互进）**，与同场景楼梯门 `=1` 不一致——若产品要走进即进，须另开门闩补丁。

**自动进屋取舍**：**保留** `loadChiefHouseOnStoryEnd=true`（现网已勾；0901/0902 续聊链依赖「播完→进屋」）。推荐 **A+B**：藏人（结束当帧 + 进村/读档）+ 保留自动进屋；**勿擅自关自动进屋**（方案 C 仅产品明确只要手进时用）。

## ③ 调用链与对拍

### B1. `OnStoryFinished` — 只进屋，不藏人

```
ChiefNearDoorStoryTrigger.OnStoryFinished
  → base（计数/退订）
  → if loadChiefHouseOnStoryEnd → LoadScene(Village_Chief_House)  // blackFade
  → ❌ 无 Npc_Chief.SetActive(false)
  → ❌ 无关合层「村长」
  → ✅ 仅关 GushaSidePortrait（onStoryEnd 另一订阅）
```

```233:263:Assets/Scripts/Game/GameRuntime/Entities/SceneEntities/Village_KenMuNi/ChiefNearDoorStoryTrigger.cs
        protected override void OnStoryFinished()
        {
            base.OnStoryFinished();
            if (!loadChiefHouseOnStoryEnd) { return; }
            // ...
            loadGsm.LoadScene(SceneName.Village_Chief_House);
        }
```

`SimpleStoryTrigger` 已用后：`this.enabled = false`，**不关 GameObject** → Collider/节点仍在；且合层 `村长` 根本不挂该组件。

### B2. `OnEnterScene` — 无门口戏显隐

`Village_KenMuNiSceneManager` 只按 `homeDoorStoryComplete` 管莱/相机/BGM；**无** `CheckStoryUsed("Village_村长家门口初次对话")` → 藏 `Npc_Chief` / 合层 `村长`。  
对照莱：`TrySetSceneEntityActive<ForestSceneLaiLogic>(!homeDoorStoryComplete)` —— 门口村长缺同构。

### B3. `House_Chief`

| 项 | 现状 |
|----|------|
| Enabled / Active | Prefab 启用；场景未删 |
| NextScene | `Village_Chief_House` |
| ShowLoadingUI | **0** → 日常黑幕（0902） |
| TriggerWhenMoveIn | **未覆写 = 0** → 须点交互；同 Prefab 的 `StairsDoor_BackToChief` 显式写成 **1** |
| 与村长重叠 | `Npc_Chief` 大 Trigger 与门邻近；`canTouchWithPlayer=0` 不挡物理；合层仅 SR 不挡 Collider |
| 门闩锁 | **无**「戏未播不可进」逻辑；门一直可交互进 |

故「进不去」**不是**门被删/被关 Active；多为 **人还在** + **走进无触发（须点）**。

### B4. 应藏哪些？

产品「别再摆人」→ **两者都藏**：

| 物体 | 理由 |
|------|------|
| 合层 `村长` | 玩家看见的贴画 |
| `Npc_Chief` | 交互体积/再触发风险；已用后组件虽禁用，GO 仍占位 |

**勿**只关 `GushaSidePortrait` 充数。

### B5. 自动进屋 vs 手进

| 组合 | 含义 | 裁决 |
|------|------|------|
| **A+B** | 藏人 + **保留**自动进屋；回村/失败路径靠 A；手进门仍可用 | **推荐默认** |
| A+C | 关自动进屋，只藏人+手进 | 仅产品明确不要自动进 / 续聊另挂 |
| 只 B | 自动进屋但回村仍见人 | **不够** |
| D/E | 挪 Collider / 删门 | **否决** |

续聊（`Village_村长家继续对话`）门闩依赖「门口戏已用 ∧ 续聊未用」在 **进屋后** `OnEnterScene`；关自动进屋会打断现网主路径，故本期默认不拆。

## ④ 方案对比

| 方案 | 做法 | 何时选 | 裁决 |
|------|------|--------|------|
| **A** | 门口戏已用 → 关 `Npc_Chief` + 合层 `村长`（`OnStoryFinished` 当帧 + `Village` `OnInit`/`OnEnterScene` 读档） | 凡回门外须无人 | **主修** |
| **B** | 保留 `loadChiefHouseOnStoryEnd=true` | 现网续聊自动进屋 | **保留** |
| **C** | 关自动进屋，只 A + 手进 | 产品不要自动进 | 备选 |
| **D** | 只缩 Collider 不藏人 | — | **否决** |
| **E** | 删门 / 改回对白 | — | **否决** |
| **F**（可选） | `House_Chief` 场景覆写 `TriggerWhenMoveIn=1` | Play 证实「走进无反应」且产品要走进即进 | 与 A 可同批；不替代藏人 |

### 必答

1. **藏谁**：合层 `村长` + `Npc_Chief`。  
2. **门为何像进不去**：人未藏为主；次因点进 vs 走进。门本身未锁死。  
3. **自动进屋**：保留（B）；用 A 覆盖回村/失败。  
4. **最小文件**：`ChiefNearDoorStoryTrigger.cs`（结束藏人）；`Village_KenMuNiSceneManager.cs`（进村按 `CheckStoryUsed` 藏）；可选场景 YAML 关默认 Active / 绑引用；可选 `House_Chief` `TriggerWhenMoveIn`。

## ⑦ 风险与回滚

| 风险 | 处置 |
|------|------|
| 只关 `Npc_Chief`、合层仍见人 | **必须双关** |
| 进村过早藏、未播戏 | 严格 `CheckStoryUsed(DoorStoryPrefabName)` |
| 关自动进屋打断续聊 | 本期默认 **不关**；若改 C 须重挂续聊入口 |
| Find 合层名失败 | 场景绑引用优先 |
| `TriggerWhenMoveIn=1` 与门口大 Trigger 抢进 | 先藏 `Npc_Chief` 再测；必要时缩门 Collider |
| 送树屋 / 相机闪 | **不动**（0920 临时关送树屋仍有效） |

**回滚**：还原显隐调用与可选门覆写；保留 0902 黑幕进屋 API。
