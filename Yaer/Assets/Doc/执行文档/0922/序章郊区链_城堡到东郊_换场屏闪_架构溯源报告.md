## ① 结论一句话（两段分裁 + 一并修）

| 段 | 路径 | 裁定 |
|----|------|------|
| **①** | 城堡→郊 `HomeScene1→ForestScene` | **Stairs 同源**：`InitPlayer.SetFollow(forceSnap)` + 目标 **`ForestScene.smoothTime=0.3`** + 黑幕 hold≈0.3s 早揭幕。Δ 约 **(4.2, −6.6)**。**禁止**整景改 0（林恩 M3 可见手推 / 0912·0922 钉死）。 |
| **②** | 郊→东郊 `ForestScene→ForestEastScene` | 东郊磁盘 **已 `smoothTime=0`**（0922 走廊案）→ **进场手推应已消**。若仍「闪」：主因转向 **Loading 壳时序** + 首进 **`ForestEastSceneFirstEnter` 的 PlayerAutoMove（≈+8u）+ CM XDamping**，或截图 **半透明残影（Alpha）**——**勿再改东郊 smoothTime 交差**。 |

**一并施工推荐**：**P0 = 方案 B/C 变体（进场 instantSnap / 临时 0，不改 Forest 磁盘字段）** 盖段①，并让凡进 Forest 仍为 0.3 的路径（含东郊→郊反向大 Δ）受益；**P1 = 方案 D/E**（FirstEnter 时序或 Alpha）专治段②首进残差。同一施工说明分节；**勿回退** Stairs / 出店 / 东郊↔走廊已定格。

## ③ 调用链 / smoothTime / FirstEnter

### 双壳图

```
【段①】HS1 右门 ShowLoadingUI=0
  SceneChangeDoor → LoadScene(blackFade:true)
    → Black FadeShow → 卸场 → 加载 Forest
    → InitPlayer: SetFollow(forceSnap)     // Forest.smoothTime=0.3 → 手推
    → hold mapTransitionBlackHoldSeconds≈0.3
    → CloseFormFade（不等 onComplete）    ★ 早揭幕
    → OnEnterScene：若 !homeDoorStoryComplete → CancelFollow + SetLock

【段②】Forest 右门 ShowLoadingUI=1
  → LoadSceneWithLoadingPanel → blackFade:false
    → Ready 即 OnBlackFadeEnd（无 hold）
    → InitPlayer: SetFollow；East.smoothTime=0 → 当帧对齐
    → Loading 假进度 2～3s 后淡出（揭幕在 Loading 层）
    → 首进：LeftDoorEnterStoryTrigger Enter → ForestEastSceneFirstEnter
         → 无 SetFollow/CameraMove；有 PlayerAutoMove → AutoMoveDestination≈+7.89x
```

1. **同源？**  
   - 段①：**是** Stairs 同源（手推+早揭幕）。
