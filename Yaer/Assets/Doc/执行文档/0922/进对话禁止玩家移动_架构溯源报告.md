> 日期：2026-09-22  
> 角色：架构侦探（**只读**，未改代码 / 场景 / Prefab）  
> Unity：2020.3.48f1  
> 现象：村·村长家门口三人戏（首句「奶奶。」）——**按住移动撞进对白后，对话期间人仍滑/走**  
> 产品钉死：**进对话立刻禁止玩家移动**（含松手前惯性/纵深）  
> 对白锚点：`Village_村长家门口初次对话` / `ChiefNearDoorStoryTrigger`  
> 提示词：`Assets/Doc/提示词/0922/进对话禁止玩家移动_架构侦探提示词.md`

## ① 结论一句话

**公共进故事路径会调 `PauseGameHandle`/`StopMove`，但村里位移真源是 `TownPlayerLocomotion`，它只认 `AllowControl`（对话中仍为 true），且 0922 键族的村意图读键走了裸 `Input.GetKey`，绕过 `cantMove`。**  
`StopMove` **清不掉** `depthVelocity`（组件注释已写明）→ 按住横/纵/斜进门口对白后，Town FixedUpdate **继续积分并写平面速**，人在对话框下还在动。  
推荐 **方案 B（主）+ A（进故事当帧清零）+ C（村意图尊重 cantMove）**；**否决**只改门口 Trigger、否决减速冒充停步。影响面：凡 `Village2_5D` + `onStoryTriggered` 的对白一并受益。

## ② 复现矩阵（代码推演；Play 验收前）

| 操作 | 对话中是否位移？ | 位移方向 | 备注 |
|------|------------------|----------|------|
| 静止靠近触发门口对白 | **推演：否** | — | 基线；无速度可积 |
| **按住右/左** 撞触发 | **是** | 横 | `IsBoundCommandKeyHeld` 裸 GetKey → Town 写 vx |
| **按住上/下（纵深）** 撞触发 | **是** | 前后（世界 Y） | `GetVillageExploreVerticalSign` 裸 W/S；**StopMove 不清 depthVelocity** |
| 斜向按住撞触发 | **是** | 斜 | 归一仍写横+纵深 |
| 触发后立刻松键 | **可能短滑一截** | 同进门方向 | 若进故事未清 `depthVelocity`/vx，松键后 Town 才清纵深 |
| 对话中再按键 | **是** | 按住方向 | 意图仍灌入 Town |
| 非村场景普通对白按住走 | **推演：否/弱** | — | 无 Town；Combat 吃 `cantMove`+StopMove 较有效 |

触发后应见：`hasInStoryEventState=true`、`cantMove=true`，但 `AllowControl=true`、`depthVelocity` 与 Town FixedUpdate **仍可非零**。

## ④ 方案对比与推荐

| 方案 | 做法 | 何时选 | 裁决 |
|------|------|--------|------|
| **A** | `StoryTriggeredHandle`：StopMove + **Town 清 depthVelocity / 写横 0 / rb.velocity=0**（可抽 `HaltVillageLocomotionForStory`） | 进故事当帧刹住惯性 | **必做** |
| **B** | Town `OnFixedUpdate` 首行：`hasInStoryEventState \|\| cantMove` → 清速度并 return | 对话中持续按住仍不走 | **主修** |
| **C** | 村意图 `GetVillageExplore*` / `IsBoundCommandKeyHeld` 尊重 `cantMove`（或走包装 GetKey） | 输入层不再灌 Town | **推荐同做**（键族不回退） |
| **D** | 仅门口 Trigger 停步 | 其它村对白仍漏 | **否决唯一交付** |
| **E** | 加大摩擦慢慢停 | 产品要禁止移动 | **否决** |

### 必答

1. **主因**：Town 在对话中仍积分；村读键绕过 `cantMove`；`StopMove` 不清 `depthVelocity`。  
2. **推荐**：**B + A + C**（最小集中 `TownPlayerLocomotion` + `PlayerLogic.StoryTriggeredHandle` + `PlayerInputComponent` 村意图）。  
3. **验收**：按住横/纵/斜撞门口对白 → 人立刻停死；对话中再按无位移；键族单通道仍成立。

## ⑦ 风险与回滚

| 风险 | 处置 |
|------|------|
| 键族回归 | C 只加 `cantMove` 门闩，不恢复 Axis/双族 |
| 锁区 / CanNotSomeActionArea | 已 SetAllowMove(false)；B 与之一致 |
| 战斗 Default 模式 | Town `enabled=false`；B 不伤战斗；C 仅村意图函数 |
| 对话中需 AutoMove | 若有剧情推人，须白名单或临时清 `hasInStoryEventState` 外路径——现网门口无此需求 |
| 只做 A 不做 B | 当帧刹住后按住键下一帧又走 | 必须 B |

**回滚**：还原三处门闩/Halt；保留 0922 键族推导。
