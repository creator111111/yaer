# 游戏左下角版本号 1.0.5 · 架构溯源报告

> 日期：2026-09-22  
> 角色：架构侦探（短核对；**本阶段未改工程**）  
> Unity：2020.3.48f1  
> 产品钉死：画面**左下角**常驻 **`1.0.5`**（主菜单 + 局内）  
> 提示词：`Assets/Doc/提示词/0922/游戏左下角版本号1.0.5_施工提示词.md`

---

## ① 结论一句话

**选方案 A**：新建极简常驻 UI Form（`VersionPanel`），挂 **`EUIGroup.System`**，文案读 **`Application.version`**，并把 `ProjectSettings.bundleVersion` **`0.1` → `1.0.5`**。必须处理 **`CloseAllUIForm` 会关掉 System 组**（换场/读档/回主菜单只留黑幕）——开局打开后，**每次 `CloseAllUIForm` 后 Ensure 重开或把 Version 加入 filter**，禁止方案 B（只挂 StartScene）。文案默认纯 **`1.0.5`**（无 `v` 前缀规范）。

---

## ② 现网核对

| 项 | 现网 |
|----|------|
| 已有 VersionLabel / 常驻版本 Form | **无**（Grep 无业务版本 UI） |
| `bundleVersion` | `ProjectSettings/ProjectSettings.asset` → **`0.1`** |
| `Application.version` / `DefaultVersionHelper.GameVersion` | 同源读 `Application.version`（即 bundleVersion） |
| UI 组深度（`InitScene`） | Bottom **0** / Middle **100** / Top **200** / System **300** |
| 主菜单 | `OpenMainMenu` → `StartPanel` @ **Bottom** |
| 黑幕 | `BlackPanel` @ **System**；`CloseAllUIForm(black)` 关**除黑幕外全部** |
| 战斗左下 | `FightingPanel` @ **Bottom**（血条/头像占左下） |

**无 UI 规范**要求 `v`/`Ver.` → 显示字符串 = **`Application.version`**（施工后即 `1.0.5`）。

---

## ③ 方案对比

| 方案 | 做法 | 裁决 |
|------|------|------|
| **A** | 新 `VersionPanel` Form + System 组；`bundleVersion=1.0.5`；文案=`Application.version`；抗 `CloseAllUIForm` | **推荐** |
| **B** | 只在 StartScene / StartPanel 摆死字 | **否决**（进局消失） |
| **C** | 塞进 FightingPanel / MenuPanel | **否决**（关 HUD/开菜单易藏；主菜单无 Fighting） |

### 方案 A 挂点（施工钉死）

| 项 | 值 |
|----|-----|
| Prefab | `Assets/GameRes/Prefabs/UI/VersionPanel.prefab`（新建） |
| 路径常量 | `UIPrefabPath.GetUIPrefabPath("VersionPanel")` |
| Logic | `VersionFormLogic : BaseUIFormLogic` — `OnOpen` 设 TMP=`Application.version` |
| UI 组 | **`EUIGroup.System`**（depth 300，换场后组仍在；高于 Menu/对话） |
| 锚点 | 左下 `(0,0)` + 安全边距约 **12～24px**；小字、低对比 |
| Raycast | Image/TMP **Raycast Target = false**（不挡菜单/对话/地图） |
| 打开时机 | 进主菜单前或 `OpenMainMenu` 时 `EnsureVersionForm()`；**幂等**（已开则不再 `Open`） |
| 抗清屏 | `CloseAllUIForm` 后调用同一 Ensure；或 `CloseAllUIForm` **永久 filter** Version 实例 |

**替代（次选）**：挂 `UIComponentGM` 下非 Form 的 DontDestroy Canvas——绕过 CloseAll，但偏离现网 Form 管线，优先不采用。

### 与战斗左下 HUD

村内常无 FightingPanel，左下空；战斗场景血条也在左下。施工：**极小字贴最角**；System 叠在 HUD 之上可接受（水印级）；勿做大块挡血条点击（已关 Raycast）。

### 黑幕

全屏 `BlackPanel`（同 System）盖住版本号属可接受；揭幕后 Ensure 后仍在。

## ⑥ 风险与回滚

| 风险 | 处置 |
|------|------|
| `CloseAllUIForm` 清掉版本 | Ensure / filter（必做） |
| 每换场再 Open 叠多份 | GetUIForm 判空再开 |
| 挡点击 | Raycast 全关 |
| 只改文档不改显示 | 禁止；须运行时 Form + bundleVersion |
| 改存档/关于页 | 禁止 |

**回滚**：删 VersionPanel、还原 `bundleVersion: 0.1`、去掉 Ensure 调用。
