# 精灵战士 NPC — 对白台本（执行说明）

**用途**：村内 **精灵战士 npc** 交互对白，按**游戏内日期是否满 15 日**分两版，录入 CSV 或做对话 prefab。  
**角色**：战士（精灵战士）、雅（雅尔）  
**分支**：
- **§1** — **15 日之前**触发
- **§1.2** — **15 日及之后**触发

**FaceType（单列）**：与 NodeCanvas `SayEx` → `DialogueFaceType` 一致；导入 CSV 时对应 **`Face` 列**。详见 `对话立绘表情与图片名称对照_执行说明.md`。

| 注意 | 说明 |
|------|------|
| 雅尔 | **勿用 `Normal`**；CSV Speaker 写 **`雅`**，映射为 **`雅尔`** |
| 精灵战士 | **当前工程无专用 `DialogueRoleName` 与立绘图集**（策划图仅标注「精灵战士npc」）；FaceType 先按长图标注，施工时补 Actor |
| 两分支 | **15 日前 / 15 日后为两套 prefab 或两套 CSV**，触发器按日期分支，勿混在同一 Graph |

### 附录：本段涉及 FaceType

**雅尔**：`Surprised` `VerySurprised` `Daze` `Unhappy` 等（见对照文档 §3.1）

**精灵战士（图集待建）**：`Normal` `Angry` 等（长图未给细表情，可按台词语气暂定）

## 3. 资源与触发（简版）

| 项 | 15 日前（§1） | 15 日后（§1.2） |
|----|---------------|-----------------|
| 建议 prefab | `Village_ElfWarrior_BeforeDay15` | `Village_ElfWarrior_AfterDay15` |
| 触发条件 | 游戏日 **&lt; 15**（或等价存档字段，与关卡统一） | 游戏日 **≥ 15** |
| 调用 | `StoryComponentGSM.TriggerStory(...)` | 同上 |
| NPC | 场景内 **精灵战士 npc** 交互体 | 同一 NPC，触发器内分支 |

**存放路径**：`Assets/GameRes/Prefabs/Dialogue/` **根目录**

**实现提示**：`SimpleStoryTrigger` 单挂一个 prefab 时无法按日分支；需 **脚本判断日期** 后 `TriggerStory` 不同名，或两个 Trigger 互斥启用。

---

## 4. 制作步骤

1. §1、§1.2 **各导出一份 CSV**。  
2. 补 Speaker 映射 `战士→精灵战士` 后 Import CSV。  
3. 绑定雅尔 / 精灵战士 Actor；战士立绘未就绪时可先字幕验收。  
4. 按日期切换触发逻辑，DialogDebug / 村内验收两版各播一遍。
