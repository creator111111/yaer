# 商店老板娘 — 特殊交互对白台本（执行说明）

**用途**：村内商店场景，玩家点击老板娘**不同部位**触发的短对话，录入 CSV 或做对话 prefab。  
**角色**：店（商店老板娘）、雅（雅尔）  
**交互分支**：
- **§1** — 点击**头部**（货币争执）
- **§1.2** — 点击**胸部**（特殊服务 → 黑屏转场 → 树屋后续）

**FaceType（单列）**：与 NodeCanvas `SayEx` → `DialogueFaceType`、图集子图名一致；**本表每行只填当前说话人**那一格，导入 CSV 时对应 **`Face` 列**。详见 `对话立绘表情与图片名称对照_执行说明.md`。

| 注意 | 说明 |
|------|------|
| 雅尔 | **勿用 `Normal`**（`Avatar_Yaer_*` 无此键） |
| 老板娘 | **当前工程无「老板娘」`DialogueRoleName` 与立绘图集**；下表 `FaceType` 按策划长图标注，施工时需新增 Actor / 图集或暂用占位 |
| 策划改稿 | §1 序号 1 **以红笔改稿为准**（见 §1 注释），勿用划掉的旧句 |
| 两分支 | **头部 / 胸部为独立 prefab 或独立 CSV**，勿混在同一触发器 |

### 附录：本段涉及 FaceType（填表校验用）

**雅尔（9 种）**：`VerySurprised` `Surprised` `Daze` `Laugh` `Smile` `Unhappy` `Sad` `Smug` `ChiBie`

**老板娘（策划图意图，图集待建）**：`Smile` `Laugh` `Surprised` `Angry` 等，为独立角色图集（非古莎）

## 3. 资源与触发（简版）

| 项 | 点击头部（§1） | 点击胸部（§1.2） |
|----|----------------|------------------|
| 建议 prefab | `Village_ShopKeeper_HeadClick` | `Village_ShopKeeper_ChestClick` |
| 触发 Collider | 老板娘**头部** hitbox | 老板娘**胸部** hitbox |
| 调用 | `StoryComponentGSM.TriggerStory(...)` | 同上 |
| 转场 | 无 | C6 黑屏后进入树屋；需 `LoadScene` / 室内定位或第二段 Story |

**存放路径**：`Assets/GameRes/Prefabs/Dialogue/` **根目录**

**互斥建议**：同一帧勿同时触发头/胸；两 Collider 分区明确，避免重复 `HasRunningStory`。

---

## 4. 制作步骤

1. §1、§1.2 **各导出一份 CSV**（或两个 prefab 各一份）。  
2. 确认 Speaker 映射含 `店→老板娘` 后 Import CSV。  
3. 胸部线 C6 在 NodeCanvas 用 **ActionNode**（黑幕 + 切场景/切镜头），C7～C8 在树屋 Graph 或链式 `TriggerStoryActionTask`。  
4. 商店场景挂**两个**独立触发器，DialogDebug / 村内验收。
