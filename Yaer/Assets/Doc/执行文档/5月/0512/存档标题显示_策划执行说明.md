# 存档列表标题 — 策划执行说明

**用途**：改「读取存档 / 存档位」上类似 `序章：龙城郊`、`序章：拉普路西` 的**显示文案**（不改玩法、不改场景资源名）。

---

## 1. 先记住这一句话

列表上的整句 = **章节前缀**（如「序章」）+ **：** + **地点显示名**。

- **地点显示名**：由程序里的「地点内部键」查表得到（中 / 英 / 日各一张表）。
- **地点内部键**：玩家**最后一次保存时所在场景**写入存档；进入某场景时由对应场景管理脚本更新。

---

## 2. `Village_KenMuNi1` 里改哪个物体？（Hierarchy / SceneManager）

**结论（当前工程）**：**不能**靠改场景里某个 GameObject 的名字或 Inspector 字段，单独「自定义本场景的存档标题」。存档上的地名**不读**场景物体名，也**没有**挂在 `SceneManager` 上的「存档显示名」配置项。

以 **`Village_KenMuNi1`** 为例，Hierarchy 根下常见的 **`SceneManager`** 物体上挂的是脚本 **`ForestSceneManager`**（与 `ForestScene` 等共用同一套场景管理逻辑）。该脚本在初始化里**写死**调用 `SetNowPlace(PlaceName.HomeToJingLingVillage)`，也就是把「当前地点」设为内部键 `HomeToJingLingVillage`。玩家在本场景**保存**后，读档列表里地名部分会按这个键去 **`PlaceName.cs` 字典**里取「龙城郊」等文案。

你在 **`SceneManager`** 上能看到的 **`config`**（`GameSceneManagerConfig`）、**`EnterPosConfig`**（从哪个场景进来落在哪里）、**`canShowSaveGame`** 等，管的是**流程与是否允许存档**，**不是**存档列表那一行标题的文案来源。

| 你想做的事 | 在 `Village_KenMuNi1` 里改物体？ | 实际做法 |
|------------|----------------------------------|-----------|
| 把「龙城郊」三个字改成别的（但仍表示同一条「家→精灵村郊」逻辑） | 改 `SceneManager` / `Map` 名字**无效** | 改 `PlaceName.cs` 里 **`HomeToJingLingVillage`** 对应的中 / 英 / 日 **value**（见下文 §3） |
| 希望「肯姆尼村」和「龙城郊」在存档里显示成**两个不同名字** | 单靠场景里摆物体**做不到** | 需要程序：为本场景单独写（或分支）`SetNowPlace(新键)`，并在 `PlaceName` 里注册新键的三语文案；策划提供文案即可 |

**替代方案说明**：若坚持「配置驱动、策划只在 Unity 里填表不改脚本」，需要程序另做 **ScriptableObject / Excel** 等配置，再在场景 Manager 里读取；**现状没有这条链路**。

---

## 3. 想改「龙城郊」「拉普路西」这种地名 — 策划可直接改表

1. 用 Unity 关联的编辑器（Visual Studio / Rider 等）打开脚本：  
   `Assets/Scripts/Game/Static/Enum/Map/PlaceName.cs`
2. 文件里有三块字典（同一行里的**键 key 不要改**，只改**值 value** 的引号内文字）：
   - `PlaceChsName` → 简体中文界面用的显示名  
   - `PlaceChsName_en` → 英文  
   - `PlaceChsName_jp` → 日文  
3. 例如「龙城郊」对应键是 `HomeToJingLingVillage` 那一行；「拉普路西」对应键是 `WestRappRoad`（在表里写作 `SceneName.WestRappRoad`，本质仍是同一个内部键）。
4. 保存脚本后回到 Unity 等编译通过，**新存一档**或在已有进度下再保存一次，读档界面会按**当前语言**显示新文案。

**若只改中文**：至少改 `PlaceChsName`；英 / 日不改则外文界面仍是旧词。

---

## 4. 想改「序章」这两个字 — 另一处脚本

打开：  
`Assets/Scripts/Game/GameRuntime/UI/FormLogic/Archive/Control/ButtonArchive.cs`

找到字典 **`textConfig_2`**（约 53 行附近），里面有中 / 英 / 日三条「序章 / Prologue / 序章」——改这里即可改前缀。**改完同样等编译、再存读档验证。**

---

## 5. 新场景也要出现在存档标题里 — 需要程序配合

当前逻辑是：**先有内部键** → **进入场景时写入「当前地点」** → **保存时写入存档** → **读档 UI 用键去 `PlaceName` 表里取显示名**。

因此「从没出现过的地点」不能只靠策划改表完成，还需要程序：

1. 在 `PlaceName.cs`（或 `SceneName` 等）增加**新键**与三语言显示行；  
2. 在对应场景的 `*SceneManager` / `*SceneMgr` 里调用 `SetNowPlace(该键)`（与现有 `HomeScene1Manager`、`ForestSceneManager`、`WestRappRoadSceneMgr` 等写法一致）。

策划可把**内部键命名建议**和**中 / 英 / 日三语文案**整理成表交给程序一次性接入。

---

## 6. 自己怎么验收

1. 在游戏中走到目标场景（或已有该进度的存档）。  
2. **保存**（新档或覆盖）。  
3. 打开读取存档界面，看标题是否变为预期文案；切换游戏语言可核对英 / 日。

---

## 7. 逻辑溯源（给对齐用，可跳过）

| 环节 | 说明 |
|------|------|
| 谁写入存档里的「地点键」 | `ArchiveComponentGM` 保存时用 `PlayerMapData.GetNowPlace()` 写入 `ArchiveInfo.currentSceneName`。 |
| 谁更新「当前地点」 | 各场景管理器里 `PlayerHandlerComponentGSM.SetNowPlace(...)`（如家、森林东西郊、拉普路西等）。 |
| 谁显示在 UI 上 | `LoadGameFormLogic` 调 `ButtonArchive.UpdateInfo`；标题里地名来自 `PlaceName.GetPlaceChsName(sceneName)`（函数名带 Chs，实际会按当前游戏语言选表）。 |
