> 日期：2026-09-23  
> 角色：架构侦探（**只读**，未改代码 / 场景 / Prefab）  
> Unity：2020.3.48f1  
> 现象：点货栏**长条有响应**、点右边**数字框没响应**；产品要两处都进入数量输入，且进入时**先清空（含 0）**  
> 场景：`Village_Shop` · 购买 Tab · `Shop_Bar`  
> 提示词：`Assets/Doc/提示词/0923/商店货栏点击进输入并清空_架构侦探提示词.md`  
> 范围：**只改本交互**；总价/Tab 高亮整修另票

## ① 结论一句话

**长条「有响应」= 行根 `Button` SpriteSwap，整修 R0 后已不再 `ActivateInputField`，故未进入输入、更未清空。**  
**数字框「没响应」= 可见的是 DigitStrip；`MakeQuantityClicksHitInput` 关掉子图射线后，点在数字图上的点击常**穿透到背后整行 Button**，TMP 吃不到第一次点击。**  

最小修：**统一入口 `BeginQuantityEdit()`**（清空 TMP+DigitStrip → `Select`/`ActivateInputField`），长条与数字框都调它；数字框用**盖住 Number 的可点热区**（Input 根 Image 全铺 / 或 Number 上接收 Pointer 再转交），禁止再 `transition=None`、禁止 Validate+`\0`、禁止动联合钳制公式。

产品改口：进入输入用**清空**，取代现网 K1「全选仍显示 0」。

## ④ 必答

1. **数字框无响应直接原因**：可见 DigitStrip `raycastTarget=false` → 点击落到**整行 Button**；TMP 未 Activate。次因：Number 热区小（≈47×34），与「点在数字上」体感不一致。  
2. **长条点击**：仅 SpriteSwap「有响应」，**没有**进输入、**没有**清空。  
3. **最小改**：行上统一 `BeginQuantityEdit()` = 清空 + Activate；  
   - 长条：`Button.onClick` 或行级 `IPointerClick`（**勿**改 `transition=None`）→ `BeginQuantityEdit`；  
   - 数字框：保证 Number 全矩形可点（Input `targetGraphic` 全铺 Number，或 Number 收 Pointer 再转交），避免穿透到 Button。  
4. **清空显示**：`SetTextWithoutNotify("")` + `SyncNumberDigitDisplay` → `HideAllDigits`（空串）；**失焦空串 → Parse→0 写回**（与现网 `OnQuantityEndEdit` 一致，可接受）。清空时勿立刻走「空串又钳回 0 显示」：用 WithoutNotify，或聚焦中空串跳过写回 0（仅失焦再 0）。

## ⑤ 方案对比

| 方案 | 做法 | 裁决 |
|------|------|------|
| **A** | `BeginQuantityEdit()`：清空+Activate；长条 onClick、数字框可点热区 | **主推** |
| **B** | 只扩 Input 热区、长条仍不进输入 | **否**（产品两点都要） |
| **C** | 恢复整行 Pointer+手搓高亮 | **否**（整修刚否决） |
| **D** | 继续 SelectAll 留 0 | **否**（产品要清空含 0） |

**覆盖关系**：本期清空后首键即新数字，**取代**「全选 0 再覆盖」的观感；可不关 `onFocusSelectAll`，但 `onSelect` 应改为清空优先，避免又刷回全选 0。
