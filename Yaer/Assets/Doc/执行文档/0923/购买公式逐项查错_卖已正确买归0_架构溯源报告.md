### 手算 vs 日志

```
min( (gold - otherCost) / price , max(0, MaxStack - held) )
= min( (800 - 0) / 200 , max(0, 10 - 10) )
= min( 4 , 0 )
= 0
```

**等于**日志 `max=0`。无提前错 return（price>0、非 bypass 早退堆叠-only）。
