# 商店数量点击全选覆盖输入 · 架构溯源报告

> 日期：2026-09-23  
> 角色：架构侦探（**只读**，未改代码 / 场景 / Prefab）  
> Unity：2020.3.48f1 · TextMeshPro  
> 现象：点数量框后输入像在旧数字**末尾累加**（例 `5`→`53`）；产品要**点击全选 + 覆盖输入**；**0922 购买联合上限钳制必须保留**  
> 场景 / UI：`Village_Shop` · 买卖行右侧数量（隐形 TMP + DigitStrip）  
> 提示词：`Assets/Doc/提示词/0923/商店数量点击全选覆盖输入_架构侦探提示词.md`

---

## ① 结论一句话

**累加主因是「逻辑上未稳定保持全选」→ 光标落在串尾 → 数字键追加；不是钳制公式算错。**  

磁盘 `Village_Shop` / `ShopPanel` 已有 `m_OnFocusSelectAll: 1`，但：

1. **鼠标点选**常在聚焦后再把 caret 点到点击处（隐形字区多落在**末尾**），冲掉全选 → 首键变成追加；  
2. **0830** 把 `selectionColor` alpha 关死 → 即使得选也**看不见**，体感像「隐形光标在末尾」；  
3. Helper **运行时从不显式写** `onFocusSelectAll`（Ensure 新建框时可能默认 false）；  
4. 0922 **边输边钳**写回 `SetTextWithoutNotify` 会清选区，若未再 SelectAll，后续键仍易追加——次因，勿当关钳借口。

**0922 联合钳制公式不动**（买=`min((gold−其它行)/price, stackRoom)`；卖=持有；`ReclampAllBuyRowsForJointGold` 保留）。只动聚焦/全选交互。

推荐：Helper **强制** `onFocusSelectAll=true` + 行组件 **点选/选中后补 SelectAll**（含一帧延迟挡鼠标清选）；caret/selection **可保持全透明**（仅逻辑全选）；可选 DigitStrip 聚焦轻态。禁止关钳制、禁止加减钮当主交付。

## ③ 调用链与对拍

### 数量框结构

```
Shop_Bar → ShopBuyRowQuantityInput
  → TMP_InputField（字/caret/selection 全透明）
  → DigitStrip 图片数字（玩家看见的）
```

### 隐形样式（0830，现网）

```68:101:Assets/Scripts/Game/GameRuntime/UI/FormLogic/Shop/ShopQuantityInputHelper.cs
        // caretWidth=0、blink=0、selectionColor.a=0
        // ❌ 未设置 onFocusSelectAll
```

注释已写：关 selection 蓝块是为消「闪一下」——**副作用是全选无视觉**，难辨是否选中。

### 磁盘 vs 运行时

| 项 | Prefab/场景 | Helper 运行时 |
|----|-------------|---------------|
| `m_OnFocusSelectAll` | **1**（已有） | **不写**；Ensure 新建可能漏 |
| caret / selection 透明 | 盘上旧值可能仍宽/蓝 | Bind 时 Apply 覆盖为 0 |
| 钳制 | — | 行 `TryClamp` + Form 联合 max |

故「盘上勾了全选」≠「鼠标点完仍全选」。

### 钳制（须保留，非累加主因）

```
onValueChanged → TryClampQuantityToBusinessMax
  → ApplyQuantityText (SetTextWithoutNotify) → 清选区/caret 常到末尾
Form：ResolveBuyMaxQuantity 联合金币；改数量 → ReclampAllBuyRowsForJointGold
```

钳制负责「超购买力立刻调回」；**关掉会破坏「决定不因超钱包失败」**。累加应靠全选覆盖，不靠关钳。

### 必答

1. **累加主因**：未稳定全选（鼠标清选 + 无可见选区反馈）；钳制写回是次因加剧。  
2. **最小挂点**：`ShopQuantityInputHelper` 强制 `onFocusSelectAll=true`；`ShopBuyRowQuantityInput` 在 `onSelect` / PointerClick 后 **SelectAll 补刀**（建议 `WaitForEndOfFrame` 一次）。`ShopFormLogic` **不改公式**。  
3. **透明全选**：可以——逻辑全选即可覆盖输入；不必恢复闪烁 caret（0830）。若要反馈，优先 DigitStrip 聚焦色，而非粗蓝 selection。  
4. **0922**：公式与回扫文件语义**不动**；仅交互层。

## ④ 方案对比

| 方案 | 做法 | 裁决 |
|------|------|------|
| **A** | `onFocusSelectAll=true` + 点选后补 `SelectAll`（可延一帧） | **主推** |
| **B** | 首键若未选中则清空再写入（自定义 Input） | 备；易与 TMP/钳制打架 |
| **C** | 恢复可见 selection/caret | 可选轻反馈；勿当唯一修；防 0830 闪烁回潮 |
| **D** | 关联合钳制「好输入」 | **否决** |
| **E** | 加减按钮 | **否决**（产品要键盘覆盖） |

**A 实现要点**

- `ApplyInvisibleInputTextStyle` 或 `ApplyIntegerInputSettings`：`inputField.onFocusSelectAll = true`。  
- 行：`quantityInput.onSelect` / `IPointerClickHandler` →  
  `selectionAnchorPosition = 0; selectionFocusPosition = text.Length`（或 TMP 等价 API）。  
- 钳制写回后若仍聚焦：可选再 SelectAll，使「9→钳成1」后继续键仍覆盖。  
- 不改 `ResolveBuyMaxQuantity` / `ReclampAllBuyRowsForJointGold`。
