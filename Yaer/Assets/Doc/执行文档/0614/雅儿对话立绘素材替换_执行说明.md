# 雅儿对话立绘 — 素材替换执行说明

**模式**：架构侦探（只读溯源，不改代码）  
**调查日期**：2026-06-14  
**关联详表**：`Assets/Doc/执行文档/0601/对话立绘表情与图片名称对照_执行说明.md`

---

## ① 结论（一句话）

雅儿在对话里其实有 **两套图**：**字幕条小头像**（换 PNG + 打图集）和 **屏幕大立绘**（改 **`GoOutStoryYaerPainting`** 或 **`YaerPainting`** 预制体里的图）。村线、埃吉尔任务等当前主线对话，大立绘统一看 **`GoOutStoryYaerPainting.prefab`**。

---

## ② 先分清你要换哪一种

| 你在游戏里看到的位置 | 叫什么 | 要不要开对话 Prefab | 主要改哪里 |
|----------------------|--------|---------------------|------------|
| 字幕条左侧圆形/方形小头像 | **小头像（Avatar）** | 不用 | `ArtRes/.../Yaer/Avatar/` 的 PNG + 四个 `Avatar_Yaer_*.spriteatlas` |
| 对话时屏幕上的半身/全身大图 | **大立绘（Painting）** | 不用逐个改；改**立绘母预制体**即可 | 见下文 §4 |

**生活类比**：小头像像聊天软件头像；大立绘像视觉小说立绘。换图路径完全不同。

---

## ③ 小头像（Avatar）— 换图路径

### 3.1 源图放哪里

四套服装，路径模板：

```
Assets/ArtRes/UI/Story/DialogueForm/Yaer/Avatar/{服装文件夹}/{表情英文名}.png
```

| 服装文件夹 `Avatar/` 下 | 对应图集 | 存档条件（衣服 / 头饰） |
|-------------------------|----------|-------------------------|
| `Dress` | `Avatar_Yaer_Dress_Crown.spriteatlas` | 连衣裙 + 皇冠（**默认**） |
| `ArmorNone` | `Avatar_Yaer_Armor_NoHeadWear.spriteatlas` | 铠甲 + 无头饰 |
| `ArmorCrown` | `Avatar_Yaer_Armor_Crown.spriteatlas` | 铠甲 + 皇冠 |
| `Armor` | `Avatar_Yaer_Armor_ArmorHead.spriteatlas` | 铠甲 + 护头盔 |

图集文件目录：

```
Assets/GameRes/Atlas/Avatar/Avatar_Yaer_*.spriteatlas
```

### 3.2 文件名必须和「表情枚举」一致

程序用 `表情英文名` 当钥匙取图，**文件名、图集子图名、NodeCanvas 里选的 Face Type 必须完全一致**。

雅儿每套服装 **9 张**，固定如下：

| PNG / 枚举名 | 中文 |
|--------------|------|
| `VerySurprised` | 惊愕 |
| `Daze` | 呆滞 |
| `Laugh` | 笑 |
| `ChiBie` | 吃瘪 |
| `Unhappy` | 不高兴 |
| `Sad` | 苦闷 |
| `Smug` | 得意 |
| `Smile` | 微笑 |
| `Surprised` | 惊讶 |

> 没有 `Normal.png`；台本里若写 Normal，小头像可能空白。

### 3.3 操作步骤（小头像）

1. 用同名 PNG **覆盖** 对应 `Avatar/{服装}/` 下的文件（或先导出再按上表命名）。
2. Unity 中打开对应 `Avatar_Yaer_*.spriteatlas` → **Pack Preview**（或 Build）。
3. 不用改任何对话 Prefab；所有引用雅儿的对话会自动用新图。

### 3.4 可选：从 Face 文件夹整理源稿

美术常把带中文名的稿放在：

```
Assets/ArtRes/UI/Story/DialogueForm/Yaer/Face/{Dress|ArmorNone|ArmorCrown|Armor}/
```

例如 `0_0007_微笑.png` → 导出为 `Avatar/Dress/Smile.png`。对照表见 0601 文档 §3.2。

## ④ 大立绘（Painting）— 该开哪个预制体

大立绘不是散落在每个对话里各配一套图，而是 **嵌套「立绘母预制体」**。改母预制体后，所有引用它的对话一起更新。

### 4.1 村线 / 出村 / 埃吉尔任务（**最常用**）

| 项 | 路径 |
|----|------|
| **立绘母预制体（改这个）** | `Assets/Prefabs/DialougeProtrait/GoOutStoryYaerPainting.prefab` |
| 脚本 | `GoOutStoryYaerPainting.cs`（村线默认铠无头饰表情键） |

**嵌套位置**（对话 Prefab 内，无需逐个打开换图）：

```
某对话 Prefab（如 Village_KenMuNiStart）
└── Yaer（DialogueActorEx）
    └── GoOutStoryYaerPainting   ← 嵌套的母预制体实例
```

**当前使用此立绘的对话 Prefab 示例**（不全列）：

- `Village_KenMuNiStart.prefab`
- `Village_KenMuNiStar_Test.prefab`
- `Village_Aegir_QuestOffer.prefab`
- `Village_Aegir_QuestTurnIn.prefab`
- `Village_Leader‌GuShaAmyAliy.prefab`
- `WestRappRoadGoblinAndGusha.prefab`
- `HomeScene1GoOutStory.prefab` 等

**预制体内部结构**：

```
GoOutStoryYaerPainting
├── Clothes
│   └── ArmorNone          ← 身体底图（Image）
├── Heads
│   ├── ArmorHead          ← 护头盔层（按存档开关）
│   └── ArmorCrown         ← 皇冠层（按存档开关）
└── Faces                  ← 9 个表情子节点，同时只显示一个
    ├── Armor_NoHeadWear_Smile
    ├── Armor_NoHeadWear_Laugh
    ├── Armor_NoHeadWear_Surprised
    ├── Armor_NoHeadWear_VerySurprised
    ├── Armor_NoHeadWear_Daze
    ├── Armor_NoHeadWear_ChiBie
    ├── Armor_NoHeadWear_Unhappy
    ├── Armor_NoHeadWear_Sad
    └── Armor_NoHeadWear_Smug
```

**子节点名 = 程序切换表情的键**（`Armor_NoHeadWear_` + 表情枚举）。**不要改节点名**，只换每个子物体上 `Image → Source Image` 的图。

**图源现状**：工程里大立绘 Image 多直接引用 `Face/` 下带中文名的 PNG（如 `Face/Dress/0_0007_微笑.png`），与 `Avatar/` 下英文名 PNG 是两套文件。

### 4.2 新游戏开场（连衣裙 + 皇冠全身层）

| 项 | 路径 |
|----|------|
| **立绘母预制体** | `Assets/Prefabs/DialougeProtrait/YaerPainting.prefab` |
| 使用处 | `NewGameStory.prefab` 内 `Yaer` 下嵌套的 `YaerPainting` |

**Faces 下节点名格式**：`Dress_Crown_{表情}`（如 `Dress_Crown_Smile`）。  
`Clothes/Dress` 下有连衣裙分层（身体、衣服、鞋等 Image）。

另有 `Assets/GameRes/Prefabs/UI/Painting/YaerNewGamePainting.prefab`（`NewGameYaerPainting` 脚本），逻辑与 `Dress_Crown_*` 键一致，用于新游戏相关 UI。

### 4.3 不要和「关卡插画」混用

```
Assets/ArtRes/Painting/Yaer/Armor.png / Dress.png 等
```

这是 **过场/宣传全幅插画**，不是对话 UI 立绘，换对话图时不要改这里。

## ⑤ 推荐操作流程（大立绘）

### 方式 A：覆盖源 PNG（适合批量、不改 Prefab）

1. 在 `GoOutStoryYaerPainting.prefab` 里点开某个表情子节点，看 `Image` 当前引用的 PNG 路径。
2. 用新图 **覆盖同路径同名文件**（保持 guid 不变，Prefab 自动更新）。
3. 对 9 个表情重复；身体层改 `Clothes/ArmorNone`，头饰改 `Heads/` 下对应 Image。

### 方式 B：在母预制体里换引用（适合单张试看）

1. 打开 `Assets/Prefabs/DialougeProtrait/GoOutStoryYaerPainting.prefab`。
2. 展开 `Faces → Armor_NoHeadWear_Smile`（或其它表情）。
3. 在 `Image` 组件把 `Source Image` 拖成新 Sprite。
4. 保存 Prefab。所有嵌套该预制体的对话自动生效。

## ⑥ 验收清单

1. **小头像**：`DialogDebug.unity` 直接 Play → 拖 `Village_KenMuNiStart`（或任意村线对话）→ 看字幕条左侧雅儿头像是否更新、切表情是否正常。
2. **大立绘**：同场景看屏幕大立绘是否与头像表情一致切换。
3. **图集**：若只换了 `Avatar/` 但未 Pack 图集，小头像不会变——记得 Pack。
4. **节点名**：若大立绘某句台词切表情后 **整人消失**，多半是 Faces 下缺少对应 `Armor_NoHeadWear_{表情}` 节点或名写错。
