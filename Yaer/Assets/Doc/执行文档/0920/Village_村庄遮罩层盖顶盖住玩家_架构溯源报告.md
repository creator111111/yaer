## ③ 用户验收清单

1. Hierarchy：五个场景各有遮罩实例，名建议 `村庄遮罩_*`，与合层**并列**，不在合层子级里。  
2. 遮罩根 LocalPos 与合层根一致（表上坐标）。  
3. `背景` 子物体 **Inactive**；合层原样，无双影。  
4. 遮罩可见子层 SortingLayer = **Effect**，Order ≥ 0（建议 ≥10）。  
5. Play：走进窗光 / 树荫，角色被压暗盖住；退出亮区恢复。  
6. 倒树那套 SpriteMask / MaskInteraction **未出现**（本期是盖顶画）。  
7. 村长家、夜景场景无遮罩。

## ④ 给施工员

### 推荐方案（只此一种）

每个目标场景：

1. 拖入对应 `村庄遮罩/*.prefab`，父节点 = **合层的父节点**（民居 = `Map`；肯姆尼 = `Design`）。  
2. 根 Transform = 合层根（表上 XYZ）。  
3. 子物体 `背景` → **取消勾选**。  
4. 其余带 `SpriteRenderer` 的子物体：  
   - `Sorting Layer` = **Effect**（ID `3211182563` / YAML 有时写 `-1083784733`）  
   - `Order in Layer`：相对关系保留（1/2/3），整体抬到 **≥10**（例如 11/12/13），避免和现网 Effect 特效抢同 Order。  
5. `Mask Interaction` 保持 **None (0)**；材质保持 Sprites-Default。  
6. Z 保持 **0**（不要用 Prefab 里 PSD 的 2.5/5/7.5/10）。

肯姆尼三段各挂一份，互不合并。

### 为什么必须抬到 Effect（盖住玩家）

| | SortingLayer 索引 | Order |
|--|-------------------|-------|
| 玩家身体 | **Player (6)**，ID `-385201763` | `TownPlayerLocomotion`：`order = -round(Y×100)`，村里约可到数百～数千 |
| 合层常见前景 | SceneObject (8) | 场景覆盖 |
| 倒树遮罩样板 | **Effect (9)** | 0 |

Prefab 默认 **Default / 0～3** 画在玩家**后面**，盖不住人。Effect 整层在 Player / SceneObject **之上**，同层内再比 Order——所以抬到 Effect 后，不必去追玩家动态 Order。

本期是 **盖顶压暗**，禁止做成倒树那种 `SpriteMask` 裁切。

### 不要改

| 不要改 | 原因 |
|--------|------|
| 现网合层子物体 / Sorting / Sprite | 产品要求不动已有美术 |
| 遮罩 Prefab 源文件（ArtRes） | 场景实例上改 Sorting；源保持 Default 给美术 |
| `Player.prefab` 的 Sorting / depthSorting | 无关 |
| 夜景 Prefab / `Village_KenMuNi_night` | 禁止 |
| 合层 Prefab 源 | 禁止把遮罩嵌进去 |

### 否决

- 整 Prefab 原样丢进场景且开着 `背景`：双影。  
- 只改合层某层 Sprite 当遮罩：破坏现网合层。
