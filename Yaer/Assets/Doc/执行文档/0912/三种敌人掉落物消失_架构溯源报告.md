## 沟通摘要

### ① 结论一句话

三种怪确为 **Slime / TenWan / 常驻 WoodWorm**；掉落链（死亡动画事件 → `ShowDropItem` → 点击入包）**逻辑仍通**；「不见了」是 **世界掉落 Sprite 引用断了**：商店改中文 Icon 时删了英文名 `SlimeCore.png` / `TenWangFruit.png` / `InsectBeak.png`（旧 GUID），换了 `史莱姆核/藤蔓果/虫喙.png`（新 GUID），**背包 Database 已改、三怪 Prefab `dropItem` 未改** → `SetActive(true)` 后 Missing Sprite，看不见。三怪**同源**。

### ② 原因（通俗）

掉落物不是另画一张世界贴图，而是直接挂了背包用的道具 Icon。后来商店把 Icon 文件改成中文名并重新导入（GUID 全换），背包跟着新图走了，怪物脚下的掉落物还指着已经删掉的旧图，所以死后其实「刷出来了」，但屏幕上什么也看不到。

### ③ 用户需要做什么（检查清单）

| # | 操作 | 期望（现网未修） |
|---|------|------------------|
| 1 | Play：击杀常驻史莱姆 / 藤蔓 / 木虫（勿只用巢生木虫） | Hierarchy 里尸体下 `dropItem` 应变 `active=true` |
| 2 | 同刻看 Inspector → SpriteRenderer | Sprite = **Missing**（或空） |
| 3 | 若硬点碰撞体区域（不可见） | 距离≤4 时仍可能进包（Tips 横幅仍无，属注释） |
| 4 | 对照：虫巢蹦出的木虫 | 设计上 `hasDropItem=false`，不应掉 |
| 5 | 拍板后施工：三 Prefab 重绑中文 Icon GUID（或等价方案） | 死后可见可点，进包对应道具 |

## 2. 调用链（死亡 → 掉落 → 拾取）

```
HP=0 → BaseMonster.OnDead / 子类 ChangeState<*DeadState>
  → Dead.anim 末帧 AnimationEvent
       functionName: AnimaEventTrigger
       data: RemoveMonsterOnDead:{Slime|TenWan|WoodWorm}
  → AnimationEventComponent → BaseMonsterState.RemoveMonsterOnDead
  → BaseMonster.MonsterDeadEndEvent()
       ├─ hasDropItem==false → MonsterDelayRemove()（无掉落）
       └─ hasDropItem==true  → ShowDropItem() → dropItem.SetActive(true)
            + 尸体/掉落改 sortingLayer=Monster1

玩家点击 dropItem（DropItemSrc.Update）
  → Camera.main 世界坐标 + colliderObj.OverlapPoint
  → 与玩家 X 距 ≤4
  → AddMainItem(itemName)  // Tips OpenTipsForm 现网注释
  → 淡出 → RemoveDropItem → MonsterDelayRemove
```

**现网断点标注**：

| 环节 | 状态 |
|------|------|
| Dead.anim 事件 | ✅ 三怪均有 `RemoveMonsterOnDead:*` |
| `hasDropItem` Prefab | ✅ 均为 `1`（常驻） |
| `dropItem` 引用 | ✅ 非 null；默认 `m_IsActive: 0`（生前关，死后开） |
| `DropItemSrc.itemName` / `monsterLogic` | ✅ Slime/TenWan/WoodWorm 主 Prefab 齐；⚠️ `WoodWorm_1` 的 `monsterLogic={fileID:0}` |
| **Sprite** | ❌ 三 GUID **工程内无 owner `.meta`**（Missing） |
| Tips 横幅 | ℹ️ 注释掉；「没横幅」≠「没进包」 |

## 5. 修复方案对比

| 方案 | 做法 | 优点 | 风险 / 成本 | 推荐 |
|------|------|------|-------------|------|
| **A 重绑 Prefab Sprite（主推）** | 三怪 + `WoodWorm_1` 的 `dropItem` SpriteRenderer 改为现网中文 Icon GUID；`WoodWorm_1` 补 `monsterLogic` | 最小；对齐背包图；不改代码 | 世界掉落与 UI Icon 共用一张图（原本即如此） | ✅ **推荐** |
| **B 恢复旧英文 Icon 文件并保留旧 GUID** | 从 `c8d44392^` 检出 `SlimeCore.png` 等放回并恢复 meta guid | Prefab 零改 | 与商店中文命名规范冲突；双份 Icon 易再漂 | 备选 |
| **C 运行时 `ShowDropItem` 从 `MainItemDefProvider` 赋 Icon** | 代码按 `DropItemSrc.itemName` 拉 Sprite | 以后改 Database 自动同步 | 改代码面；需验对象池/时序 | 中长期可选 |
| **D 只开 Tips** | 解开 `OpenTipsForm` | 不解决「看不见」 | 偏离主诉 | ❌ 不单做 |

**验收标准（施工后）**

1. 三怪各击杀 ≥2 次：尸体旁 **可见** 掉落 Sprite。  
2. 走近点击：背包增加 `SlimeCore` / `TenWangFruit` / `InsectBeak`。  
3. WormEgg / 巢生木虫仍不掉。  
4. 已杀怪重进场景仍隐藏（存档设计）——写明即可。  
5. Tips 横幅：默认不要求；产品若要另开。

**施工注意**

- 只改 Sprite 引用（及可选 `WoodWorm_1.monsterLogic`）；**不要**新建掉落表。  
- 勿给 `TenWanSceneObj` / WormEgg / Root / Boss 生虫开 `hasDropItem`。  
- 改完在 Editor 确认 `dropItem` 无 Missing Sprite。
