## ① 结论（一句话）

**下一关已确认为肯姆尼村（`Village_KenMuNi1`）。同一次复现 Console 过滤 `MapSelect` 为空，说明既没有走过地图点选进村，也没有走过章末 `OpenMap` 的解锁日志——正常「章末 → 地图 → 点肯姆尼」整条链在当次 Play 里根本没跑。磁盘上能进村的 C# 入口几乎只剩 `MapFormLogic`（必打 `[MapSelect]`）与商店回村（打 `[VillageShopDebug]`）；因此当前现象更像「绕过章末/地图的未知换场，或 Editor 本地右门被临时改过」，而不是「地图误点 / 左门去东郊」。**

生活类比：你说人已经到了肯姆尼，但门禁刷卡记录（`MapSelect`）一张都没有——说明不是从「地图选关」那扇正规门进来的，得另查后门。

**日志语义（为何「空」很关键）**

`[MapSelect]` 不只挂在「点击进村」，章末开图解锁也会打：

| 日志原文（代码） | 何时出现 |
|------------------|----------|
| `[MapSelect] 序章/章末解锁关卡 place=…` | `ChapterEndFormLogic.UnlockChapterEndMapPlace`（`OpenMap` 内） |
| `[MapSelect] 延迟 SelectPlaceLight …` | 地图回调晚到时的排队高亮 |
| `[MapSelect] 点击 ButtonJingLingVillage → LoadScene(Village_KenMuNi1)` | `MapFormLogic.OnSelectJingLingVillage` **唯一**正规进村 |

因此：**过滤 `MapSelect` 全空 ⇒ 当次离开流程里，章末开图解锁与地图点选进村都未执行。**

| 据此对路径表的裁决 | |
|--------------------|--|
| **路径 B（地图点选进村）** | **排除**（必有点击日志） |
| **路径 A（左门 → 东郊）** | **排除**（目的地已确认是肯姆尼，不是东郊） |
| **章末主链跑完再瞬移** | **排除**（至少应有解锁类 `[MapSelect]`） |
| **仍待查** | 无 `[MapSelect]` 却进 `Village_KenMuNi1` 的通道（见 §⑤ R7） |
