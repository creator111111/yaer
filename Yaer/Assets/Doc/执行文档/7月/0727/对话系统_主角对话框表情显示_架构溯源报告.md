## ① 结论一句话

**对话框里雅儿那张「小脸」不是大立绘 Prefab，而是按存档衣服+头饰选 `Avatar_Yaer_*` 图集，再用 `FaceType` 英文名当钥匙取 Sprite，塞进字幕条 `Portrait`（历史则塞 `ImageAvatar`）；大立绘另走 `StoryFormPainting` 切子物体，两套资源互不共用，不能「改一处全好」。**

生活类比：小头像像微信头像（从图册里抽一张贴上去）；大立绘像舞台上的人偶（Prefab 里换脸换衣）。以后想用「给舞台人偶拍照当头像」，最好只改「抽图册」那一层（`DialogueAvatarLoader`），上面贴图的框和说话流程都不用动。

## ② 原因（生活类比 + 技术锚点）

### 2.1 必须先分清的两套图

| 你在游戏里看到的   | 本报告称呼                     | 真正换的是什么                                            | Prefab / 资源                                                                    |
| ---------- | ------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------ |
| 字幕条左侧小图    | **小头像 Avatar**（**本次主调查**） | `Image.sprite` ← `SpriteAtlas.GetSprite(FaceType)` | UI：`NormalDialogueNewPanel` → `Bottom/Portrait`；图集：`Avatar_Yaer_*.spriteatlas` |
| 对话历史每行左侧小图 | **历史头像**（小头像旁路）           | 同上 Loader，赋给 `HistoryDialogueBox.imgAvatar`        | 同 Panel 内 `HistoryPanel/.../ImageAvatar`                                       |
| 屏幕半身/全身大图  | **大立绘 Painting**（对照）      | `StoryFormPainting.UpdateFace` 激活 `Faces` 子物体      | 母预制体如 `GoOutStoryYaerPainting.prefab` / `YaerPainting.prefab`                  |

> **假结论警告**：大立绘 Prefab 已经能「换表情」，但**不会**自动更新小头像；小头像从不读 Painting 子树。

### 2.2 小头像主链（台本 → 对话框 Image）

| 阶段 | 谁 | 做什么 | 技术锚点 |
|------|-----|--------|----------|
| 1 台本 / 节点 | CSV 第 7 列 `FaceType` 或 NodeCanvas `SayEx` | 写入节点上的表情枚举 | `DialogueRow.faceType`；`StatementNodeEx.FaceType`（`BBParameter<DialogueFaceType>`） |
| 2 CSV 空列默认 | 导入工具 | 雅儿空 FaceType → **Smile**（因图集无 Normal） | `DialogueFaceTypeCsvDefaults.GetDefaultForActor("雅尔")` |
| 3 请求字幕 | `StatementNodeEx.OnExecute` | `DialogueTree.RequestSubtitles(SubtitlesRequestInfoEx(..., FaceType, ...))` | `SubtitlesRequestInfoEx.FaceType` |
| 4 UI 收请求 | `DialogueTMPUGUI.Internal_OnSubtitlesRequestInfo` | 取 `DialogueActorEx`，调 `RefreshAvatar` | `actor.RefreshAvatar(info.FaceType, …)`；旁白无 Actor 则藏头像 |
| 5 Actor 广播 | `DialogueActorEx.RefreshAvatar` | 先挂 `OnRefreshAvatarEvent`，再 Loader 取图 | 事件参数：`(RoleName, faceType, sprite)` —— **大立绘订阅此事件** |
| 6 选图集 + 取 Sprite | `DialogueAvatarLoader.GetAvatar` | 雅儿读存档衣服/头饰拼路径；`atlas.GetSprite(faceType.ToString())` | `ResolveAvatarAtlasPath` + `DialogueAvatarPathHelper` |
| 7 贴到字幕条 | `DialogueTMPUGUI.OnGetAvatar` | `actorPortrait.sprite = sprite`；null 则隐藏 | 字段：`public Image actorPortrait` |
| 8 写历史（旁路入口） | `NormalDialogueFormNewLogic.RecordHistoryDialogue` | 只存 `roleName + faceType + text`，**不存 Sprite** | 订阅 `dialogueUI.OnGetNewStatement` |
| 9 历史再取图 | `HistoryDialogueBox.UpdateDialogue` | **再次** `DialogueAvatarLoader.GetAvatar` | `[SerializeField] Image imgAvatar` |

```
SayEx / CSV FaceType
  → StatementNodeEx
  → SubtitlesRequestInfoEx.FaceType
  → DialogueTMPUGUI
       ├─ DialogueActorEx.RefreshAvatar
       │    ├─ DialogueAvatarLoader.GetAvatar → SpriteAtlas.GetSprite
       │    │    └─ OnGetAvatar → actorPortrait（Bottom/Portrait）
       │    └─ OnRefreshAvatarEvent → StoryFormPainting（大立绘，另链）
       └─ OnGetNewStatement → HistoryDialogueInfo（只记枚举）
            └─ 打开历史 → HistoryDialogueBox → 再走 Loader → ImageAvatar
```

### 2.3 「对话框内表情」钉死的 UI

| 项 | 值 |
|----|-----|
| 对话面板 Prefab | `Assets/GameRes/Prefabs/UI/NormalDialogueNewPanel.prefab` |
| 字幕条容器 | `Bottom`（`DialogueTMPUGUI.subtitlesGroup`） |

### 2.4 雅儿服装如何切入小头像

| 项 | 说明 |
|----|------|
| 读档来源 | `PlayerDataComponentGM.GetClothesData()` → `PlayerClothesData` |
| 用到的部位 | `BoneName.Clothes` + `BoneName.Headwear` |
| 路径公式 | `Assets/GameRes/Atlas/Avatar/Avatar_Yaer_{衣服}_{头饰}.spriteatlas` |
| 现有四套图集 | `Dress_Crown` / `Armor_NoHeadWear` / `Armor_Crown` / `Armor_ArmorHead` |
| 新游戏默认 | `InitNewGameData`：`Dress` + `Crown`（与沙盒默认一致） |
| DialogDebug 无存档 | `PlayerDataComponentGM == null` → 警告 + 默认 **Dress + Crown** |
| ArtRes 源图目录 | `Assets/ArtRes/UI/Story/DialogueForm/Yaer/Avatar/{Dress\|ArmorNone\|ArmorCrown\|Armor}/`（文件夹名是美术整理用；**运行时路径用衣服+头饰枚举串**） |
| 取 Sprite 键 | **`faceType.ToString()`**，须与 PNG / 图集子图名一致 |
| 缺图 / Normal | `GetSprite` 得 null → `actorPortrait` / `imgAvatar` **隐藏**，字幕继续；雅儿图集**无 `Normal`** |

**每套图集实际 9 表情（与 Dress 目录 PNG 一致）**：  
`Surprised` / `Daze` / `ChiBie` / `Smug` / `Sad` / `Laugh` / `Smile` / `Unhappy` / `VerySurprised`

### 2.5 FaceType 契约

| 层级 | 规则 |
|------|------|
| 枚举 | `DialogueFaceType`（`Assets/Scripts/Game/Static/Enum/Role/DialogueFaceType.cs`） |
| 小头像图集子图名 | **= 枚举英文名**（`atlas.GetSprite(faceType.ToString())`） |
| 美术 PNG 建议 | `表情英文名.png` |
| CSV 空列 · 雅儿 | 导入时默认 **Smile**（`DialogueFaceTypeCsvDefaults`） |
| 运行时 SayEx 若显式选 Normal | Loader **不**做 Smile 回退 → 小头像空白（GoOut **大立绘**才有 Normal→Smile 回退） |
| 大立绘 Face 子物体名 | **不是**裸枚举名，而是带服装前缀，如 `Armor_NoHeadWear_Smile`、`Dress_Crown_Smile` |

### 2.6 大立绘对照（勿与小头像混谈）

| Prefab / 脚本 | 表情键怎么拼 | 服装 | 与小头像关系 |
|---------------|--------------|------|--------------|
| `StoryFormPainting` 基类 | 默认 `UpdateFace(faceType.ToString())` | 有 `UpdateClothes`，子类可选调用 | 订阅 `OnRefreshAvatarEvent`；**忽略**事件里的 Sprite |
| `GoOutStoryYaerPainting`（村线/出村常用） | `Armor_NoHeadWear_{faceType}`；Normal→`Armor_NoHeadWear_Smile` | 默认脸固定铠无头饰；`armorHead`/`armorCrown` 开关；`UpdateClothes` **注释掉未跟存档** | Faces 下仅有 **Armor_NoHeadWear_*** 九张；**不能**直接覆盖小头像四套服装矩阵 |
| `YaerPainting` | 基类裸枚举 **或** Prefab 内实为 `Dress_Crown_*`（需与脚本一致；当前脚本为空子类走基类 `faceType.ToString()`，而 Prefab 子物体名为 `Dress_Crown_*` —— **存在键名不一致风险，见开放问题**） | Clothes 节点存在 | 仅 Dress_Crown 系；缺 `ChiBie` 子物体 |
| `NewGameYaerPainting` | `Dress_Crown_{faceType}` | 新游戏线专用 | 脚本在，未见独立同名 Prefab 资产（可能挂在对话 Prefab 上） |

**结论（截图能否复用大立绘）**：大立绘 **已具备「按 FaceType 切脸」**，但 **未具备与小头像同等的「衣服×头饰×表情」完整矩阵**；GoOut 线还把身体服装跟存档的逻辑注释掉了。若直接截现有 GoOut/YaerPainting，小头像服装会跟错或不全。

### 2.7 预加载与其它角色差异（点到为止）

- 预加载名（如 `Yaer_Dress_Crown_DialogueAvatar`）出现在 `AtlasResPackage`、`ForestSceneResConfig`、`NewGameSceneResConfig`、`SelectClothesSceneResConfig`；运行时 Loader 仍用 **磁盘路径** `Avatar_Yaer_{clothes}_{headWear}.spriteatlas` 经 `ResComponentGM.LoadAsset`。
- 其它角色：单图集 `Avatar_{RoleName}.spriteatlas`，无衣服维度。
- `Assets/Prefabs/DialougeProtrait/` 下已有各角色 **Painting Prefab**（舞台立绘先例）；**没有**「专门给小头像用的 DialoguePrefab 截图管线」先例。

### 2.8 硬绑 SpriteAtlas 的点（改造摸底）

| 层级 | 硬绑点 | 说明 |
|------|--------|------|
| Loader | `DialogueAvatarLoader` + `DialogueAvatarPathHelper` | **唯一真正取 Sprite 的地方**（对话+历史都进这里） |
| Actor | `DialogueActorEx.RefreshAvatar` | 只转发；历史**不经过** Actor |
| UI | `OnGetAvatar` / `HistoryDialogueBox.RefreshAvatar` | 只消费 Sprite |
| Painting | `OnRefreshAvatarEvent` → `UpdateFace` | 不消费小头像 Sprite |
| 预加载 | `*SceneResConfig` / `AtlasResPackage` | 绑图集预载名；改截图后可能要减依赖或改预载对象 |
| CSV | `DialogueFaceTypeCsvDefaults` | 只影响导入默认表情，与取图方式无关 |

## ③ 用户需要做什么（检查清单）

1. **进 DialogDebug 或正式对话**：Open `DialogDebug` → Play，或村线任意雅儿说话的对话；看字幕条左侧 `Portrait` 是否随句变脸。  
2. **Inspector 核对小头像**：选中 `NormalDialogueNewPanel` 上的 `DialogueTMPUGUI` → 字段 **`actorPortrait`** 应指向 **`Bottom/Portrait`**。  
3. **对照表情**：SayEx / CSV 的 FaceType（如 `Daze`）↔ `ArtRes/.../Yaer/Avatar/Dress/Daze.png` ↔ 图集子图名；拼写差一个字母会空白。  
4. **对照服装**：看存档衣服/头饰是否落在四套之一；DialogDebug 无存档时应为 Dress+Crown。  
5. **勿用 Normal 测雅儿小头像**：会空白；大立绘 GoOut 会回退 Smile，两边表现不一致。  
6. **打开历史**：确认历史行 `ImageAvatar` 与当前句同表情（同源 Loader；若中途换装，历史重开可能跟**当前**服装图集，见开放问题）。  
7. **大立绘只作对照**：Hierarchy 里点 `GoOutStoryYaerPainting` / `YaerPainting`，确认切的是 `Faces` 子物体，不是 `Portrait`。

## ④ 给程序看的补充

### 4.1 「静态图 → Prefab 截图」挂点优先级（只建议，不施工）

| 优先级 | 挂点 | 侵入面 | 建议 |
|--------|------|--------|------|
| **P0** | **`DialogueAvatarLoader.GetAvatar` 内替换取图实现** | 对话 + 历史一次覆盖；Actor / TMPUGUI / HistoryBox 签名可不变（仍回调 `Sprite`） | **首选** |
| P1 | 新建 `IDialogueAvatarProvider`，Loader 委托之 | 可测、可切静态/截图双实现 | 若要长期双轨 |
| P2 | 仅改 `DialogueActorEx` | **历史旁路绕过 Actor**，须再改 History | 不推荐单独做 |
| P3 | 改 `DialogueTMPUGUI` + `HistoryDialogueBox` | 两处 UI 重复逻辑 | 最差 |
| — | 改 Painting / 预加载 / CSV | 解决不了小头像，或范围过大 | 本期非目标 |

**推荐形状（概念）**：Loader 内对 `DialogueRoleName.Yaer`（或可配置角色）走「准备隐藏立绘实例 → 设衣服/表情 → 截 RT → 生成 Sprite → 回调」；其它角色暂留 SpriteAtlas。缓存键建议：`(role, clothes, headwear, faceType)`。

### 4.2 大立绘 Prefab 复用缺口

| 能力 | 现状 | 截图方案缺口 |
|------|------|--------------|
| 换表情 | GoOut / NewGame 有；键带服装前缀 | 需统一「截图用」键规则，或专用截图 Prefab |
| 换服装跟存档 | GoOut 的 `UpdateClothes` **注释掉**；头饰仅开关两物体 | 须补齐或新建「全服装矩阵」截图 Prefab |
| 四套小头像服装 | 图集有 4 套 | GoOut 只有 Armor_NoHeadWear 脸集；YaerPainting 偏 Dress_Crown |
| Normal 回退 | 仅 GoOut Painting | Loader 层无回退，截图层需否对齐要拍板 |
| 分辨率 / 圆形遮罩 | Portrait 282；历史 140 | 截图尺寸、是否裁脸、是否 Mask —— 开放问题 |
