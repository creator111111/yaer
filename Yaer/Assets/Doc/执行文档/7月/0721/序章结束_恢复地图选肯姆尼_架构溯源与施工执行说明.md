# 序章结束 · 恢复「地图选肯姆尼」— 架构溯源与施工执行说明

**文档版本**：v1.1（2026-07-21）

**触发**：一章流程里，玩家过完序章后应进入 **世界地图**，**照常滚字幕**，再**点选肯姆尼关卡进村**；当前因关卡点未写入解锁数据，易表现为「选不了 / 像没开地图」。

## ① 结论（一句话）

**正常流程已定：序章一结束就解锁肯姆尼关卡 → 打开地图并照常滚字幕 → 玩家点该关卡 → 进 `Village_KenMuNi1`。代码里「点了进村」已经对；缺的是序章结束时把关卡写进存档解锁。施工只补解锁（并修 ESC 竞态），不要改成先弹确认窗、也不要扯「解锁路线」。**

**生活类比**：护照上要先盖「肯姆尼可去」的章，地图才能点那颗星；盖完章后照常放片尾字幕，你再亲手点星进村——不是字幕一完人就瞬移，也不是点星前再问一句「你确定吗」。

## ② 正常流程（已定稿 · 玩家视角）

| 步骤 | 玩家看到什么 | 系统做什么 |
|------|--------------|------------|
| 1 | 序章打完（`WestRappRoad` 章末） | 进入章末演出 / `ChapterEndPanel` |
| 2 | — | **立刻解锁肯姆尼关卡**（写入 `unlockPlaces`，键 `JingLingVillage`） |
| 3 | **世界地图打开**，上面照常 **滚动字幕** | `OpenMap` + 现有字幕逻辑；**不要砍字幕** |
| 4 | 字幕播完（或 ESC 跳过字幕）后，地图可点 | `SelectPlaceLight` 可保留作高亮；**以 Unlock 为准可点** |
| 5 | 玩家点击肯姆尼关卡（`ButtonJingLingVillage`） | **黑幕换场进 `Village_KenMuNi1`**（现有 `OnSelectJingLingVillage`，保留） |

**不是问题的部分**（勿误改）：
- 点关卡后进新地图 —— **就是正常流程**，不要改回「只播对话不换场」。
- 地图上滚字幕 —— **要保留**，不要为了「早点能点」拆掉字幕。

**当前真正的坑**：
- `JingLingVillage` **从未** `UnlockPlace`，按钮靠临时点亮，不可靠 → 体感「选不了」。

## ③ 架构溯源（只读 · 精简）

### 3.1 调用链

```
WestRappRoad · ChapterEndTrigger
  → ChapterEndStory_0 → ChapterEndPanel
    → OpenMap() → MapPanel
    → 【缺】UnlockPlace(JingLingVillage)   ← 本任务补这里
    → 滚动字幕（照常）
    → SelectPlaceLight("ButtonJingLingVillage")
    → 玩家点击 ButtonJingLingVillage
      → LoadScene(Village_KenMuNi1)        ← 已实现，保留
```

### 3.2 命名

| 玩家说法 | 代码 / 资源 |
|----------|-------------|
| 地图上的肯姆尼关卡按钮 | `ButtonJingLingVillage` |
| 解锁写入存档的键 | `PlaceName.JingLingVillage` = `"JingLingVillage"` |
| 点进去的场景 | `SceneName.Village_KenMuNi1` |
| 进村后存档地点显示「肯姆尼」 | `PlaceName.KenMuNi`（与解锁键不同，勿混用） |

### 3.3 根因

| ID | 问题 | 结论 |
|----|------|------|
| R1 | 点了进村 | **正确**，保留 `LoadScene` |
| R2 | 选不了 / 像没解锁 | **缺** `UnlockPlace(JingLingVillage)`；只靠 `SelectPlaceLight` 不够 |
| R3 | ESC 跳过字幕时 `mapLogic == null` | 可能永远灰钮；施工时一并修 |

全工程无第二套「跳过地图直接进村」的活跃路径；进村入口仍是地图点击。

### 名词说明（避免再误解）

| 旧文档里的说法 | 白话意思 | 本任务态度 |
|----------------|----------|------------|
| **二次确认弹窗** | 点了肯姆尼之后，先弹出「是否前往肯姆尼？」再进村 | **不要**。点了就进，符合正常流程 |
| **`UnlockRoad(HomeToJingLingVillage)`** | 地图上「家 → 精灵村」那条**路线贴图**是否点亮（和关卡按钮能不能点是两套数据） | **本期不做**。只解锁**关卡点**即可；路线图另案 |

## ⑥ 施工步骤

| 步骤 | 文件 | 做什么 |
|------|------|--------|
| **MP-1** | `ChapterEndFormLogic.OpenMap`（推荐开图成功 callback 内，或开图前） | 调用 `UnlockPlace(PlaceName.JingLingVillage)`，写入存档 |
| **MP-2** | 同上 callback 后 | 若已开 `MapPanel`，再调一次刷新可点状态（或依赖下次 `ShowUnlockPlace`）；保证字幕滚动期间/结束后关卡可点 |
| **MP-3** | `ChapterEndFormLogic.SkipRollingSubtitles` | `mapLogic == null` 时排队等 Open 回调，再收尾 / `SelectPlaceLight`，禁止静默 return |
| **MP-4** | `MapFormLogic.OnSelectJingLingVillage` | **不改行为**；仅可改注释：标明「地图选关后进村，正常流程」 |
| **MP-5** | 日志 | `[MapSelect]`：解锁成功、点击进村 |

解锁示例：

```csharp
// 序章结束开地图时写入；之后 ShowUnlockPlace 才能正式点亮 ButtonJingLingVillage
GameManager.GetGMComponent<PlayerDataComponentGM>()
    ?.UnlockPlace(PlaceName.JingLingVillage);
```

**禁止**：
- 章末自动 `LoadScene`（跳过玩家点选）
- 只 `SelectPlaceLight`、不写 `unlockPlaces`
- 加「是否前往」确认窗
- 为本任务加 `UnlockRoad`
