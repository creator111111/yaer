# 白天 Idle/Walk 序列帧锚点对齐战斗服（脚底）— 架构溯源报告

**文档版本**：v1.0（2026-08-18）  
**文档性质**：【架构侦探】只读核对；**本文件不施工**（不改 png / meta / Clip / Animator）  
**Unity**：2020.3.48f1  
**范围**：铠甲三态白天 Idle + Walk 的 **`.png.meta` 锚点**；参考战斗服待机 / 铠甲走路 **只读**  
**非范围**：png 像素、guid、AnimationClip、Animator、龙宫、裙子 `Dress/*_DayLight`、参考目录本身

关联提示词：`Assets/Doc/提示词/0818/白天待机走路_按战斗服锚点对齐_架构侦探提示词.md`

---

## ① 结论一句话

**可以按「同尺寸逐帧拷贝 pivot / 同宽不同高按距底像素换算」施工。** 72 张白天图目前全是图心锚点（`alignment: 0`，`pivot 0.5,0.5`），对应参考全是脚底自定义锚点（`alignment: 9`）。没有「宽也不同」的例外；多出来的像素在头顶，脚贴底边。Idle 缺帧 5/7/15/17 两边都缺，不要补。走路参考上的 `spriteBorder` **不要拷**。

---

## ② 原因（生活类比）

旧战斗服每张贴纸已经在脚底钉了图钉，换帧时脚不滑。白天那套还把图钉钉在肚脐（图心），一播就上下跳。

要对齐，就是把白天每张图的图钉钉到和旧战斗服**同一只脚**的位置：

- 画布一样大 → 图钉坐标原样抄过来。  
- 一样宽、白天图更矮或更高 → 左右钉点不变，上下按「离底边多少像素」换算，别按比例乱拉整张图。

Clip 已经引用 ArtRes 白天 png 的 guid（例 `ArmorIdle_DayLight.anim` → `Armor1` guid `2dd39777…`）。**改 meta 锚点即可生效，不要改 anim。**

---

## ③ 用户需要做什么

本阶段先认公式。施工后在 Unity 里核对：

1. 打开任意白天 Sprite，绿色十字应在脚底附近，和对应战斗服参考帧一致（不要还在腰上）。  
2. 播 `ArmorIdle_DayLight` / `CrownIdle_DayLight` / `NoneIdle_DayLight`：脚不原地打滑、人不上下跳。  
3. 播三套 `*Walk_DayLight`：同上。  
4. 参考目录（`战斗服*` / `铠甲*走路`）锚点未变；guid 未变。  
5. 裙子 Dress、龙宫、战斗服参考 **未改**。

### 4.2 Idle 缺帧 5 / 7 / 15 / 17

白天三目录与战斗服待机三目录 **都没有** 这些号。与 0807 帧图重命名案一致。**禁止补空帧、禁止重排号。**

### 4.3 抽查（脚是否在底、公式是否成立）

Unity pivot：`(0,0)` 左下，`y≈0` 贴脚底。参考 Idle `y≈0.03`（约离底 18～21px）；Walk `y` 接近 0，部分略负（脚贴画布底边）。

不透明像素包围盒（抽样）：**底边留白 dest 与 src 相同**，高度差几乎全在头顶。

| 抽查 | 画布 | 底边留白 | 结论 |
|------|------|----------|------|
| Idle Crown1 | 双方 `353×584` | 都是 4px | 同尺寸，十字在脚，**COPY** |
| Idle Armor1 | 双方 `353×563` | 都是 4px | 同尺寸 **COPY**（头顶空白 dest 比 src 多 2px，属画内容差，仍拷贝画布 pivot） |
| Idle Armor20 | dest `325×562` / src `325×581` | 都是 1px | 同宽不同高，多 19px 在 src 头顶，**YSCALE** |
| Walk Crown1 | 双方 `277×560` | 都是 0 | 同尺寸 **COPY** |
| Walk Armor1 | dest `277×546` / src `277×542` | 都是 0 | dest 更高，多 4px 在 dest 头顶，**YSCALE** |

**没有「宽不同」或「脚不在底边」的帧。** 公式可用。

同宽不同高：

```
alignment = 9
destPivot.x = srcPivot.x
destPivot.y = srcPivot.y * srcHeight / destHeight
```

`y` 允许略负（参考走路已有），**禁止 clamp 到 0**（会把脚抬起来）。

### 4.4 spriteBorder

走路参考多帧有非零 `spriteBorder`（例：护头走路 `1.png` 为 `{x:234, y:0, z:0, w:0}`；全无走路 `2.png` 为 `{x:0, y:17, z:98, w:0}` 等）。  
白天目录当前全是 `{x:0,y:0,z:0,w:0}`。

角色 Sprite 走 Simple，拷 border 会搅九宫。底边已经对齐，**不靠 border 才能钉脚**。  
**施工默认：不拷贝 spriteBorder。**
