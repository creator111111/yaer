# 版本号仅主界面显示 · 架构溯源报告

> 日期：2026-09-24  
> 角色：架构侦探（**只读**；未改代码 / Prefab / `bundleVersion`）  
> Unity：2020.3.48f1  
> 产品拍板（**覆盖 0922**）：左下 `Application.version`（现网 `1.0.5`）**只在主界面**；进局后一律不显示  
> 提示词：`Assets/Doc/提示词/0924/版本号仅主界面显示_架构侦探提示词.md`  
> 对照：`执行文档/0922/游戏左下角版本号1.0.5_架构溯源报告.md`（当时要求主菜单+局内常驻，本票**撤销**）

---

## ① 结论一句话

**局内仍见 `1.0.5` 的主因 = P1：`CloseAllUIForm` 永久跳过 Version + 末尾 `EnsureVersionForm()`，换场/开局清屏后版本又被补开。**  
最小改选 **M1**：CloseAll **不再**保留/Ensure Version；仅 `OpenMainMenu`（ProcedureMenu）Ensure；进局靠既有 CloseAll 自然关掉。文案仍读 `Application.version`，**勿改**数值。

---

## ② Play 对照表

| 界面 | 现网左下有无 1.0.5 | 产品要求 |
|------|-------------------|----------|
| 主菜单 StartScene / StartPanel | **有**（`OpenMainMenu`→Ensure；Engine 日志 `Game Version: 1.0.5`） | **要有** |
| 新游戏/读档进局后（村/林） | **有**（CloseAll 过滤+末尾 Ensure） | **无** |
| ESC 菜单 / 地图 / 对话 / 章末 | **有**（Form 仍挂 System） | **无** |
| 回主菜单 | **有**（Ensure 再次/仍在） | **再有**（Ensure 即可） |

用户截图与 0922 施工目标一致：现网按「常驻」工作；本票改生命周期，不是修显示字符串。

## ③ 调用点清单（全量 Grep）

| 位置 | 行为 |
|------|------|
| `UIComponentGM.EnsureVersionForm` | 幂等 `OpenUIForm(VersionPanel, System)` |
| `UIComponentGM.CloseAllUIForm` | **跳过** Version 实例 + **末尾** `EnsureVersionForm()` ← **P1** |
| `ProcedureComponentGM.OpenMainMenu` | 开 StartPanel **前** `EnsureVersionForm()` ← 主菜单入口（保留） |
| `ProcedureMenu.OnEnter` | 调 `OpenMainMenu()` |
| `ProcedureGame` | **无** Version 开/关 |
| `NewGame` / `LoadGame` / `ReturnToMainMenu` / `RestartNewGameFromProgress` | 黑幕内 `CloseAllUIForm(black)` → 因 filter+Ensure，Version **活下来** |
| 其它 `OpenUIForm(VersionPanel)` | **无**（仅 Ensure 路径） |

生命周期（现网）：

```
ProcedureMenu.OnEnter
  → OpenMainMenu → EnsureVersionForm()     // 主菜单出现 1.0.5
  → 选难度 / 读档 → NewGame|LoadGame
       → CloseAllUIForm(black)
            → 跳过 Version
            → EnsureVersionForm()          // ★ 进局后仍有
换场 / 读档 / 回菜单前的 CloseAll
  → 同上：保住或补开 Version               // ★ 局内常驻
ReturnToMainMenu → … → ProcedureMenu → OpenMainMenu → Ensure（幂等）
```

## ④ 假说裁定

| ID | 内容 | 裁定 |
|----|------|------|
| **P1** | CloseAll 跳过 Version + 末尾 Ensure → 进局仍有 | **主因** |
| **P2** | 仅主菜单开；进 ProcedureGame 关 | **施工应对**：M1 用 CloseAll 自然关即可；可选 OnLeave 显式 Close |
| **P3** | 回主菜单再 Ensure | **要保留**（`OpenMainMenu` 已有） |

0922 曾否决「只挂主菜单」——**现产品就要进局消失**，该否决作废。

## ⑤ 方案拍板

| 方案 | 做法 | 裁决 |
|------|------|------|
| **M1** | ① 删 CloseAll 对 Version 的 `continue` 与末尾 Ensure；② 仅 `OpenMainMenu` Ensure；③ 进局不另 Ensure（CloseAll 会关掉） | **主推** |
| **M2** | Form 常驻，进局 `SetActive(false)` | **否决**（易漏 CloseAll/换场路径） |
| 继续全局常驻 | — | **否决**（产品覆盖） |
| 改 `bundleVersion` / 关于页 | — | **否决** |

### M1 施工要点

| 文件 | 改动 |
|------|------|
| `UIComponentGM.CloseAllUIForm` | 去掉 Version 永久 filter；去掉末尾 `EnsureVersionForm()`；备注改为「0924：版本仅主菜单」 |
| `UIComponentGM.EnsureVersionForm` | 保留；仅主菜单调用 |
| `ProcedureComponentGM.OpenMainMenu` | **保留** Ensure；改注释（勿写局内保活） |
| 可选 | `CloseVersionForm()` 封装；`ProcedureMenu.OnLeave` 或 `NewGame` 开头显式关（双保险，非必须） |
| `VersionFormLogic` / `UIPrefabPath` | 注释改为「仅主界面」；**勿**再写常驻/抗 CloseAll |
| Prefab / bundleVersion | **不动**（仍 `1.0.5`） |

回主菜单：`ReturnToMainMenu` → CloseAll（会关 Version）→ 再进 `ProcedureMenu` → `OpenMainMenu` Ensure → **再有**。
