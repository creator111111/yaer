# 章末不要显示战斗立绘 · 架构溯源报告

> 日期：2026-09-24  
> 角色：架构侦探（**只读**；未改代码 / Prefab / 设置默认）  
> Unity：2020.3.48f1  
> 现象：章节结束（大标题 → 黑幕开地图 → 滚动字幕 / 选关）仍出现 **FightingPanel `Illustration`**（铠甲持剑战斗立绘）  
> 触发链：`ChapterEndStory_0`（场景 `ChapterEndTrigger`）→ `ChapterEndAction` → `ChapterEndPanel` → `MapPanel`  
> 提示词：`Assets/Doc/提示词/0924/章末不要显示战斗立绘_架构侦探提示词.md`  
> 证据：现网调用链 + Prefab 节点；本机 `Editor.log` 近期无 `[ChapterEnd]` 条（未再跑通章末），时序表按代码推演，与用户「出地图仍见立绘」一致  

---

## ① 结论一句话

**主因 H1：章末前一段 Story 的 `OnStoryEnd` 按设置延迟 ~0.4s 恢复战斗立绘；`ChapterEndPanel` 全程既不强制关 Illustration，也不拦截该恢复。**  
FightingPanel 在 **Bottom**、章末/地图在 **Top**，立绘会从标题淡入/黑幕缝隙「透」出来（H2 加重观感，非独立根因）。

禁止：把 `_storyEndBattleImageDelay` 改 0；禁止全局默认关 `showBattleImage`。

## ② 上游 Story / 面板

| 项 | 现网 |
|----|------|
| 触发 Prefab | **`ChapterEndStory_0`**（`Assets/GameRes/Prefabs/Dialogue/ChapterEndStory_0.prefab`） |
| 场景触发物 | `ChapterEndTrigger`（`SimpleStoryTrigger` 认名 / `ChapterEndStory*`） |
| 图内节点 | 含 `FightingPanelVisibleActionTask`（`Visible` 空序列化 → 默认 **false → Hide()**）、其后 **`ChapterEndAction`**（`chapterId` 默认 0）、BGM 等；**无** `FightingPanelSetIllustrationVisibleActionTask` |
| 章末 UI | `ChapterEndAction` → `OpenUIForm(ChapterEndPanel, EUIGroup.Top)`，**仅开面板** |
| FightingPanel | 场景基类 `OpenFightingPanel` → **`EUIGroup.Bottom`**，跨场景常残留 |

## ③ 调用链（必画）

```
TriggerStory(ChapterEndStory_0)
  → OnStoryPrefabLoad
       → SetFightingBattleIllustrationVisible(false)     // 立刻关立绘 ✓
  → … 图：FightingPanelVisible(false) → Hide()           // CancelPending + illustration.SetActive(false)
  → ChapterEndAction.OnExecute
       → OpenUIForm(ChapterEndPanel, Top)                 // ★ 无 Cancel / 无强制关立绘
       → EndAction() 立即返回
  → … 图续跑（BGM 等）→ 对话树结束
  → StoryComponentGSM.OnStoryEnd
       → showBattleImage==true 时
       → UpdateBattleImageVisiable(true, fromStoryEndRestore: true)
       → CoDeferredShowBattleImageAfterStory (~0.4s)
            → 仅查：设置开 + homeDoorStoryComplete
            → ★ 不查 ChapterEnd 是否打开
            → ApplyBattleImageShowNow() → Illustration.SetActive(true)  // ★ 章末期间误显
  → ChapterEndFormLogic：大标题 → 黑幕 → OpenMap(MapPanel Top) → 字幕
       → OnOpen / StartChapterEndAni / ESC 跳过 / OnClose：★ 均不碰立绘
```

关键条件（`FightingFormLogic`）：

```csharp
targetVisible = isShow && ForestSceneData.homeDoorStoryComplete;
// 章末时出门剧情通常已完成 → homeDoorStoryComplete==true → 允许恢复
```

村/林 GSM 仅在 **`homeDoorStoryComplete==false`** 时强制关立绘；章末路径**挡不住**恢复。

## ④ 时序表（代码推演；设置「显示战斗立绘」= 开）

| 时刻 | ChapterEndPanel | MapPanel | Illustration Active | 谁最后调了显隐 |
|------|-----------------|----------|---------------------|----------------|
| ChapterEndAction 刚执行 | 打开中 | 无 | 多半仍关（Story 开始已关 / 图内 Hide） | `ChapterEndAction` 只开面板 |
| OnStoryEnd +0s | 已开（大标题流程） | 无或未开 | 仍关；**已排程**延迟显 | `OnStoryEnd` → `fromStoryEndRestore` |
| OnStoryEnd +~0.4s | 开 | 可能仍无 | **变为开** | `CoDeferredShowBattleImageAfterStory` → `ApplyBattleImageShowNow` |
| 大标题淡出 / 开地图 | 开 | 开（Top） | **仍开**（Bottom 透出） | 无人再关 |
| 字幕滚动 / ESC 跳过 | 开 | 开 | **仍开** | ESC 只跳字幕/标题，不碰立绘 |
| ChapterEnd OnClose | 关 | 视流程 | 仍可能开 | OnClose **不** Cancel / 不按场景规则收口 |

施工验收须补 Play：Console 过滤 `[ChapterEnd]`，并可临时在 `ApplyBattleImageShowNow` / `UpdateBattleImageVisiable` 打短日志核对上表「+0.5s」一行。

## ⑤ 假说裁定

| ID | 假说 | 裁定 |
|----|------|------|
| **H1** | OnStoryEnd 延迟恢复；章末无人再关 | **主因** |
| **H2** | ChapterEnd/Map sorting 低于 Illustration，立绘「透」在上面 | **加重**：Fighting=Bottom、章末/地图=Top；透明/淡入阶段仍可见底层 Illustration |
| **H3** | `ChapterEndStory_*` 图节点把立绘设回 visible | **弱**：无 SetIllustrationVisible；仅有 early `FightingPanelVisible`→Hide，其后靠 OnStoryEnd 再显 |
| **H4** | FightingPanel 不该在场却残留 Open | **并存**：Form 常驻 Bottom；Hide 后 `ApplyBattleImageShowNow` 仍可单独点亮 Illustration 子物体 |
| **H5** | 仅 `showBattleImage=true` 出现 | **成立且须修**：产品要求设置开时章末也**不**露；协程内已读该设置 |

## ⑥ 最小修（施工默认）

| 步骤 | 做法 |
|------|------|
| 1 | `ChapterEndFormLogic.OnOpen`（或 `UpdateUI`/`StartChapterEndAni` 入口）：`CancelPendingStoryEndBattleImageShow` + `UpdateBattleImageVisiable(false)`（强制关） |
| 2 | **章末面板存活期间拦截恢复**：`OnStoryEnd` / `CoDeferredShow…` / `ApplyBattleImageShowNow` 前查 `ChapterEndPanel` 是否已打开（或章末 Form 设静态/GSM 旗标）；是则 **不** `ApplyBattleImageShowNow` |
| 3 | `OnClose`：再按设置 + 场景规则恢复（村内 / `homeDoorStoryComplete` 未完成仍应关；林战可显——与现 `UpdateBattleImageVisiable` 条件对齐即可） |
| 4 | ESC 跳过各阶段：不额外开立绘；依赖 1～2 已关且拦截 |

### 方案对比

| 方案 | 做法 | 裁决 |
|------|------|------|
| **A** | 章末 OnOpen 强制关 + 存活期拦截 OnStoryEnd 恢复 + OnClose 按规则恢复 | **主推** |
| **B** | `_storyEndBattleImageDelay = 0` | **否决**（对话衔接闪屏回归） |
| **C** | 设置默认 `showBattleImage=false` | **否决** |
| **D** | 只抬 ChapterEnd sorting / 加满不透明罩 | **否决**（不消 H1；罩不住所有阶段） |
| **E** | 章末 Close FightingPanel | **次选/慎用**（影响血条 HUD；优先只关 Illustration） |
