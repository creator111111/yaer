## 沟通摘要

### ① 结论一句话

这是 **Unity 2020.3 的 2D ACT + 村庄 2.5D 探索**。全局服务在 `GameMgr`，关卡玩法在各场景的 `SceneManager`（GSM），演出必须走 NodeCanvas，玩家动画分 Home / Combat 两套，**村里 Y 轴是前后纵深，不是跳高**。

### ② 原因（通俗）

前人已经把「管整个游戏的东西」和「只管当前这一关的东西」拆开了。新功能如果写在错误的层（例如在 `Update` 里堆剧情、自己造 `isTalking`、村庄脚本去改战斗的 `Run`），就会把现有状态机弄乱。文档比代码注释更全，未拍板的事先记在 `OPEN_QUESTIONS.md`，不要猜着改核心设计。

### ③ 用户需要做什么（检查清单）

| # | 操作 | 现网预期 |
|---|------|----------|
| 1 | Unity **2020.3.48f1** 打开 `Yaer` 文件夹 | 引擎版本必须对上，禁止升级 |
| 2 | 菜单 `Game Framework / Scenes in Build Settings / All Scenes` | 日常 Play 才能 `LoadScene` |
| 3 | 从 **InitScene** 进 Play，不要直接 Play 关卡 | `Launch → Preload → StartScene 主菜单 → ProcedureGame` |
| 4 | `Ctrl+G`（Editor / GameManagerTool） | 可跳过开头、跳森林/家里做开发 |

| 6 | 设计不清楚 | 先记 `Assets/Doc/OPEN_QUESTIONS.md`，不要擅自改核心 |

## 2. 分层总图（谁管什么）

```
Unity 启动 InitScene
        │
        ▼
Game Framework Procedure（Launch / Preload / Menu / Game）
        │
        ▼
GameManager（全局单例：Pause / InConversation / PlayerControl / RayCast）
   ├── GM 组件：UI、存档、切场景、资源、Procedure、PureMVC、声音
   └── 当前场景 GSM：BaseGameSceneManager 子类
            ├── GSM 模块：摄像机、剧情、实体、输入、Tips、换场…
            ├── 玩家 PlayerLogic（Home / Combat 双控制器）
            ├── 怪物 BaseMonster 子类
            └── 场景交互：门、宝箱、SimpleStoryTrigger
```

| 层 | 目录 | 职责 | 不要放什么 |
|----|------|------|------------|
| GF | `Scripts/GameFramework` | 资源、FSM Procedure、UI Form、Entity | 玩法业务 |
| GameMgr | `Scripts/Game/GameMgr` | 跨场景服务、存档、切场景记录 `Now/LastSceneName` | 某一关的 NPC 显隐 |
| GSM | `GameRuntime/GameSceneManager` | **当前关卡**枢纽；`nowSceneName` 必须与 Unity 场景名一致 | 全局存档格式 |
| Entity | `GameRuntime/Entities` | 玩家 / 怪 / 门 / 箱子 | 自己再搞一套切场景 |
| Static | `Scripts/Game/Static` | `SceneName`、`PlaceName`、路径常量 | 运行时单例 |
| UI | `GameRuntime/UI/FormLogic` | 对话、商店、地图、菜单、Tips | 在 Form 里直接改怪 AI |

**取当前场景管理器**：`GameManager.GetGameSceneManager()`。  
**取全局组件**：`GameManager.GetGMComponent<T>()`。

## 3. 启动与进局调用链

```
InitScene
  ProcedureLaunch
    ResourceComponent.InitResources
    GameManager.OnInit / OnEnter
    → ProcedurePreload（Init UI）
      ChangeSceneComponentGM 加载 StartScene
      → ProcedureMenu（主菜单）

```

| 锚点 | 路径 |
|------|------|
| Launch | `Assets/Scripts/Game/GameRuntime/Procedure/ProcedureLaunch.cs` |
| Preload（硬编码切 StartScene） | `…/ProcedurePreload.cs` |
| Menu / Game | `…/ProcedureMenu.cs`、`ProcedureGame.cs` |

**打包**：Build Settings 正式只挂 `InitScene`；其它场景走 AssetBundle。日常开发必须 All Scenes。编辑器默认 `EditorResourceMode=true`，Play 不必每次打 AB。

## 4. 场景管理器（GSM）生命周期

场景根物体通常叫 `SceneManager`，挂 `BaseGameSceneManager` 子类，并配 `GameSceneManagerConfig`。

```
Awake → OnInit()
  OnInitAddModules()     // 默认 12 个 GSM 模块
  InitModules()
  OnInitRegisterProxy()
  InitPlayer()           // Config.canCreatePlayer 才创建
首帧 Update 且异步计数完成
  → GameManager.OnGameSceneManagerReady(this)
切场销毁
  → OnShutDown → RemoveGameSceneManager
```

默认模块（`OnInitAddModules`）：

`Res` / `Buff` / `MapControl` / `PlayerHandler` / `Event` / `Camera` / `Raycast` / `SceneEntity` / `Story` / `Input` / `LoadScene` / `Tips` / `Effect`

`GameSceneManagerConfig` 关键开关：

| 字段 | 含义 |
|------|------|
| `canCreatePlayer` | 商店等纯 UI 场景为 false |
| `isFightingScene` | **true → Combat 控制器；false → Home 控制器** |
| `canMove` / `canRaycast` / `canSave` | 本场景移动、射线、存非默认坐标 |

### 4.1 子类与场景对照（磁盘已核实）

| Unity 场景 | 应挂脚本 | 逻辑名 `nowSceneName` |
|------------|----------|------------------------|
| Village_KenMuNi1 | `Village_KenMuNiSceneManager` | `SceneName.Village_KenMuNi1` |
| Village_Chief_House | `Village_Chief_HouseSceneManager` | `Village_Chief_House` |
| Village_Shop | `Village_ShopSceneManager` | `Village_Shop`（不生成玩家） |
| Village_HomeScene1/2/23/45 | 各自 `Village_HomeScene*SceneManager` | 对应常量 |
| HomeScene1 / HomeScene2 | `HomeScene1Manager` / `HomeScene2Manager` | **龙宫**，禁止挂到村民家 |
| ForestScene / ForestEastScene | `ForestSceneManager` / `ForestEastSceneManager` | 森林 / 东郊 |
| NewGame / Start / SelectClothes / DialogDebug | 各自专用 Manager | 对应常量 |

**硬坑**：同玩法多场景必须拆子类。村挂 `ForestSceneManager` 会把 `SetNowPlace` 写成森林键；民居挂 `HomeScene1Manager` 会把地点写成龙宫。

村庄 2.5D 白名单（`SceneName.IsVillageExplorationScene`）目前只有：

- `Village_KenMuNi1`
- `Village_Chief_House`（室内，走 `IsIndoorVillageExplorationScene`，平面速度对齐 Home，不吃村街 11.2）

其它民居仍是 Default 移动，不要擅自扩白名单。

### 4.2 换场

```
SceneChangeDoor / NodeCanvas LoadSceneTaskAction / 地图 UI / Procedure
  → LoadSceneComponentGSM.LoadScene
  → ChangeSceneComponentGM（记 NowSceneName / LastSceneName）
  → 加载 Assets/GameRes/Scenes/{场景名}.unity
  → 目标场景 EnterPosConfig：用 lastScene = 刚离开的场景名 匹配落点
```

- 门上 `bornPos` **运行时不读**。
- 对话结束 **不会**自动换场，图里必须显式 `LoadScene`。
- 可交互门必须在 `SceneEntityComponentGSM.objRoot` 的 `sceneObjs` 里；E 提示靠 bounds 相交，不靠 Trigger 回调。
- 村内交互体 **Z 宜为 0**。
- 详细：[技术文档/场景相关/场景切换.md](../技术文档/场景相关/场景切换.md)

存档标题：`PlayerHandlerComponentGSM.SetNowPlace(内部键)` → `ArchiveComponentGM` 写入 `ArchiveInfo.currentSceneName` → UI 用 `PlaceName.GetPlaceChsName`。改显示名只改字典。

## 5. 玩家：Home / Combat 双轨 + 村庄纵深

`PlayerLogic.UpdateRuntimeController` 按 `Config.isFightingScene` 换 RuntimeAnimatorController。

| 轨 | 控制器目录 | Bool | C# 状态机 | 典型场景 |
|----|------------|------|-----------|----------|
| Home | `GameRes/RuntimeController/Entity/Player/Home/` | **Walk**（无 Run） | `PlayerHomeSM` | 龙宫、多数民居 |
| Combat | `…/Player/Combat/` | **Run**（无 Walk） | `PlayerCombatSM` | 森林战斗、村街（Combat 进村） |

**契约**：`BaseStateMachine` 只有 `AnimatorStateInfo.IsName(当前 C# 状态名)` 为真才跑该状态 `Enter/Update`。两边抢 Bool 会整卡死（典型：先 AD 再 W/S）。

**村庄规范**（`02_SYSTEM_SPEC`）：

- Y = 纵深，禁止用 Z 位移；Rigidbody2D；村内 Gravity Scale = 0。
- `TownPlayerLocomotion` **只允许写 Walk，禁止写 Combat 的 Run**。
- Combat 进村时：Idle/Run 用 `HasVillageExploreDepthMoveIntent()` 认 W/S。
- `PlayerLocomotionMode.Village2_5D`：丢掉蹲/攻/跳等战斗键（村内禁止 Space 跳跃，0723 已决议）。

落地：`CapsuleGroundChecker` 只向下 Raycast，Mask 是 GroundCenter|GroundCommon，**不认 OnlyMapObj**。怪的 `GroundCld` 若实心，人会踩在怪上却 `IsGrounded=false`（史莱姆/藤蔓/木虫同族坑，0913 走廊木虫已跟修）。

## 6. 剧情与 UI

**唯一启动口**：`StoryComponentGSM.TriggerStory(prefabName)`。

```
TriggerStory(name)
  → ResComponentGM.LoadAsset(DialoguePath)
  → 实例化 NodeCanvas 对话 Prefab
  → 结束必须回到图的状态机
```

禁止：脚本私自 `isTalking`、固定 `Wait` 去对齐镜头。镜头用 `CameraComponent.SetFollow`，后续逻辑放 `onComplete`。

| 模块 | 代表 | 说明 |
|------|------|------|
| 对话 UI | `NormalDialogueFormNewLogic`、`DialogueMaskAvatarPresenter` | 字幕、Mask 小头像、立绘 |
| 台本 | `Assets/Dialog/*.csv` → `Tools / Dialogue / Import CSV` | 生成 NodeCanvas Prefab |
| 场景触发 | `SimpleStoryTrigger.StoryPrefabName` | 碰撞/交互播指定 Prefab |
| 自定义 Action | `GameRuntime/NodeCanvas/NodeCanvasNode/ActionTask/` | 黑幕、立绘、切场、战斗面板 |

Prefab 加载失败常见原因是 **资源未落盘 / guid 断**，不是 ResMgr 坏了。
