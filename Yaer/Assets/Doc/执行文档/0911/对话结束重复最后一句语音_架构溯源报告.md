# 对话结束重复最后一句语音 — 架构溯源报告

**文档版本**：v1.0（2026-09-11）  
**文档性质**：【架构侦探】只读溯源；**未改**代码 / Prefab / 音频 / Git  
**Unity**：2020.3.48f1  
**现象**：对白结束后，再点 NPC / 物体 / 转场 / 开新演出时，会再次播出 **上一段最后一句人声**  
**产品期望**：对白结束（或切下一段前）上一段 VO **停干净**；后续操作不得复读旧最后一句  
**不是**：改台本；重导音频；改 BGM 混音（除非证据指向）；不是 Mask/立绘案  
**提示词**：`Assets/Doc/提示词/0911/对话结束重复最后一句语音_架构侦探提示词.md`

---

## 沟通摘要

### ① 结论一句话

**根因 ≈ H1（成立）：有 Audio 的句子把 VO 打在对话框 `localSource`（`AddComponent<AudioSource>`，默认 `playOnAwake=true`）上；结束只 `Stop()`、不清 `clip`；关壳 `SetActive(false)` 后再开交互/新演出 `SetActive(true)` → Unity 按残留 clip 自动复播最后一句。**

### ② 原因（通俗）

人声挂在对话框自己的喇叭上，戏散了只按了暂停，**磁带没抽出来**，喇叭还开着「一亮就自动播」。  
你再点人、开门、切下一段时对话框又亮起来 → **最后那句又播一遍**。  
不是文件坏了，是结束时没收拾干净。

### ③ 用户 1 分钟自查

| # | 操作 | 看什么 |
|---|------|--------|
| 1 | 找一段 **最后一句有 Audio File** 的对白，正常点完 | 结束瞬间：Hierarchy 选 `NormalDialogueNewPanel` 下挂 `DialogueTMPUGUI` 的物体 |
| 2 | 看其上 `AudioSource` | `isPlaying=false`，但 **`clip` 仍是最后一句 VO 名**；`Play On Awake` 多半为勾选 |
| 3 | 立刻点 NPC / 开下一段对白 | 壳重新显示时，**同一 clip 再响一遍**（对照） |
| 4 | 对照：最后一句 **无** Audio 的对白后再交互 | **不应**复读人声（用于排除「随便什么音」） |
| 5 | 确认不是打字机键音 | 复读应是 **完整一句 VO**，不是短促按键声 |

### ④ 程序补充

见下文 §1～§8。

## 1. 结论（程序向）

| 项 | 裁定 |
|----|------|
| **主因** | **H1 成立**：VO 残留在 UI `localSource`；结束 Stop 不全；关/开壳触发 **PlayOnAwake 复播** |
| **播放挂点（现网主路径）** | `actor.GetComponent<AudioSource>()` 常为 null → 回落到对话框 **`localSource`**（手册亦写「对话 UI 上的 AudioSource」） |
| **结束缺口** | `OnDialogueFinished` / `Paused` 仅 `playSource.Stop()`；**无** `clip=null`、**无**关 `playOnAwake`；`StoryComponentGSM.OnStoryEnd` **不停 VO**；`StartDialogue` **无**防御性停声 |
| **复触发** | `UIFormLogic.InternalSetVisible` → `gameObject.SetActive`；CloseForm 关壳、再 TriggerStory/Open 开壳 |
| **方案** | **A**：结束真源统一停干净（Stop + 清 clip + `playOnAwake=false`）；开场可加防御 Stop；**禁止**每个 NPC/门打补丁 |
| **待 Play** | 纯转场、纯物体交互且 **不开** 新对白壳时是否仍复现（若否，仍由「再开壳」解释；若是，再查场景其它源） |

## 2. 证据链

### 2.1 播放调用链

路径：`Assets/Scripts/Game/GameRuntime/NodeCanvas/NodeCanvasExtend/DialogueTMPUGUI.cs`

```
SubtitlesRequest（句上绑了 Audio File）
  → actorSource = actor.transform.GetComponent<AudioSource>()  // 仅本物体，不含子物体
  → playSource = actorSource ?? localSource
  → playSource.clip = audio
  → playSource.Play()
  → Wait(时长 or 按键) → Continue
```

`localSource` 惰性创建：

```csharp
_localSource = gameObject.AddComponent<AudioSource>(); // 未设 playOnAwake=false
```

Unity 默认 **`playOnAwake = true`**。

策划手册（`Assets/Doc/策划手册/序章主角配音配置手册.md`）：  
「语音从对话 UI 上的 AudioSource 播放」→ 与 localSource 主路径一致。

**磁盘旁证（NewGameStory）**  
- Prefab 内唯一 `AudioSource` 在子物体 **`BGM`**（`m_PlayOnAwake: 1`），**不在** 雅尔/王 Actor 根上。  
- 故雅尔句 `GetComponent<AudioSource>()` → **null** → VO 打在 **对话框 localSource**，不是 BGM、不是 SoundComponentGM 人声通道。

→ **最后一句 clip 挂在：`NormalDialogueNewPanel` 层级里 `DialogueTMPUGUI` 所在 GameObject 的 AudioSource（运行时 AddComponent）上。**

### 2.2 结束与销毁链路

```
树结束 → DialogueTree.OnDialogueFinished
  → DialogueTMPUGUI.OnDialogueFinished
       · StopAllCoroutines()          // ⚠ 停不了 UniTask.Forget()
       · playSource?.Stop()           // ⚠ 不清 clip、不改 playOnAwake
  → DialogueEndSubtitlesCanvasGroupFade（0.7s）
  → OnDialogueEnd
       → StoryComponentGSM.OnStoryEnd()   // 清旗、战斗立绘；⚠ 无 VO Stop
       → PauseDialogue()
       → CloseForm() → Visible=false → SetActive(false)
  → OnClose → ClearDialogueScene() → Destroy(对话树实例)
```

| 步骤 | 是否停干净 VO |
|------|----------------|
| Finished/Paused `Stop()` | 停止播放，**clip 残留** |
| OnStoryEnd | **否** |
| Destroy 对话树 | 清掉 Actor/BGM 源；**清不掉** UI 上 localSource |
| CloseForm 关壳 | 源仍挂在壳上，带着最后一句 clip |

### 2.3 为何「再交互 / 新演出」会复读

```
再 TriggerStory / OpenUIForm(NormalDialogueNewPanel)
  → 壳 Visible=true → SetActive(true)
  → localSource 仍挂上一句 clip + playOnAwake==true
  → Unity 自动 Play() → 复读最后一句 VO
```

与用户四类触发的对应：

| 触发 | 是否易再开对话壳 | 与 H1 关系 |
|------|------------------|------------|
| NPC 交互 → 新对白 | 是（`SimpleStoryTrigger`→`TriggerStory`） | **直接命中** |
| 物体交互 → 新对白/演出 | 多同类 | **直接命中** |
| 立刻新演出 | 是 | **直接命中** |
| 转场 | 关壳/切场景后再开 UI | **高度同构**；纯切场无再开壳则待 Play |

`SimpleStoryTrigger` 本身 **无** AudioSource.Play；不播旧 VO，只再开剧情。

### 2.4 对照实验（写入报告 · 施工/验收必做）

| 实验 | 预期（若 H1） |
|------|----------------|
| 收尾句 **有** VO → 再开任意对白 | **复读**该句 |
| 收尾句 **无** VO → 再交互 | **不**复读人声 |
| DialogDebug 只播完不关壳再开 | 可能较轻；**真机关壳再 Trigger** 更稳复现 |
| 正常点完 vs 中途强制切场景 | 均可能；强制切若绕过 Finished 则更脏（H2 叠加） |

## 3. 假说表（H1～H7）

| ID | 假说 | 裁定 | 证据 |
|----|------|------|------|
| **H1** | Actor/UI AudioSource 残留 clip；交互/开壳再 Play（含 PlayOnAwake） | **✅ 主因** | localSource + Stop 不清 clip + 默认 playOnAwake + SetActive 开关壳 |
| **H2** | 结束未走 Finished，从未 Stop | **次要/叠加** | 正常点完仍可复现则非唯一；强制转场/拆树须另验 |
| **H3** | playSource 指错，Stop 打空 | **弱** | 同句刚 Play 的引用；主路径 localSource 稳定 |
| **H4** | UniTask 结束后仍重入 Play | **非主因倾向** | 出字协程不会二次 Play；但 Finished **停不了** Forget UniTask（残留风险另记） |
| **H5** | 交互 SFX 误用同 clip | **排除倾向** | SimpleStoryTrigger 无播 VO；复读是完整一句 |
| **H6** | 新 StartDialogue 未先 Stop，旧源仍持 clip | **✅ 成对缺口** | StartDialogue 无停声；与 H1 同一残留 |
| **H7** | BGM 闪避像复读 | **排除倾向** | 产品描述为完整一句人声 |

## 4. 排除（一句话）

| 项 | 结论 |
|----|------|
| 打字机键音 | 短促、多段；与「整句 VO」不符 |
| 音频资源坏 / 需重导 | **否**（D 禁止当根因） |
| SoundComponentGM BGM | VO 不走该通道（本句路径） |
| NewGameStory 内 BGM 子物体 | 有 PlayOnAwake，但 VO 未写到该源；树销毁后与 UI localSource 无关 |

## 5. 建议施工（优先 A · 只建议不施工）

1. **结束真源统一停干净**（`OnDialogueFinished` / `OnDialoguePaused`，必要时 `OnDialogueEnd` / `OnStoryEnd` 再兜一层）：  
   - 对当前 `playSource`：**Stop**  
   - **`clip = null`**（防 PlayOnAwake / 误 Play）  
   - **`playOnAwake = false`**（创建 localSource 时一并设）  
2. 若存在「曾写过 Actor.AudioSource」的对白：结束时对 **本场 DialogueScene 内发言 Actor 源** 同样 Stop+清 clip（登记本场播过的源，**禁止**全局 `FindObjectsOfType` 乱停）。  
3. **`StartDialogue` 开头防御性 Stop**（同一套清理），防关壳异常路径。  
4. **禁止**在每个 NPC/门/交互入口复制 Stop 当终局（方案 C）。  
5. **禁止**未证伪就重导音频（D）。  
6. 方案 B（VO 只走 localSource/人声通道、禁止写 Actor）可作二期架构清洁；本期 A 即可止血。  
7. 施工说明：`Assets/Doc/施工说明/0911/对话结束停干净语音_施工说明.md`  

### 验收

- 有 VO 收尾句 → 再 NPC / 物体开新戏 / 转场后再开对白 / 立刻新演出：**均不复读**旧最后一句  
- 新对白首句 VO 正确  
- BGM 不被误停  

---

## 6. 剩余风险

| 风险 | 说明 |
|------|------|
| 多 Actor 同场曾播 VO | 只清 playSource 可能漏早期 Actor 源；应用「本场播过源」列表 |
| UniTask.Forget 不随 Finished 取消 | 极端时序下尾部逻辑仍跑；可加取消令牌（二期） |
| Skip / 黑幕强制结束 | 须确认仍进 Finished/Paused；否则 H2 |
| 纯转场无再开壳 | 若仍复读，再查 DontDestroy / 其它 AudioSource（验收矩阵补一行） |
| PlayOneShot 键音 | 与 localSource 共用时勿误清正在播的逻辑；清 clip 在**对白结束**时做即可 |

## 8. 可复制给施工员（5～10 条）

> 根因已拍板：**H1**（localSource 残留 clip + PlayOnAwake + 关开壳）。走 **A**。

1. **目标**：对白结束后，NPC/物体/转场/新演出均不再复读上一段最后一句 VO。  
2. 在 `DialogueTMPUGUI` 结束路径（Finished/Paused，必要时 End）：对实际播过的源 **Stop + clip=null + playOnAwake=false**。  
3. 创建 `localSource` 时立刻 `playOnAwake=false`。  
4. `StartDialogue` 开头做一次同款防御清理。  
5. `OnStoryEnd` 可再兜一层停 VO（防异常结束）。  
6. **禁止**每个交互入口打 Stop 补丁；**禁止**全局 Find 全场景 AudioSource.Stop；**禁止**重导音频当修复。  
7. 若有 Actor 源路径：按「本场播过」登记清理，勿只 Stop 当前 playSource 漏网。  
8. 施工说明：`Assets/Doc/施工说明/0911/对话结束停干净语音_施工说明.md`。  
9. 验收：有 VO 收尾 → 四类触发不复读；无 VO 收尾对照；新句 VO 正常；BGM 正常。  
10. 可加 `[DialogueVoiceDebug]`：Play/Stop 时打 source 名、clip 名、story 名。
