# 村内开场 — 雅 / 古莎 对白台本（执行说明）

**用途**：章节开始进村后与古莎同行至村长家门口的整段对话，录入 CSV 或做对话 prefab。  
**角色**：雅（雅尔）、古（古莎）、艾米（Amy，末句）  
**演出**：章节开始 → **黑屏入场** → 立绘 + 对话框出现 → 播下列对白  

**FaceType（单列）**：与 NodeCanvas `SayEx` → `DialogueFaceType`、图集子图名一致；**本表每行只填当前说话人**那一格，导入 CSV 时对应 **`Face` 列**（与 `Speaker` 同行）。运行时同一枚举名在不同角色图集中取不同立绘（详见 `对话立绘表情与图片名称对照_执行说明.md`）。

| 注意 | 说明 |
|------|------|
| 雅尔 | **勿用 `Normal`**（`Avatar_Yaer_*` 无此键） |
| 古莎 | 可用 `Normal`；`Awkward` / `Cry` / `Daze` / `Sad` 会切立绘服装层（`GuShaPainting`） |
| 艾米 | 常用 `Normal`、`Scared`（`Avatar_Amy`） |

### 附录：各角色可用 FaceType 速查（填表校验用）

**雅尔（9 种）**：`VerySurprised` `Surprised` `Daze` `Laugh` `Smile` `Unhappy` `Sad` `Smug` `ChiBie`

**古莎（常用）**：`Normal` `Smile` `Happy` `Laugh` `Surprised` `VerySurprised` `Sad` `Daze` `ForcedSmile` `Awkward` `Angry` `Hurt` `Cry`

## 4. 制作步骤

1. 按 §1 导出 CSV（§2 列格式）；`Face` 列待导入工具支持后自动写入 SayEx。  
2. 开场前奏见 `0525/CSV导入工具_开场前奏选项_施工执行说明.md`。  
3. Bind Graph + 绑 Actor；`DialogDebug.unity` 试播后进村验收。
