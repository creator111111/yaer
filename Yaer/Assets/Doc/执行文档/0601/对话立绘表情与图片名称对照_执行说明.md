# 对话立绘 — 表情选项与图片名称对照（执行说明）

**用途**：在 NodeCanvas `SayEx` 节点选表情、整理美术 PNG、核对图集时查表。  
**调查依据**：`DialogueFaceType.cs`、`DialogueAvatarLoader.cs`、`DialogueAvatarPathHelper.cs`、各 `Avatar_*.spriteatlas` 与 `Assets/ArtRes/UI/Story/DialogueForm/` 源图目录（2026-06-01 静态盘点）。

---

## 1. 核心规则（必记）

| 层级 | 规则 |
|------|------|
| **NodeCanvas 里选的「表情」** | 枚举 `DialogueFaceType`（`StatementNodeEx` → `FaceType`） |
| **图集里 Sprite 的名字** | **与枚举英文名完全一致**，如 `Smile`、`VerySurprised` |
| **程序如何取图** | `atlas.GetSprite(faceType.ToString())`（见 `DialogueAvatarLoader`） |
| **美术源文件建议命名** | `表情英文名.png`，与枚举一致，便于打进 SpriteAtlas |

**生活类比**：表情英文名 = 货架标签；PNG 文件名、图集子图名、节点里下拉选项必须拼写一致，差一个字母就取不到图。

**雅尔（Yaer）额外规则**：图集按 **衣服 + 头饰** 分套，路径为  
`Assets/GameRes/Atlas/Avatar/Avatar_Yaer_{衣服}_{头饰}.spriteatlas`  
（运行时读存档换装；DialogDebug 无存档时用默认 **Dress + Crown**）。

**其它角色**：单图集 `Assets/GameRes/Atlas/Avatar/Avatar_{角色名}.spriteatlas`（如 `Avatar_Gusha`）。

---

## 5. 在 Unity 里怎么用（简版）

1. 打开对话 prefab → NodeCanvas 图 → **SayEx** 节点。  
2. **Face Type** 下拉选 §2 / §4 中该角色 **「图集内有的」** 英文名。  
3. 新增表情：在 `ArtRes/.../Avatar/` 加 `{枚举名}.png` → 加入对应 `Avatar_*.spriteatlas` → Pack。  
4. 试播：`DialogDebug.unity` 拖 prefab Play，或 InitScene 进正式场景。

## 6. 村内雅 / 古开场台本 → 表情建议（示例）

| 台词倾向 | 雅尔建议枚举 | 古莎建议枚举 |
|----------|--------------|--------------|

| 大笑 / 卷角 | `Laugh` | `Happy` / `Laugh` |
| 惊讶「再来一次」 | `VerySurprised` | `Happy` |
| 无奈「不是街头艺人」 | — | `ForcedSmile` 或 `Awkward` |
| 回礼表演 | `Smile` | `Surprised` |
| 说小翅膀 | `Smile` | `Smile` |
| 呼扇 / 可爱 | `Laugh` | `Happy` |

（具体以美术稿为准；选不到图时先查 §4 该角色是否有该枚举。）
