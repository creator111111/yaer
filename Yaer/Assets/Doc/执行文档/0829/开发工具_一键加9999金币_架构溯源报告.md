# 开发工具 · 一键加 9999 金币 — 架构溯源报告

**文档版本**：v1.0（2026-08-29）  
**文档性质**：【架构侦探】只读核实 + 施工指引（**本阶段未改代码**）  
**Unity**：2020.3.48f1  
**用途**：验收 Menu Money 图片数字、商店扣款成败时快速灌金

关联：`0829/MenuPanel_Money对接…` · `QuestManager` / `PlayerGoldData`  
样板：`Tools/MainItem/一键添加全部主道具` · `Tools/UI/Setup MenuPanel Money Digits`

---

## ① 结论一句话

**现网无刷金 Tools/热键；加金 API 已齐。推荐方案 A：Editor 菜单 `Tools/Debug/Add 9999 Player Gold`（仅 Play），走 `QuestManager.getInstance()` → `GetPlayerGoldData()` → `AddGold(9999)` → `SavePlayerGold()`；成功后尽量刷新已打开的 Menu Money（需把 `RefreshMoneyFromArchive` 公开或加 public 包装）；未 Play 友好失败。禁止正式 UI 作弊钮。**

---

## ② 原因（通俗）

任务发奖才会 `AddGold`，测菜单金币/商店扣款太慢。工程里已有「Play 中 Tools 一键塞背包」同款入口，刷金照抄即可；改 JSON 或菜单上加作弊按钮都不合适。

## ④ 给程序

### A. 现成工具证伪

| 搜索面 | 结论 |
|--------|------|
| `AddGold` 调用方 | **仅** `QuestManager` 任务发奖 Gold 分支 |
| MenuItem 含 gold/money/刷金 | ❌ 无；仅有 `Setup MenuPanel Money Digits`（装配 UI，不加金） |
| Play 热键刷金 | ❌ 无（商店 Face Debug 的 F1～F3 无关） |

**结论：须新建工具。**

### B. 加金链路（钉死）

```
QuestManager.getInstance()
  → GetPlayerGoldData()     // 有 GSM 用场景 Archive；否则 ArchiveComponentGM
  → AddGold(9999)           // 累加；amount≤0 忽略（本工具写死 9999）
  → SavePlayerGold()        // SaveSpcData<PlayerGoldData>，必须落盘
```

| 失败场景 | 表现 |
|----------|------|
| `!Application.isPlaying` | 拒绝；`DisplayDialog` 或 LogWarning（对齐 `MainItemAddAllBagMenu`） |
| `GameManager` / Archive / goldData null | LogError；不改盘 |
| Edit 模式改 `gold=` | ❌ 禁止绕过 AddGold |

语义：**累加 +9999**（非设为 9999）——便于测多位 DigitStrip。

### D. 加金后刷新 Menu Money

现网 `MenuFormLogic.RefreshMoneyFromArchive()` 已在 `OnOpen`/`OnReveal` 调用，但是 **`private`**。

| 做法 | 优先级 |
|------|--------|
| 工具成功后 `Object.FindObjectOfType<MenuFormLogic>()` → 调 **public** 刷新 | **P0 建议** |
| 仅 Log「请再 ESC 开菜单」 | 底线可接受 |

施工最小改动：把 `RefreshMoneyFromArchive` 改为 `public`，或新增 `public void DebugRefreshMoney()` 转调私有方法——**勿**复制读金逻辑到 Editor。

### E. 最小施工清单

| # | 文件 | 动作 | 优先级 |
|---|------|------|--------|
| 1 | 新建 `Assets/Editor/Tool/Debug/AddPlayerGoldDebugMenu.cs`（或同区） | MenuItem + Validate；AddGold(9999)+Save；Log 前后余额 | **P0** |
| 2 | `MenuFormLogic.cs` | `RefreshMoneyFromArchive` → public（或薄 public 包装） | **P0** |

**排除**：正式包 UI；第二钱包字段；不 Save。

**预期伪代码（Editor）**

```csharp
#if UNITY_EDITOR
[MenuItem("Tools/Debug/Add 9999 Player Gold")]
static void Add() {
  if (!Application.isPlaying) { /* dialog */ return; }
  var qm = QuestManager.getInstance();
  var data = qm.GetPlayerGoldData();
  if (data == null) { /* error */ return; }
  var before = data.gold;
  data.AddGold(9999);
  qm.SavePlayerGold();
  Debug.Log($"[DebugGold] {before} → {data.gold}");
  Object.FindObjectOfType<MenuFormLogic>()?.RefreshMoneyFromArchive();
}
[MenuItem("Tools/Debug/Add 9999 Player Gold", true)]
static bool Validate() => Application.isPlaying;
#endif
```

样板对齐：`MainItemAddAllBagMenu`（Play 门禁 + InitScene 提示）。
