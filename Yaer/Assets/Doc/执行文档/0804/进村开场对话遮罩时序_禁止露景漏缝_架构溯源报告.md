## ① 结论一句话

**漏缝发生在「`CloseFormFade` 已开始/完成 → 对话 Prefab 异步加载 + `NormalDialogueNewPanel` 打开 + 立绘/字幕再淡入」整段空窗：村景已可见，遮罩尚未盖满。推荐村专用方案 A′：场景 Ready 且仍全黑时就 `TriggerStory`，等对话壳 Ready（并建议立绘/字幕已不透明或跳过前奏淡入）后再 `CloseFormFade`；不要动通用换场默认契约。**

---

## ② 原因（生活类比 + 锚点）

### 生活类比

窗帘（换场黑幕）先拉开，墙上的画（开场对话立绘+对话框）还在仓库里慢慢搬——客厅（村庄）就露了出来。正确做法：画先挂好（或窗帘别拉），再拉开窗帘。上一轮把「按播放键」挂在窗帘拉开之后，能播但对「对话挡景」目标是错序。

### 漏缝时间窗（钉死）

| 时刻 | 状态 | 村景是否可见 |
|------|------|--------------|
| BlackPanel FadeShow 全黑 + LoadScene | 幕后加载村 | 否 |
| SceneManager Ready + hold≈0.3s | 仍全黑 | 否 |
| **`CloseFormFade` 开始～结束** | 黑幕透明度↓ | **逐渐可见** |
| `OnBlackFadeEnd` → `OnEnterScene` → `TryTriggerVillageStartStoryOnce` | 才 `TriggerStory` | **已可见** |
| `ResMgr.LoadAsset` 异步 | 尚无对话壳 | **裸露** |
| `OpenUIForm(NormalDialogueNewPanel, Middle)` + `StartDialogue` + `Yield` + 实例化树 | 壳渐出 | **仍可能漏** |
| Prefab 前奏：立绘 CanvasGroup 0→1（≈0.7s）+ 对话框 Alpha 淡入 | 遮罩未满 | **缝最大** |

→ 不是「黑幕与前奏叠感」问题，是 **先露景、后播遮罩**。

### 现网时序 vs 目标

```
【现网 · 漏缝】
Ready → hold → CloseFormFade          ← 露景开始
     → OnEnterScene → TriggerStory    ← 太晚
     → 异步 Load + 开壳 + 前奏淡入    ← 更晚才盖住

【目标 · 零漏缝】
Ready（仍全黑）
  → TriggerStory → 壳 Ready / 遮罩盖满（仍全黑或对话已挡）
  → 再 CloseFormFade（或对话结束后再露，见方案 B）
  → onStoryEnd → 村景正常可见（镜头锁等跟 homeDoor 逻辑）
```

### 层级事实（影响方案 B）

| UI | `EUIGroup` | 含义 |
|----|------------|------|
| `BlackPanel` | **System**（最高档之一） | 压在 Middle 之上 |
| `NormalDialogueNewPanel` | **Middle** | 黑幕未关时，对话会被黑幕挡住看不见 |
| 对话内 `BlackMask` | 默认 **alpha=0** | 不自动全屏挡景 |

→ **不能**简单「黑幕一直压到 `onStoryEnd`」而不改层级/透明度，否则玩家看不到对白。

### Prefab 前奏

`Village_KenMuNiStart` 开场：藏战斗立绘意图 → 雅/古立绘 Alpha 淡入 → 对话框 Alpha 淡入。  
若在**已亮村景**下播：淡入过程就是漏缝放大器。  
若在**仍全黑**下播完再淡出黑幕：前奏可在幕后完成；或施工时改为瞬间 `alpha=1` 减负。

### 上一轮 OPEN Q3

原决议「Prefab 前奏与换场黑幕叠感可接受」→ **作废/被推翻**。本报告新开「遮罩时序」节；旧 Q3 应标注「被 0804 遮罩时序需求取代」。

## ③ 用户需要做什么（拍板 + 验收）

### 拍板

1. **黑幕保持到对话 UI Ready 即淡出（A）**，还是 **对话整段结束后才露景（B）**？  
   - 默认推荐：**A′（Ready 即淡出，但须遮罩已盖满）** —— 对白期间不压着 System 黑幕。  
2. 通用 `LoadScene` 是否加可选参数，还是 **村专用旁路**？（默认：**村专用**，勿破坏其它换场）  
3. Prefab 前奏：幕后播完 / 改瞬间显示 / 不动？（默认：**幕后播完或施工时跳过淡入**）

### 验收清单

1. 新档点地图进村：从黑幕到对话首句，**肉眼看不到村景**（无闪）。  
2. 对话过程中村景仍被立绘+对话框盖住（允许边缘构图，但不允许「先空村再弹窗」）。  
3. 对话结束后村景正常；镜头锁符合 `homeDoorStoryComplete==false`。  
4. 再进村不重播；其它场景 `LoadScene` 黑幕无回归。  
5. DialogDebug 拖 Prefab 单测仍可用。

## ④ 给程序看的补充

### 4.1 方案比选

| 方案 | 做法摘要 | 零漏缝？ | 改动面 | 风险 | 推荐？ |
|------|----------|----------|--------|------|--------|
| **A′ 黑幕未淡出时 Trigger，遮罩 Ready 后再 CloseFormFade** | Ready 后拦截 `CloseBlackAndNotify`；村内先 `TriggerStory`；`onStoryTriggered` / 开壳回调（+可选等前奏结束）再淡出黑幕 | **能** | 村旁路 + 少量 LoadScene 钩子 | 须定义「Ready」；`OnEnterScene` 勿二次 Trigger（靠 `HasRunningStory`） | **推荐** |
| A 仅开壳即淡出 | 同 A′ 但不 tip 前奏 | 前奏淡入时仍可能漏边 | 更小 | 立绘从 0 淡时露景 | 可作最低档 |
| B 黑幕保持到 onStoryEnd | 对白期间 System 黑幕不关 | 理论挡景 | 须解决「黑幕挡住 Middle 对话」：降黑幕 alpha / 升对话组 / 改用对话 BlackMask | 易看不见字；影响其它依赖黑幕结束的逻辑 | 不推荐除非改层级 |
| C 淡出前加占位全屏遮罩 | CloseFormFade 同时亮占位 → 对话起再撤 | 能 | 多一套 UI | 多资源/多状态 | 次选 |
| D 仅预加载 Prefab 缩短空窗 | hold 内 LoadAsset | **不能零漏缝** | 小 | 仍先淡出再开壳 | 可作 A′ 加速，不可单独用 |

### 4.2 推荐落地要点（A′ · 村专用）

1. **不要**改所有 `LoadScene` 的默认：`CloseFormFade → OnBlackFadeEnd → OnEnterScene` 仍是全游戏契约。  
2. **进村开场专用**：当目标场景为 `Village_KenMuNi1` 且本档尚未播过 Start 时：  
   - 在 `onGameSceneManagerReady`（仍持有 `blackFormLogic`、**尚未** `CloseFormFade`）调用与现 `TryTriggerVillageStartStoryOnce` 同等逻辑；  
   - 订阅一次性：`StoryComponentGSM.onStoryTriggered` 或 `OpenUIForm` callback（建议再等前奏结束 / 或强制立绘·字幕 alpha=1）；  
   - 再 `CloseFormFade` → 现有 `OnBlackFadeEnd` → `OnEnterScene`。  
3. **`OnEnterScene` 内现有 Trigger**：保留门闩即可（`HasRunningStory` / `CheckStoryUsed`）避免双开；或改为「仅当未在黑幕阶段启动过」的显式标志。  
4. **`base.OnEnterScene` 的到达 Tips**：黑幕淡出后可能弹出——若 Tips 露在对话下/上，验收时看是否要延后（另小点，非必须）。

伪代码方向（不施工）：

```text
onGameSceneManagerReady(manager):
  if 需要村开场遮罩:
    TriggerStory("Village_KenMuNiStart")
    await 对话壳 Ready (+ 遮罩盖满)
    CloseFormFade → OnBlackFadeEnd
  else:
    原 hold → CloseFormFade → OnBlackFadeEnd
```

### 4.3 Prefab 前奏建议

| 策略 | 说明 |
|------|------|
| 幕后播完再淡出黑幕 | 零漏缝且保留动画；黑幕多留 ≈0.7s+ |
| 进村专用跳过淡入（alpha 直接 1） | 黑幕可更快淡出；改 Prefab 或运行时跳过 Node | 
| 不动前奏 + 仅开壳就淡出 | 可能仍漏边，不满足「禁止漏缝」 |
