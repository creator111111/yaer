## ① 结论一句话

**21 个 GoOut Faces 节点都在、无同名重复；其中 10 个新表情（`ChiBie2/3`、`GanGa`、`RenNai`、`NanGuo`～`NanGuo4`、`ZhenJing`/`ZhenJing2`）枚举没有 → SayEx/CSV 选不了，大立绘最小闭环 = 在 `DialogueFaceType` 末尾（现 `LuoMo2` 之后）按名单追加。`Angry` 枚举已有、节点已挂、键规则对齐 → 大立绘可零改枚举调用，但 Prefab 上 `Angry` 与 `VerySurprised` 绑了同一张 `生气.png`（VerySurprised 错绑风险），验收必看。小头像四套 / Dress `YaerPainting` / Mask 默认另案。**

## ② 原因（生活类比 + 技术锚点）

### 生活类比

村线舞台人偶衣柜里一下子多挂了十来张新脸（节点名都按 `Armor_NoHeadWear_xxx` 写好了）；但对讲机频道表（`DialogueFaceType`）只认识旧频道 + Happy + Angry。导演喊「忍耐 / 难过2 / 震惊」时频道不存在，灯光切不过去。`Angry` 频道本来就有——人偶也能换上，但「惊愕」那一格目前误挂了「生气」同一张图，验收时会看成两张脸长一样。

### 与 Happy 轮差异一行

| | 0803 Happy | 本期批量新表情 |
|--|------------|----------------|
| 卡点 | 枚举**已有**，主要验 Prefab/绑图 | 多数枚举**没有**（同古莎 LuoMo 卡点） |
| 键规则 | `Armor_NoHeadWear_{faceType}` | **不变**（`ResolveGoOutFaceKey`） |
| 例外 | — | `Angry`：枚举有 → 可零改枚举调大立绘 |

### 调用链（台本 → GoOut 大立绘）

```
SayEx / CSV FaceType = <枚举名>
  → 须 DialogueFaceType 存在（否则下拉无 / CSV Enum.TryParse 失败）
  → StatementNodeEx → DialogueActorEx.RefreshAvatar
       ├─ Loader → Avatar_Yaer_*.GetSprite("<枚举名>")  → 新表情四套均无图 → 小头像隐藏
       └─ OnRefreshAvatarEvent
            → GoOutStoryYaerPainting.UpdateFace(ResolveGoOutFaceKey(faceType))
            → 键 = "Armor_NoHeadWear_" + faceType   （Normal 例外回退 Smile）
            → 激活 Faces 同名子物体
```

**键契约（已核实）**：`GoOutStoryYaerPainting.ResolveGoOutFaceKey` → `$"Armor_NoHeadWear_{faceType}"`；无需为本批新表情改 C# 键逻辑。

### Prefab 总览（`GoOutStoryYaerPainting.prefab`）

| 项 | 结果 |
|----|------|
| Faces 节点数 | **21**（与预梳理表一致，无同名重复） |
| 布局 | 全体 SizeDelta≈`77.2×54.7`，Scale=`2.1`，Pos≈`(-16.8, 516.6)` → **同级对齐**（0803 Happy「相对 Smile 全尺寸异常」的旧量测已过时；现为脸层裁切+统一缩放） |
| 源图目录 | 多数绑 `Face/Dress/雅尔游戏中立绘/表情/*.png`（连衣裙脸层图挂在 GoOut Armor 节点上——与 Happy 轮同源策略，验收看视觉即可） |
| 严重绑图风险 | **`Armor_NoHeadWear_Angry` 与 `Armor_NoHeadWear_VerySurprised` 共用 guid → `生气.png`**。Angry 语义对；**VerySurprised 现显示生气脸**（应用 `惊愕`/`震惊` 类图，待拍板校正） |

### 枚举现状（`DialogueFaceType.cs`）

- 末尾现为：`… Scared, LuoMo, LuoMo2`（古莎轮已落地）。
- **有**：原 9 + `Happy` + `Angry`（及古莎等其它成员）。
- **无（须追加）**：`ChiBie2` `ChiBie3` `GanGa` `RenNai` `NanGuo` `NanGuo2` `NanGuo3` `NanGuo4` `ZhenJing` `ZhenJing2`。

### 小头像
