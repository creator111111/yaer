## ① 结论一句话

**现网「必须走近」是代码门槛：`RaycastListener.OnClick` 要求玩家 `InteractiveCollider` 与点击盒 bounds 相交才派发事件；物品远程点击不能只配场景——须给 Listener 增加「忽略距离」开关（或远程子类），再仿 NpcChair 三件套挂实体 + Import 物品 CSV 成对话 Prefab。**

---

## ② 原因（生活类比）

现在点 NPC 像「走到柜台前按铃才受理」——铃（`TriggerStory`）没坏，是柜台前占位检查拦了你。  
物品要「隔着大厅指一下展柜就播讲解」——还是那个铃，只取消「必须站在柜台前」。

远处点 NPC：射线**可能打中**，但 `OnClick` 因不相交**静默不播**（无报错）——像按了铃却没人应答。

## ④ 给程序看的补充

### 4.1 现网点击对话完整链

```
鼠标左键按下
  → RaycastComponentGSM.Raycast（Procedure Pause 则整段 return）
  → 若 IsPointerOverGameObject → return（点在 UI 上不点场景）
  → Physics2D.RaycastNonAlloc（屏幕点→世界，方向 zero）
  → 命中带 RaycastListener 的 Collider
  → RaycastListener.OnClick(playerEntity)
       ★ 强制：玩家 InteractiveCollider 与 listenerCollider bounds 相交（Expand 0.2）
       ★ 不相交 → 不 Invoke（静默失败）
  → onClickEvent → InteractiveComponent.onClickInteractiveEvent
  → SimpleStoryTrigger.OnClickTriggerStory（TriggerType.Click）
  → TriggerStory(ResolveStoryPrefabName())
  → StoryComponentGSM 加载 Dialogue Prefab → 现网对话 UI
```

**E 键路径（另一条，同样要靠近）**：

```
Interact → BasePlayerState.InteractAciton
  → GetFirstCanTouchEntiy：遍历 scene 实体，InteractiveCollider bounds 相交才入选
  → closestComponent.OnInteractive() → 直接 onClickInteractiveEvent
  → 同上 SimpleStoryTrigger
```

E 提示出现也依赖 `GetFirstCanTouchEntiy` 的 overlap（`PlayerLogic.checkCanAddKeyTipsInOtherEntity`）。  
`canTouchWithPlayer`：管 E 提示挂载 / 部分物件开关；**不在** `RaycastListener.OnClick` 路径上再判一次。

### 4.2 「玩家位置占位」证据（钉死）

| 问题 | 答案 |
|------|------|
| 是否强制 overlap？ | **是**。`RaycastListener.OnClick` L43：`AreCollidersOverlapping(component.InteractiveCollider)` 为真才 `onClickEvent.Invoke()` |
| 用哪个 Collider？ | 物体：`RaycastListener.listenerCollider`（通常 Body 上 Collider2D）；玩家：`PlayerLogic` 的 `InteractiveComponent.InteractiveCollider` |
| 远处点 NPC？ | 射线可命中 Listener，但 **OnClick 因不相交静默失败** |
| 是不是策划误解？ | **否**——代码门槛 |

```37:52:Assets/Scripts/Game/GameRuntime/Entities/Component/Interactive/RaycastListener.cs
        public virtual void OnClick(GFEntity playerEntity)
        {
            if (playerEntity.Logic is PlayerLogic playerLogic)
            {
                var component = playerLogic.componentSystem.GetComponent<InteractiveComponent>();

                if (component != null && AreCollidersOverlapping(component.InteractiveCollider))
                {
                    // ...
                    onClickEvent.Invoke();
                }
            }
        }
```

### 4.3 方案对比

| 方案 | 大意 | 裁定 |
|------|------|------|
| **A** | `RaycastListener` 增加序列化开关（如 `requirePlayerOverlap`，默认 **true**）；物品勾 false | **主推**：改动小；NPC 默认不变 |
| **B** | 新建 `RemoteRaycastListener`，OnClick 不查 overlap | 可选；不改旧类默认，多一种组件 |
| C | 放大物品碰撞盖满房间 | **否决**（脏、误触） |
| D | 只用 E、走近 | **否决**（产品要远处点击） |

**主方案 A 文件级清单**：

| 文件 | 操作 |
|------|------|
| `RaycastListener.cs` | 加 Flag；`OnClick` 在 Flag 为 false 时跳过 overlap |
| 物品场景实体 | Body 挂 Listener 并勾远程；其余同 NpcChair |
| `SimpleStoryTrigger` / 对话 UI | **不改** |
| NPC 现有 Listener | 保持默认 require overlap |

**替代 B**：新类 + 物品只挂子类；旧 NPC 零 diff。

### 4.5 对话中再点 / Pause

`RaycastComponentGSM`：`ProcedureComponentGM.Pause` 为真时**不处理点击**。对话中若进入 Pause，则自然禁点——对拍现网即可，不必另造。记 OPEN：是否与「对话中能否再点物品」产品一致。

多命中：循环所有 hit，对每个**不同** `InteractiveComponent` 各调一次 OnClick——重叠时可能**多个**都触发（若都远程且都命中）。OPEN：是否只要最近/最上层一个。
