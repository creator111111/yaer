### 1.3 项目启动方式

**正式出包 Build Settings 只应挂一个场景：**

- `Assets/GameRes/Scenes/InitScene.unity`

**当前磁盘** `EditorBuildSettings` 是 **All Scenes**（Init + 各村/林/调试场景），适合编辑器联调；**出包前必须切回 Default。**

启动链（Game Framework Procedure）：

1. 用 **Unity 2020.3.48f1** 打开 `Yaer` 文件夹。  
2. **日常开发**：菜单 `Game Framework / Scenes in Build Settings / All Scenes`。  
3. Play：**必须从 InitScene 启动**（不要直接 Play 关卡当正式流程）。  
4. `ProcedureLaunch` → `ProcedurePreload` → 切 **`StartScene`** → `ProcedureMenu` → 进局 `ProcedureGame`。

| 角色 | 场景路径 | 常量 |
|------|----------|------|
| 首场景 | `Assets/GameRes/Scenes/InitScene.unity` | `SceneName.InitScene` |
| 主菜单 | `Assets/GameRes/Scenes/StartScene.unity` | `SceneName.StartScene` |
| 新游戏开场 | `Assets/GameRes/Scenes/NewGameScene.unity` | `SceneName.NewGameScene` |
| 主推可玩村 | `Assets/GameRes/Scenes/Village_KenMuNi1.unity` | `SceneName.Village_KenMuNi1` |

代码锚点：

- `Assets/Scripts/Game/GameRuntime/Procedure/ProcedureLaunch.cs`
- `Assets/Scripts/Game/GameRuntime/Procedure/ProcedurePreload.cs`
- `Assets/Scripts/Game/Static/Name/Res/SceneName.cs`

编辑器可按 ESC 跳过 Init（`InitFormLogic`）。开发工具：`Editor / GameManagerTool`（**Ctrl+G**）。

### 1.4 Windows 打包方法

以工程根 `README.md` 为准（四步）：

1. **先构建 AssetBundle**（见 §2.3）。  
2. 菜单 **`Game Framework / Scenes in Build Settings / Default Scenes`** → 只留 `InitScene`。其它可玩场景走 AB，不进 Player Build。  
3. `File / Build Settings` → **PC, Mac & Linux Standalone** → Windows → **x86_64** → **Build**。  
4. 打完若要继续开发：菜单 **`All Scenes`**。

| 用途 | 路径 |
|------|------|
| Default / All Scenes 菜单 | `Assets/Scripts/GameFramework/Editor/GF/Misc/BuildSettings.cs` |
| Default 场景配置 | `Assets/Scripts/GameFramework/Configs/BuildSettings.xml` |
| AB 路径配置 | `Assets/Editor/GFAssetBundleSettings/GFAssetBundlesSettings.cs` |

**没有** Jenkins / 独立命令行出包脚本；业务也**没有**自定义 `GetCommandLineArgs`。出包前确认 StreamingAssets 已放入对应平台 AB。

### 2.3 资源管理（AssetBundle）

主路径是 **Game Framework AB**，不是 Addressables。

编辑器默认 **`EditorResourceMode = true`**（`GameFramework.prefab`），Play 从 AssetDatabase 加载，**不必每次打 AB**。出包必须打 AB 并放入 StreamingAssets。

#### 制作流程（与 README 一致）

1. 资源放到 `Assets/GameRes/`。  
2. `Game Framework / Resource Tools / Resource Editor`：勾进 AB。  
3. 未识别类型：改 `Assets/Editor/GFAssetBundleSettings/xml/ResourceEditor.xml` 的 TypeFilter。  
4. `Resource Builder` 构建。  
5. 把导出目录里 **目标平台** 包 **复制到 `StreamingAssets`**。

| 文件 | 作用 |
|------|------|
| `…/xml/ResourceCollection.xml` | AB 资源集合 |
| `…/xml/ResourceEditor.xml` | 扫描根 = `Assets/GameRes` |
| `…/xml/ResourceBuilder.xml` | 构建参数 |
| `GFAssetBundlesSettings.cs` | XML 路径 Attribute |

`ResourceBuilder.xml` 现网要点：

- `Platforms = 2` → **Windows64**  
- `InternalResourceVersion = 3`  
- 压缩：LZ4 类（`AssetBundleCompression=1`）  
- **`OutputDirectory = E:/Yaer/yaer/Yaer/Assetbundles`** —— 换机必须在 Builder 窗口改成本机路径  
- `ForceRebuildAssetBundleSelected = True`

加载链：`ResComponentGM.LoadAsset` → GF `ResourceComponent` → 编辑器 EditorResourceHelper / 真机 StreamingAssets Package。

**无完整热更管线**（无版本 CDN）。`ResourceMode` 虽支持 Updatable，当前是 Package 输出。
