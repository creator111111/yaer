## 一、一句话定位

台本只选一个 **`DialogueFaceType`**；同一枚举驱动三条消费线：

| 线 | 显示什么 | 现网主用途 |
|----|----------|------------|
| **场景大立绘** | Painting Prefab 的 `Faces/*` 子物体显隐 | 对话场景全身/半身立绘 |
| **字幕 Mask 立绘** | 嵌在 `NormalDialogueNewPanel` Mask 窗里的同款 Painting | **对话框旁「小表情」真源** |
| **旧图集小头像** | `Avatar_*.spriteatlas` → `Image.sprite` | **历史列表**；未开 Mask 的旧面板回退 |

> 生活类比：导演对讲机只喊一个频道号（枚举）；舞台大灯（场景立绘）和窗后小灯（Mask）都认这个号切脸；旧贴纸册（图集）主要留给历史翻看。

## 二、总览调用链

```
SayEx / CSV FaceType
  → StatementNodeEx → SubtitlesRequestInfoEx
  → DialogueTMPUGUI
       ├─ actor.RefreshAvatar(FaceType)
       │     ├─ DialogueAvatarLoader → 图集 GetSprite(枚举名)     ← 历史 / 旧 Portrait
       │     └─ OnRefreshAvatarEvent → 场景 StoryFormPainting.UpdateFace(角色键)
       └─ OnGetNewStatement(role, FaceType, text)
             └─ DialogueMaskAvatarPresenter.Apply → Mask 内 Painting.UpdateFace(角色键)
```

**关键开关**：`DialogueTMPUGUI.useMaskAvatar`  
- `true`（`NormalDialogueNewPanel` 已开）：`OnGetAvatar` **不再点亮**旧 `Portrait` Image，避免与 Mask 双影；Loader 仍会跑（历史仍可能用图集）。  
- `false`：旧行为，Portrait 显示图集 Sprite。

## 四、大立绘：`StoryFormPainting`

### 4.1 基类机制

路径：`…/Painting/StoryFormPainting.cs`

1. Awake：收集 `Faces/` 下子物体 → 字典。  
2. Start：找父级 `DialogueActorEx`，订阅 `OnRefreshAvatarEvent`。  
3. `UpdateFace(string faceName)`：关掉全部脸层，打开 **name 完全等于** `faceName` 的那一层；找不到则全关。

变脸 = **切子物体**，不是换一张 Sprite 到同一 Image。

### 4.2 角色键规则（台本枚举 → Faces 子物体名）

| 角色 / Prefab | 键规则 | 脚本 |
|---------------|--------|------|
| **雅儿 GoOut** `GoOutStoryYaerPainting` | `Armor_NoHeadWear_{枚举}`；**`Normal` → `Armor_NoHeadWear_Smile`** | `GoOutStoryYaerPainting.ResolveGoOutFaceKey` |
| **雅儿 Dress** `YaerPainting` / `NewGameYaerPainting` | Prefab 为 `Dress_Crown_*`；开场用 `NewGameYaerPainting` 拼键；空壳 `YaerPainting` 若只传裸枚举会对不上节点 | 见各脚本 |
| **古莎** `GushaPainting` | 裸枚举名（`Smile`、`LuoMo`…） | `GuShaPainting` |
| **Amy / Aliy** | 裸枚举名 | 对应 Painting |
| **King** | 裸枚举名；**不在 Mask MVP** | `KingPainting` |

### 4.3 古莎为难衣 `spcFaces`

`GuShaPainting` 在切脸后额外切衣服：

| 列表内表情 | 衣服 |
|------------|------|
| `Awkward` / `Cry` / `Daze` / `Sad` | `clothes_other`（为难体） |
| 其它（含 `LuoMo` / `LuoMo2`） | `clothes_normal` |

新表情默认 **不进** `spcFaces`，除非策划明确要为难衣。

### 4.4 主要 Prefab 路径

> 目录拼写为历史遗留：`DialougeProtrait`

| Prefab | 路径 |
|--------|------|
| 雅儿 GoOut | `Assets/Prefabs/DialougeProtrait/GoOutStoryYaerPainting.prefab` |
| 雅儿 Dress | `Assets/Prefabs/DialougeProtrait/YaerPainting.prefab` |
| 古莎 | `Assets/Prefabs/DialougeProtrait/GushaPainting.prefab` |
| Amy / Aliy / King | 同目录对应 `*Painting.prefab` |

场景侧立绘由对话 Form / 场景容器挂实例；Mask 侧嵌的是**同母体 Prefab 实例**（继承 Faces 节点）。

## 五、对话框「小表情」：Mask 立绘（现网真源）

### 5.1 结构

```
NormalDialogueNewPanel
└── Bottom
    ├── Mask                    ← 裁剪窗 ≈ 282×282
    │   └── YaerAvatarRoot      ← DialogueMaskAvatarPresenter
    │       ├── GoOutStoryYaerPainting
    │       ├── YaerPainting    ← Dress；MVP 默认不用
    │       ├── AmyPainting
    │       ├── AliyPainting
    │       └── GushaPainting
    └── Portrait / Yaer         ← 旧图集 Image；useMaskAvatar 时保持关
```

UI Prefab：`Assets/GameRes/Prefabs/UI/NormalDialogueNewPanel.prefab`  
摆位细则见同目录 Mask Prefab 技术说明。

### 5.2 驱动脚本

`DialogueMaskAvatarPresenter`（挂在 `YaerAvatarRoot`）：

1. 订阅 `DialogueTMPUGUI.OnGetNewStatement`（**不**订场景 Actor——UI 壳下无 `DialogueActorEx`）。  
2. 按角色互斥显隐五个 Painting。  
3. `UpdateFace(ResolveFaceKey(role, faceType))`：  
   - 雅儿 MVP：`yaerUseGoOutOnly = true` → `ResolveGoOutFaceKey`  
   - 古莎 / Amy / Aliy：裸枚举名  

未支持角色（King 等）：Mask 保持空，不残留上一句。

### 5.3 与旧「小头像图集」的关系

| | Mask 立绘 | Avatar 图集 |
|--|-----------|-------------|
| 是什么 | 嵌套 Painting，切 `Faces` 层 | SpriteAtlas 贴纸 |
| 取键 | 与大立绘同规则（雅儿有前缀） | **永远** `faceType.ToString()` 裸名 |
| 现网字幕条 | **真源** | 仍加载但不激活 Portrait |
| 历史对话 | 不走 Mask | **仍走图集** |
| 新产品决策 | 新表情优先挂 Painting | **不再要求补四套/角色图集**（0804 拍板） |

缺图集 Sprite 时：历史头像可能隐藏；**不影响**场景大立绘与 Mask。

## 七、如何新增一个表情（最小闭环）

以「已有美术、已在 Prefab 绑好 Faces」为前提（常见施工）：

1. **`DialogueFaceType.cs` 末尾追加**成员，名 = 约定键后缀 / 裸名（禁止中文节点名、禁止插中间）。  
2. Prefab：`Faces` 子物体名符合上表键规则，Image 绑好图（程序默认不改绑图）。  
3. 古莎：若要为难衣，再把枚举写入 `GuShaPainting.spcFaces`；否则不动。  
4. **不必**改 `UpdateFace` / Loader / Mask Presenter（键规则未变时）。  
5. **不必**补 Avatar 图集（除非历史也要显示）。  
6. 台本 SayEx / CSV 填新枚举名；用 DialogDebug 验：场景立绘 + Mask 窗内对应层亮、其它脸关。

若 Prefab 节点尚未建：先美术挂层再加枚举；仅加枚举而节点缺失 → 运行时全脸隐藏。

## 九、常见坑

| 坑 | 说明 |
|----|------|
| 枚举插中间 | 旧台本表情全体错位 |
| 雅儿键前缀 | 台本写 `Smile`，GoOut 节点是 `Armor_NoHeadWear_Smile` |
| `Normal` 雅儿 GoOut | 无 `…_Normal` 节点，代码回退 Smile |
| 图集缺新脸 | 历史隐藏；Mask/大立绘仍可正常 |
| Dress 裸枚举 | `YaerPainting` 空子类 + `Dress_Crown_*` 节点易对不上；村线 MVP 用 GoOut |
| Mask 与场景不同实例 | 同 Prefab，但是两个实例；母体改 Faces 后两边都继承 |
| 以为小表情=立绘截图 | **不是**；现网是 Mask 嵌立绘，不是自动裁切大立绘 |
| Mask 首句被 Smile 盖掉 | GoOut 首次 `SetActive` 后 `Start→SetDefaultPainting` 曾强制 Smile。现网：无 Actor 时**跳过**强制 Smile，表情交给 Presenter |

## 十、验收建议（DialogDebug / 真对话）

1. SayEx 下拉能选到目标 `FaceType`。  
2. 场景 Hierarchy：对应角色 Painting 下 **仅**目标 Faces 子物体 Active。  
3. 字幕 Mask：同角色实例同步切脸；换说话人时其它 Painting 关掉。  
4. 古莎：确认为难衣是否符合 `spcFaces` 预期。  
5. 历史：未补图集则新表情头像可隐藏（已知、可接受）。
