## 1. 一句话结论

**业务只填「要去哪」（目标场景名）；统一走 `LoadSceneComponentGSM.LoadScene`；玩家落点由目标场景 `EnterPosConfig` 按「刚离开的场景名」匹配；表现上默认黑幕，可选 Loading 读条。门上的 `bornPos` 不参与运行时坐标。**

---

## 2. 换场总览（程序员速查）

### 2.1 调用链

```
[入口：SceneChangeDoor / 对话 LoadSceneTaskAction / MapFormLogic / Procedure …]
        │
        ▼
LoadSceneComponentGSM.LoadScene(sceneName, stayAction, blackFade)
        │  可选 BlackPanel 黑幕 FadeShow → onShowEnd 内 stayAction
        │  当前 BaseGameSceneManager.OnExitScene / OnShutDown
        ▼
ChangeSceneComponentGM.LoadScene(LoadSceneArgs)
        │  记录 LastSceneName = 卸载前的 NowSceneName
        │  非 InitScene：先 Unload 当前场景，再 Load 目标
        ▼
GF SceneComponent.LoadScene(Assets/GameRes/Scenes/{sceneName}.unity)
        │
        ▼
新场景 BaseGameSceneManager.Awake → OnInit → OnGameSceneManagerReady
        │  InitPlayer → SetPlayerPos（EnterPosConfig / 存档 / DefaultBornPos）
        │  PlayerLogic 按 Config.isFightingScene 换 Home/Combat 动画控制器
        └  Village_KenMuNi1 等：RefreshVillageExplorationFromActiveScene
```

### 2.2 核心类与路径

| 类 / 资源 | 路径 | 职责 |
|-----------|------|------|
| `SceneChangeDoor` | `Assets/Scripts/Game/GameRuntime/Entities/SceneEntities/CommonEntity/SceneChangeDoor.cs` | 交互进门；填 `NextSceneName`；调 `LoadScene` |
| `LoadSceneComponentGSM` | `.../GameSceneManager/Component/LoadSceneComponentGSM.cs` | 黑幕 / Loading、退出旧 GSM、触发 GF 加载 |
| `ChangeSceneComponentGM` | `.../GameMgr/Component/ChangeScene/ChangeSceneComponentGM.cs` | `NowSceneName`、`LastSceneName`、卸载顺序 |
| `BaseGameSceneManager` | `.../GameSceneManager/Base/BaseGameSceneManager.cs` | `SetPlayerPos`、`EnterPosConfig`、模块初始化 |
| `SceneEntityComponentGSM` | `.../GameSceneManager/Component/SceneEntityComponentGSM.cs` | `objRoot` / `sceneObjs`；交互实体登记 |
| `SceneName` | `Assets/Scripts/Game/Static/Name/Res/SceneName.cs` | 场景名字常量（推荐全项目引用） |
| `SceneAssetPath` | `Assets/Scripts/Game/Static/Path/SceneAssetPath.cs` | `Assets/GameRes/Scenes/{名}.unity` |
| 门预制体 | `Assets/GameRes/Prefabs/MapInteractive/SceneChangeDoor.prefab` | 标准左右门；`Stairs` 等变体见 `Assets/Prefabs/Stairs.prefab` |

### 2.3 其它入口（与门规则相同）

| 入口 | 说明 |
|------|------|
| NodeCanvas `LoadSceneTaskAction` | 对话图内显式换场；对话结束**不会**自动切场景 |
| `MapFormLogic` | 地图 UI 选点跳转 |
| `ProcedureComponentGM` | 流程 / 读档开局等 |
| `Map.LeftDoor` / `RightDoor` | 标准 `Map` 层级下的 `SceneChangeDoor`，由 `Map.OnInit` 初始化 |

## 3. 目标场景名（NextSceneName）

### 3.1 `SceneChangeDoor` Inspector 字段

| 字段 | 含义 | 注意 |
|------|------|------|
| **NextSceneName** | 目标场景逻辑名 | 必须与 `.unity` 文件名一致 |
| **TriggerWhenMoveIn** | 走进 Trigger 即换场 | 无需按 E；序章部分门为 `true` |
| **ShowLoadingUI** | 先开 LoadingPanel 再换场 | 默认 `false`，一般用黑幕 |
| **CheckNextSceneUnlock** | 是否允许进入的委托 | 常由 `MapControlComponentGSM.SetSceneUnlockCondition` 绑定 |
| **bornPos** | 策划对照用 Transform | **运行时无人读取**，不能代替 `EnterPosConfig` |

### 3.2 场景资源约定

1. 在 `SceneName.cs` 增加 `public const string`，避免魔法字符串。  
2. 场景文件放在 `Assets/GameRes/Scenes/{SceneName}.unity`。  
3. 新场景须加入 Resource Editor / AB 与 Scenes in Build（见根目录 `README.md`）。  
4. 常量表未登记的场景（如部分 `Village_House*`）仍可在门上填字符串，但需自行保证 GF 能加载。

### 3.3 标准 Map 左右门

- `MapLeft/LeftDoor`、`MapRight/RightDoor` 挂 `SceneChangeDoor`。  
- 左门通常指向左侧邻接场景，右门指向右侧邻接场景。  
- 示例：`ForestScene` 左门 → `ForestEastScene`，右门 → `HomeScene1`。

## 4. 切换后玩家位置（EnterPosConfig）

### 4.1 运行时逻辑（`BaseGameSceneManager.SetPlayerPos`）

| 优先级 | 条件 | 落点 |
|--------|------|------|
| 1 | 读档开局 `ProcedureComponentGM.archiveStart` | 存档 `PlayerSceneData.pos`，**忽略** EnterPosConfig |
| 2 | 正常换场 | `ChangeSceneComponentGM.LastSceneName` 与目标场景 `EnterPosConfig[].lastScene` 匹配 → 用该项 `pos` 的 `Transform.position` |
| 3 | 无匹配 | `MapControlComponentGSM.DefaultBornTsf`（`Map/DefaultBornPos`） |

**易错点**

- `SceneChangeDoor.bornPos`、`Map.LeftBorn` / `RightBorn` **不会**被 `SetPlayerPos` 自动选用。  
- 多入口不同落点：在**目标场景**配多条 `EnterPosConfig`，`lastScene` 填不同来源场景名。

### 4.2 配置步骤（在「被进入」的场景）

在根物体 **`SceneManager`** 上：

1. 展开 **Enter Pos Config**。  
2. 增加元素：**last Scene** = 来源场景名（如 `ForestScene`）；**pos** = 门口内侧空物体；**Date Pass** 可选。  
3. 在**来源场景**的门上填 **Next Scene Name** 指向本场景。

### 4.3 参考实例

| 目标场景 | EnterPosConfig 示例 |
|----------|---------------------|
| `HomeScene1` | `ForestScene` → 门口；`HomeScene2` → 另一 Transform |
| `Village_KenMuNi1` | `HomeScene1`、`ForestEastScene`（可带 DatePass） |
| 从村进家 | 须在 `HomeScene1` 增加 `lastScene: Village_KenMuNi1` + 室内落点 |

## 5. 转场表现：黑幕 vs 读条

| 对比 | LoadingPanel | BlackPanel（黑幕） |
|------|----------------|-------------------|
| 典型用途 | 插图 + Tips + Slider | 全屏渐黑 / 渐亮 |
| 触发 | `SceneChangeDoor.ShowLoadingUI == true` | `LoadScene(..., blackFade: true)`（默认） |
| 进度 | **假进度**（约 2～3 秒协程），非真实加载百分比 | 无读条 |
| 预制体 | `Assets/GameRes/Prefabs/UI/LoadingPanel.prefab` | BlackPanel（预加载见 InitSceneResConfig） |

同一次切场景一般**不会**黑幕与 Loading 同时承担主表现，由门上 `ShowLoadingUI` 与 `LoadScene` 的 `blackFade` 组合决定。详见 [加载地图的加载条功能](./加载地图的加载条功能.md)。

## 6. 室内 / 户外手感（换场后）

「室内」分三层，**不要混为一谈**：

| 层级 | 配置 | 室内示例 | 户外示例 |
|------|------|----------|----------|
| 动画 / 移动 | `GameSceneManagerConfig.isFightingScene` | `false` → Home 控制器 | `true` → Combat 控制器 |
| 脚步声 | `GetCurSceneTerrainType()` | `IndoorType` | `LandType`（森林、村庄） |
| 村庄 2.5D | 场景名 == `Village_KenMuNi1` | **不适用**（室内勿用该村名） | `TownPlayerLocomotion` + WalkArea |

室内接入检查：专用 SceneManager 子类、`isFightingScene = false`、目标场景 `EnterPosConfig`、来源门 `NextSceneName`、换场后 Home 动画 + 室内脚步。

## 7. 按 E 进门与 `Stairs`（交互 + 换场）

### 7.1 E 提示链路

```
PlayerLogic.Update → checkCanAddKeyTipsInOtherEntity()
  → GetFirstCanTouchEntiy() 遍历 sceneObjs
  → InteractiveComponent.bounds 与玩家 Event 碰撞盒相交
  → entityControll.AddKeyTipsNode() 显示 E

按 E → OnInteractive() → SceneChangeDoor.EnterDoor → LoadScene
```

**重要**：E 提示**不依赖** Trigger 的 `OnTriggerEnter`；用的是 **Collider2D.bounds 相交**（玩家 `Event` 子物体 BoxCollider2D ↔ 物体 `interactiveCollider`）。

### 7.2 可交互门必备条件

| 检查项 | 要求 |
|--------|------|
| 层级 | 挂在 `SceneEntityComponentGSM.objRoot` 子树下 |
| 列表 | `sceneObjs` 含该物体上的 `SceneEntity`（改 Hierarchy 后点 Inspector 触发 `OnValidate` 或手拖） |
| 组件 | `SceneEntity` + `SceneChangeDoor` + `InteractiveComponent` + `BaseEntityControll` |
| 引用 | `interactiveCollider` → 根 BoxCollider2D（Trigger）；`BaseEntityControll.interactiveComponent` 非空 |
| 初始化 | 独立门靠 `SceneEntity.OnInit`；`Map` 左右门另由 `Map.OnInit` 调 `SceneChangeDoor.OnInit` |
| 场景开关 | `BaseGameSceneManager.isCanTouchWithOther == true` |

### 7.3 村庄场景额外注意

- 玩家 **Z 轴**由 `TownPlayerLocomotion` 进村时锁定（通常 `0`）；交互物体 **Position Z 应为 0**，勿用贴图排序用的 `z=6` 等，否则 bounds 在 Z 轴不相交、永远无 E。  
- 交互盒 **X/Y** 须与门口 Walk 区玩家站位一致；仅挪到 `objRoot` 但坐标仍在远处也会无 E。  
- Play 时 Console：`[BaseGameSceneManager] GetFirstCanTouchEntiy result=null` 表示仍未相交。

## 8. 场景管理器（SceneManager）初始化

### 8.1 生命周期

- 每玩法场景根节点 **`SceneManager`** 挂 **`BaseGameSceneManager` 子类**。  
- `Awake` → `OnInit()` → 异步就绪后 `GameManager.OnGameSceneManagerReady`。  
- `OnInit` 内必须先 `base.OnInit()`，再写本场景业务。

### 8.2 常见运行时错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 进村即 `NullReferenceException`，组件变灰 | `OnInit` 里 `GetSceneEntityLogic<T>()` 找不到实体（如森林莱/王/林恩） | 村里未摆对应 NPC 时应用空判断；或从 `ForestScene` 复制实体到 `objRoot` 并刷新 `sceneObjs` |
| `GetSceneEntityLogic` 报 CS0246 | 缺少 `using Game.GameRuntime.Entities.Base.BaseSceneObj` | 补 using |
| `config == null` 警告 | 换 SceneManager 组件后未重绑 `GameSceneManagerConfig` | Inspector 重新挂载 Config |
| 换组件后剧情音效失效 | 剧情脚本 `FindObjectOfType<ForestSceneManager>()` | 改为 `GameManager.GetGameSceneManager()` 或 `BaseGameSceneManager` |

`Village_KenMuNiSceneManager` 对齐森林 BGM/存档逻辑，但**不保证**场景内必有森林同款 NPC；查找实体应允许缺失。

## 9. 新场景接入换场（推荐顺序）

1. `SceneName.cs` + `Assets/GameRes/Scenes/YourScene.unity` + 构建配置。  
2. 复制最接近的场景，新建 `YourSceneManager : BaseGameSceneManager`，设置 `nowSceneName`。  
3. 挂合适的 `GameSceneManagerConfig`（室内 `isFightingScene = false`）。  
4. 需要标准横版门时：按 `Map` 命名摆 `LeftDoor` / `RightDoor` / `DefaultBornPos`。  
5. **本场景** `EnterPosConfig`：配置各来源场景的落点。  
6. **邻接场景**门上 `NextSceneName` 指向本场景；反向入口同样配 EnterPosConfig。  
7. 独立交互门（如 `Stairs`）：放 `objRoot` 下，刷新 `sceneObjs`，对齐碰撞盒与 `NextSceneName`。  
8. Play 验证：无加载错误、`LastSceneName` 正确、落点与动画/脚步符合预期。

更完整的场景必备对象见 [搭建新场景手册](./搭建新场景手册.md)。

## 10. 验收清单（QA / 策划）

| 编号 | 操作 | 期望 |
|------|------|------|
| Q1 | 从 A 场景进门到 B | 黑幕或 Loading 正常；无 Console 加载失败 |
| Q2 | 换场后站立位置 | 落在 B 的 `EnterPosConfig` 对应门口，而非随机 DefaultBorn |
| Q3 | 室内场景 | Home 行走动画 + 室内脚步 |
| Q4 | 村庄楼梯 / 门 | 靠近出现 E；按 E 换场；目标场景有反向 EnterPosConfig |
| Q5 | 进村 / 进家 | SceneManager 保持启用，无 Awake NRE |
| Q6 | 对话仅结束 | **不**自动换场（除非对话图内有 LoadScene 节点） |
