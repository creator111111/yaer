# 道具栏位系统（PlayerBagData / 快捷栏 / 战斗 HUD）

面向策划：说明**主道具背包**、**6 格消耗品快捷栏**与**战斗界面快捷使用**的数据来源、存档字段、堆叠上限与测试方式；并记录原备忘三条的闭环说明。

---

## 1. 功能概述

- **主道具数据**由 [`PlayerBagData`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameMgr/Component/Archive/ArchiveDataClass/Player/PlayerBagData.cs) 持有：字典 `mainItemDic`（道具名 → [`MenuFormMainItemInfo`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MenuFormMainItemInfo.cs)），内含格子顺序 `index`、数量 `num`、类型等。
- **消耗品快捷栏**为固定长度 **6** 的 `quickItem` 字符串数组：按背包内消耗品顺序填充前 6 个空位，用于战斗 HUD 与快捷逻辑（见同文件 `DataChanged`、`RefreshCostItem` 等）。
- **菜单中的道具页**：[`MenuFormLogic`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MenuFormLogic.cs)、[`MenuFormMainItemBtn`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MainItemPage/MenuFormMainItemBtn.cs) 等与 `ArchiveComponentGM.GetData<PlayerBagData>()` / 场景内 `GetArchiveData<PlayerBagData>()` 同源数据（均指向 [`ArchiveComponentGM`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameMgr/Component/Archive/ArchiveComponentGM.cs) 缓存）。
- **战斗界面 6 格图标与数量**：[`FightingCanUsed`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Fighting/FightingCanUsed.cs) 监听 **`PlayerBagData.OnDataChange`**（静态事件）及读档完成事件，刷新 `quickItem` 对应槽位。

道具类型枚举见文件顶部 **`BagItemType`**：任务/贵重、消耗品、素材等；配置驱动见 [`MainItemConfig.json`](f:/Yaer/yaer/Yaer/Assets/GameRes/Config/MainItemConfig/MainItemConfig.json)，主道具枚举 [`EMainItemName`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/Static/Enum/Goods/EMainItemName.cs)。

## 2. 设计常量：单种道具堆叠上限

- 代码常量：**`PlayerBagData.MaxStackPerItem = 10`**（每种主道具数量上限为 10）。
- 获得道具时 `AddMainItem` 会钳制数量；读档后若旧存档超过上限，会在解析时统一钳制（见代码 `ClampAllItemStacks`）。

## 5. 测试与调试

### 5.1 打开测试面板（编辑器）

在 [`BaseGameSceneManager`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/GameSceneManager/Base/BaseGameSceneManager.cs) 中，`#if UNITY_EDITOR` 下按 **F1** 可打开 **`AA_TestPanel`**（若未打开则 `OpenUIForm`）。

### 5.2 单种道具

- 指令：**`添加道具(道具ID,数量(默认1))`**
- 在对应行的输入框填 **`道具ID,数量`**（英文逗号），道具 ID 为 **`EMainItemName` 枚举整型**（从 0 起，与枚举顺序一致）。
- 数量受 **`MaxStackPerItem`** 限制，超出部分不会增加。

### 5.3 一键填充全部主道具

- 指令：**`一键添加全部主道具(数量默认10,可填一个数字)`**（实现见 [`AA_TestPanel`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/AA_TestPanel/AA_TestPanel.cs)）
- 不填参数时，每种枚举对应道具各添加 **`MaxStackPerItem`（10）** 个（仍受堆叠上限约束）；填一个数字则作为每种添加数量。

## 6. 原备忘任务闭环

| 原问题 | 处理说明 |
|--------|----------|
| 有没有一键添加道具的测试面板功能？ | **有**：`AA_TestPanel` 支持单种添加；并已增加 **一键添加全部主道具** 指令（见 5.3）。 |
| 所有道具的上限都应该是 10 个 | **已实现**：`PlayerBagData.MaxStackPerItem` 与 `AddMainItem` / 读档钳制。 |
| 道具栏死亡之后读档有显示 bug | **已修复向**：[`FightingCanUsed.OnDisable`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Fighting/FightingCanUsed.cs) 在部分流程中因 `GetGameSceneManager() == null` 提前 return，导致 **未取消 `PlayerBagData.OnDataChange` 订阅**，可能重复订阅、表现异常；现改为 **始终取消静态事件订阅**。 |

## 8. 策划验收清单（建议）

1. 通过测试面板将某一种道具加到超过 10，背包内数量不超过 10。
2. 读档后数量不超过 10；战斗快捷栏与菜单展示一致。
3. 死亡 → 读档后，战斗道具栏无错位、重复刷新或图标残留（与 `FightingCanUsed` 订阅修复相关）。
4. 「一键添加全部主道具」后，战斗栏与背包能合理显示（消耗品占快捷前序格位等规则以现有逻辑为准）。
