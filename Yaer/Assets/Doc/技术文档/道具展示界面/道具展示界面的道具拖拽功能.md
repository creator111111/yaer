# 道具展示界面的道具拖拽功能（ItemShowPanel / MenuFormMainItemBtn）

面向策划与程序：说明在 **道具展示界面**（`ItemShowPanel`）中，玩家如何**拖拽道具格交换顺序**，以及数据如何写回背包、对**消耗品快捷栏**的影响。

---

## 1. 功能概述

- 道具展示界面由 [`ItemShowFormLogic`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/ItemShowPanel/ItemShowFormLogic.cs) 驱动，主列表区域使用 [`MenuFormMainItemPage`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MainItemPage/MenuFormMainItemPage.cs) 与格子预制体上的 **`MenuFormMainItemBtn`**。
- **拖拽交换顺序**的逻辑全部写在 [`MenuFormMainItemBtn`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MainItemPage/MenuFormMainItemBtn.cs) 内（实现 `IBeginDragHandler`、`IDragHandler`、`IEndDragHandler`），与「菜单里主道具页」共用同一套格子脚本。
- 拖拽成功后，通过 [`PlayerBagData.SwapItemsIndex(MenuFormMainItemInfo, MenuFormMainItemInfo)`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameMgr/Component/Archive/ArchiveDataClass/Player/PlayerBagData.cs) 交换两条道具在存档中的 **`index`**，并刷新消耗品快捷栏与 `OnDataChange`（见第 4 节）。

## 3. 交互流程（按帧）

### 3.1 可拖拽条件

- **仅左键**（`PointerEventData.InputButton.Left`）。
- 当前格子的 **`item` 不为 null 且 `item.num > 0`**（无道具或数量为 0 时不拖拽）。

### 3.2 `OnBeginDrag`

- 将 **`Button.interactable` 设为 false**，本格 **`Image.raycastTarget` 设为 false**（避免拖拽时挡住射线检测）。
- **`GridLayoutGroup`（`grid`）设为 false**，避免布局在拖拽过程中强制拉回格子位置。
- **`root` 节点 `SetAsLastSibling()`**，使被拖格子画在最上层。
- 记录起始鼠标位置 `start`，用于后续偏移计算。
- **`mask` 关闭**（避免遮罩影响表现，以预制体为准）。

### 3.3 `OnDrag`

- 使用 **`localPosition = pos + (Input.mousePosition - start) / uiCanvas.scaleFactor`** 跟随鼠标；其中 `pos` 为 `OnEnable` 时缓存的初始 `localPosition`，保证松手后能还原。
- **注意**：依赖 **`uiCanvas`** 序列化引用正确（一般为道具界面所在 Canvas），否则移动量会偏大或偏小。

### 3.4 `OnEndDrag`

**顺序要点（避免与邻格堆叠）**：`GridLayoutGroup` 只约束 **Content 的直接子节点（`root`）**；拖拽时改的是格子内 **`rt.localPosition`**。若在 **`rt` 仍带偏移**时开启 `grid`，子物体图标会暂时与邻格重叠。因此实现上为：

1. **先将 `rt.localPosition` 还原为 `pos`**（拖拽前缓存的本地坐标）。
2. 将 **`root` 的 sibling 索引**设回 **`item.index`**（拖拽前数据顺序）。
3. 通过 **`eventData.pointerCurrentRaycast.gameObject.GetComponentInParent<MenuFormMainItemBtn>()`** 取指针下的目标格；仅当 **目标格存在 `item`、且不是本格（`cell != this`）、且不是同一 `MenuFormMainItemInfo` 引用** 时：
   - 调用 **`SwapItemsIndex(item, cell.item)`**；
   - 再按交换后的 **`cell.item.index` / `item.index`** 设置 **`cell.root`** 与 **本格 `root`** 的 **`SetSiblingIndex`**。
4. **最后**将 **`grid.enabled = true`**（整段拖拽只在此处开启一次），并对 **`grid` 所在 `RectTransform`** 调用 **`LayoutRebuilder.ForceRebuildLayoutImmediate`**，保证排版与数据一致。
5. 恢复 **`mask`**、`Button`、**`Image.raycastTarget`**。

若未命中有效目标格、或落在自身格上，**不写背包**，仅完成 1～2 步与第 4～5 步。

## 4. 数据与副作用

```mermaid
flowchart LR
  dragEnd[OnEndDrag命中另一格]
  swap[PlayerBagData.SwapItemsIndex]
  refresh[RefreshCostItemOnIndexChane]
  evt[OnDataChange]

  dragEnd --> swap --> refresh --> evt
```

- **`SwapItemsIndex(i1, i2)`**（`MenuFormMainItemInfo` 重载）：交换两个 `MenuFormMainItemInfo` 的 **`index`** 字段。
- 若涉及**消耗品**（`BagItemType.CostItem`），会 **`RefreshCostItemOnIndexChane`**，按当前背包顺序**重建前 6 个消耗品对应的 `quickItem` 快捷栏**，并触发 **`OnDataChange`**（影响战斗界面快捷道具显示等）。
- 非消耗品交换仅改 **`index`**，不改变 `quickItem` 规则（以 [`PlayerBagData`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameMgr/Component/Archive/ArchiveDataClass/Player/PlayerBagData.cs) 实现为准）。

## 5. 与 `MenuFormMainItemDragger` 的关系

工程内另有 [`MenuFormMainItemDragger`](f:/Yaer/yaer/Yaer/Assets/Scripts/Game/GameRuntime/UI/FormLogic/Menu/MainItemPage/MenuFormMainItemDragger.cs)：使用 **`LimitContainer` + Canvas 比例**计算拖拽边界，在 **`OnEndDrag`** 里用 **`GetComponent<MenuFormMainItemBtn>()`**（非 `GetComponentInParent`）检测目标格。

当前 **道具展示 / 主道具列表** 的正式流程以 **`MenuFormMainItemBtn` 自带拖拽**为准。若某预制体仍单独挂载 **`MenuFormMainItemDragger`**，需确认是否与 **`MenuFormMainItemBtn` 拖拽重复**、以及 **`item` 是否在 Dragger 上被赋值**；避免两套逻辑冲突。

---

## 6. 策划验收建议

1. 在道具展示界面中，对有数量的道具格按住**左键**拖动，松手在另一有道具的格子上，两格**背包顺序**交换，再次打开界面顺序保持。
2. 交换两个**消耗品**后，战斗 HUD 快捷栏顺序是否与背包中消耗品顺序一致（前 6 个消耗品规则）。
3. 拖到空白或无效区域：格子应回到原位置，数据不变。
4. 右键 / 中键：不应触发本拖拽逻辑（代码中仅处理左键）。
