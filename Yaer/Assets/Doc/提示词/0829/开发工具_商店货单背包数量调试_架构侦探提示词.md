商店上架口径（Database OnValidate 预扫）：

- Buy：`CostItem && buyPrice >= 0`  
- Sell：`MaterialItem && sellPrice >= 0`  

以 `GetShop*Candidates` 实现为准，侦探核对并写出当前 Buy/Sell 各几件、ID 列表。

### 测试场景（工具必须能覆盖）

| # | 场景 | 背包预设 | 购买验收 |
|---|------|----------|----------|
| T1 | 空包能买 | 商店货全 0 | 钱够 → Yes + 入包 |

### 设数量语义（必拍板）

| 操作 | 期望 |
|------|------|
| 设为 N（0≤N≤MaxStack） | 背包该 ID **正好 N**（不是再 +N） |
| N=0 | 移除该键或数量 0（与 `TryRemove` 清槽语义一致，避免幽灵格） |
| N>MaxStack | 拒绝或钳到 Max（倾向 **钳到 Max + Log**，与 AddMainItem 一致） |
| 未持有设为 N>0 | 等价新建条目（走 Add/DefProvider，保证 Icon） |
| 落盘 | 每次应用 / 清空 / 全满后 `SaveSpcData` |
| 刷新 | 若菜单贵重物品已开，能否刷新？（侦探查事件 `OnDataChange`） |

**禁止**：只改内存不 Save；对非商店 ID 默默改掉任务关键道具（清空范围必须限商店列表）。
