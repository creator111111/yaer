## 提示词助手预梳理（侦探须核实，勿当唯一真相）

### 产品需求（钉死）

| 项 | 期望 |
|----|------|
| 累加 | 保留：输入正整数 → `AddGold` + Save + 刷新 Menu |
| **减少** | **新增**：输入正整数 → **扣减**同等金额 + Save + 刷新 Menu |
| 金额 | 仍用窗内 IntField + 快捷填 100 / 9999 / 999999 |
| 门禁 | 仅 Play；Editor only |
| 余额不足 | 减少失败时 **不改档**；弹窗或 Log 说明（对齐商店 TrySpend） |
| 显示 | 菜单 Money 仍最多显示 6 位（C1）；减到很小应能看到个位/0 |

### 现网缺口（预扫）

| 层 | 现状 |
|----|------|
| Window | 只有「累加 AddGold」按钮；标题写死「累加」 |
| Util | 仅 `TryAddGold(amount)` 一类封装 |
| 数据层 | ✅ 已有 `TrySpendGold` / `TrySpendPlayerGold`——**减少应走扣款 API，禁止 `gold -=` 裸写** |
| 快捷 +9999 MenuItem | 可保留；减少不必再做一个写死 MenuItem |

### UI 方案（侦探必选）

| 方案 | 做法 | 倾向 |
|------|------|------|
| **U1 · 双按钮** | 保留「累加」+ 新增「减少 Spend」并排 | **✅ 推荐**（误触清晰） |
| **U2 · 正负号** | 金额可输负数当减少 | 易误操作；AddGold 本就拒 ≤0 | ❌ |
| **U3 · 下拉模式** | 模式=累加/减少，一个执行钮 | 可行次选 |

窗标题/HelpBox 改为「累加或减少」，勿再写「仅累加」。

### 减少语义（钉死）

```
减少(amount)：
  amount ≤ 0 → 拒绝
  TrySpendPlayerGold(amount) 或 goldData.TrySpendGold + SavePlayerGold
    成功 → Save（若门面已 Save 则勿双 Save）+ RefreshMoney
    失败（余额不足）→ 不改档；提示 need/have
```

| 问 | 默认 |
|----|------|
| 不够扣时钳到 0？ | ❌ **禁止**（与商店一致：整笔失败） |
| 减少是否走 `QuestManager.TrySpendPlayerGold`？ | ✅ **优先**（内部已 Save） |
| Util 是否抽 `TrySpendGoldForDebug`？ | ✅ 与 Add 对称，窗不直接改 gold |

### 与商店验收关系

- 减到少于 Total2 → 点决定应走失败 / `Village_ShopNo`（旁路须关）  
- 加够钱 → Yes  
- 工具减少 = 开发灌/抽钱包，**不是**商店购买本身

### 严禁

- 侦探阶段改代码  
- 减少时 `gold = gold - n` 不经 TrySpend  
- 正式 MenuPanel 加加减按钮  
- 失败仍 Save / 钳 0 伪装成功

## 背景

Player Gold 窗已能自定义金额累加。用户要 **同样能减少**。复用 `TrySpend*`，升级 Window/Util，勿新造钱包。

## 任务

### A. 钉死现窗能力
仅累加；Util API 列表；扣款 API 是否已可直接调。

### B. UI 方案拍板（U1/U2/U3）
按钮文案、HelpBox、当前余额刷新时机（减少成功/失败后）。

### C. 减少链路
```
Util.TrySpendDebug(amount)
  → Play 门禁
  → TrySpendPlayerGold(amount) 或等价
  → 成功 RefreshMoney；失败 Dialog/Log need/have
```
是否双 Save、与 Add 对称的返回值设计。

### D. 最小施工清单
| # | 动作 | 优先级 |
|---|------|--------|
| 1 | Util 增加 Spend/减少封装 | **P0** |
| 2 | Window 增加「减少」按钮（或报告选定 UI） | **P0** |
| 3 | 文案去掉「仅累加」 | P0 |
| 4 | 余额不足友好失败 | P0 |
| 5 | 快捷填额仍共用 | P1 |

### E. 验收
| # | 操作 | 通过 |
|---|------|------|
| 1 | 余额充足，输入 100 → 减少 | gold-100；Save；Menu 刷新 |
| 2 | 余额 &lt; 输入 → 减少 | 不变；有失败提示 |
| 3 | 累加仍可用 | 与现网一致 |
| 4 | 未 Play | 不能改档 |
| 5 | 减到 0 后再减 | 失败不改档 |
