## 背景（策划白话，已对齐截图/资源）

1. 对话系统里，**对话框内表情**（字幕条左侧小头像 / 对话历史里的头像）目前用的是**静态图片**。
2. 资源可见：`Assets/ArtRes/UI/Story/DialogueForm/Yaer/Avatar/{服装}/` 下按表情英文名存放 PNG（如 `Daze.png`），以及 `Yaer/Face/` 源稿；图集在 `Assets/GameRes/Atlas/Avatar/Avatar_Yaer_*.spriteatlas`。
3. **后续打算**：做**立绘预制体**，在 Prefab 上直接切换表情（以及服装），再对 Prefab **截图**，用截图替代现在的静态头像图。这样表情与服装都跟立绘走，少维护「每套衣服 × 每种表情」的 PNG 矩阵。
4. **本期范围只摸主角雅儿**；其它角色（古莎、国王等）可对照写清差异，但不要扩成全角色改造方案。
5. **必须分清两套图**：
   - **小头像（Avatar）**：对话框 / 历史记录里那张脸 —— **本次主调查对象**
   - **大立绘（Painting）**：对话时屏幕上的半身/全身大图（`YaerPainting` / `GoOutStoryYaerPainting` 等）—— 须写清与小头像是否同源、是否共用 FaceType、后续截图方案是否可能复用大立绘 Prefab

## 必读 / 优先扫描线索（侦探自行确认是否完整，可增补）

### A. 表情从「台本」到「节点」
- CSV / 导入：`DialogueRow`、`DialogueCsvParser`、`DialogueCsvGraphBuilder`、`DialogueFaceTypeCsvDefaults`
- 运行时节点：`StatementNodeEx`（`FaceType`）、`SubtitlesRequestInfoEx`
- 枚举：`DialogueFaceType`（`Assets/Scripts/Game/Static/Enum/Role/DialogueFaceType.cs`）

### B. 对白播放 → 刷头像
- `DialogueTMPUGUI`（`OnGetNewStatement` / `RefreshAvatar` / `OnGetAvatar`）
- `DialogueActorEx.RefreshAvatar` + `OnRefreshAvatarEvent`
- `DialogueAvatarLoader.GetAvatar`
- `DialogueAvatarPathHelper`（雅儿按衣服+头饰选图集路径）
- 存档换装如何影响雅儿图集：与 `PlayerDataComponentGM`（或同类存档组件）的耦合点

### C. UI 消费端（对话框 + 历史）
- `NormalDialogueFormNewLogic`（历史记录、`RecordHistoryDialogue`）
- `HistoryDialogueBox` / `HistoryDialogueInfo`（历史行再次 `GetAvatar`）
- 对话框上真正挂 Sprite 的 Image / 字段名（侦探从 Prefab 或逻辑里钉死）

### D. 大立绘（对照，勿与小头像混为一谈）
- `StoryFormPainting` 及雅儿子类：`YaerPainting`、`GoOutStoryYaerPainting`、`NewGameYaerPainting`
- 它们是订阅 `OnRefreshAvatarEvent` 后换自己的图，还是另有 Face/服装逻辑？
- Prefab 路径（如 `GoOutStoryYaerPainting.prefab`）与小头像图集是否独立

### E. 资源与预加载
- 源图：`Assets/ArtRes/UI/Story/DialogueForm/Yaer/Avatar/`、`.../Yaer/Face/`
- 图集：`Assets/GameRes/Atlas/Avatar/Avatar_Yaer_*.spriteatlas`
- 场景预加载：`AtlasResPackage`、各 `*SceneResConfig` 里 `Yaer_*_DialogueAvatar` 条目
- （若存在）其它角色已有 `DialoguePrefab` 目录，是否已有「Prefab 立绘」先例可对照

### F. 沙盒
- `DialogDebugPlayground` / `DialogDebugDialogueUISetup`：无存档时默认服装路径是否影响表情显示
