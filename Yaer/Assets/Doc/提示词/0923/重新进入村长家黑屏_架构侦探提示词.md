# Cursor Agent Prompt · 重新进入村长家黑屏卡住

> **角色**：【架构侦探】只读；查「出村长家后再进 → 黑屏」  
> **日期**：2026-09-23  
> **现象（用户原话）**：**重新进入村长家会黑屏**（长期停在黑幕、进不去可玩状态）  
> **场景**：`Village_KenMuNi1` ↔ `Village_Chief_House`（手动 `House_Chief` 和/或门口戏后自动进屋）  
> **不是**：第一次门口戏+续聊正常链路的「故意全黑盖壳」；改 WalkArea；改续聊台本内容；改商店再进店案（可对照机制）  

把下面「侦探」整段交给 Agent。没分清「首进续聊黑幕」vs「二进永久黑」、没对拍 `TryDeferBlackFadeForCover` / `CloseFormFade` / 残留 BlackPanel 之前，不要施工。

## 提示词助手预梳理（须证伪）

### 产品钉死

| 项 | 要求 |
|----|------|
| 再进村长家 | 黑幕应**正常淡出**，室内可走、可交互 |
| 续聊 | 同档已播过则**不再**自动续聊（门闩 F1）；二进应静默进屋 |
| 边界 | 勿为修黑屏又开回 LoadingPanel 蛋糕读条（0902 否决） |

### 现网相关契约（对照，勿当终裁）

| 路径 | 行为 |
|------|------|
| 首进且应播续聊 | `TryDeferBlackFadeForCover` → 全黑 Trigger 续聊 → 树就绪 Prepare → `CloseFormFade` |
| 续聊已用再进 | `ShouldPlayChiefContinue()==false` → Defer **return false** → 换场默认淡出 |
| 续聊结束换古莎 | 另开系统 BlackPanel → 全黑换合层 → 再淡出 |
| 0922 门口藏村长 | 出村/进村 Apply 显隐；自动进屋仍 `LoadScene` 黑幕 |

假说：

1. **Defer 误持黑**：二进仍 `ShouldPlay==true` 或 `TriggerStory` 卡住 / Prepare 永不 Finalize，黑幕不关  
2. **CloseFormFade 回调丢失**：`deferredCloseBlackAndNotify` 被清掉或双开黑幕叠层，只关了一层  
3. **换古莎黑幕残留**：上次 `OpenSystemBlackFade` 未 Hide，再进叠加  
4. **门/stayAction**：`House_Chief` 或 `ChiefNearDoor` 进场 stayAction 布置后未揭幕（0922 藏人路径）  
5. **Init/相机**：SceneManager NRE / 相机锁死，体感「黑屏」（须与 BlackPanel Active 区分）  

### 强制排除

| 勿当主因 | 理由 |
|----------|------|
| 续聊台词错 | 与黑幕卡住无关 |
| 故意把二进也播续聊却忘揭幕当「功能」 | 产品要可玩，不是卡死 |
| 只用拉长超时 | 治标；须证伪谁没调 Close |
