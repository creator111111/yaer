# Cursor Agent Prompt · 购买数量：输入皆变 0 + 再点数字框不清空

> **角色**：【架构侦探】只读钉两病 → 【施工员】最小修  
> **日期**：2026-09-23  
> **产品原话（两问题）**：  
> 1. **购买端**不管输入什么都会变成 **0**  
> 2. **再次点击**购买数量时，数字**不会消失**，无法重新输入；**点其他位置都可以**（先失焦再点则正常）  
> **场景**：`Village_Shop` 购买 Tab · 货栏数量  
> **背景**：刚落「长条/数字框进输入并清空」；本票在其上修回归，**勿再整页翻修**  
> **不是**：改货单价；改决定入包主语义；贩卖端除非同源一并验；Tab 高亮大翻修  

先复制「侦探」填复现；拍板后「施工员」。两病可同一次施工，但报告须分裁。

## 提示词助手预梳理（须证伪）

### 产品钉死

| # | 期望 |
|---|------|
| P1 | 购买：有钱时输入合法数量（如 1、2）应留下该数（再受联合上限钳），**不得无论什么都变 0** |
| P2 | 数量已非空时，**再点**数字框（或长条）→ 应再次进入编辑并**清空**，可直接重输；不必先点别处 |

### 现网可疑（预扫，对照 `ShopBuyRowQuantityInput`）

```
BeginQuantityEdit → ClearForEdit（空串）→ Select/Activate → OnQuantityValueChanged?
onValueChanged → ApplyValueChangedPipeline → TryClamp（max=0 → 写 0）
再点数字框：若已是 focused，onSelect / Button.onClick 可能不再触发 → 不清空
点别处 → 失焦；再点 → 又走 Begin/onSelect → 能清空
```

假说：

| ID | 病 | 假说 |
|----|----|------|
| **Z1** | 皆变 0 | `ResolveBuyMaxQuantity` 恒 0（金币读不到 / price 错 / 旁路关且 gold=0）→ 边输边钳成 0 |
| **Z2** | 皆变 0 | 清空后 `OnQuantityValueChanged` / Pipeline **立刻**按空串或 max 写回 0，键入也被打成 0 |
| **Z3** | 皆变 0 | `_isClearingForEdit` 未挡住后续钳制帧 |
| **R1** | 再点不清空 | 已聚焦时 `onSelect` 不二次触发；数字框 Click 未再调 `BeginQuantityEdit` |
| **R2** | 再点不清空 | 行 Button 已选中，第二次 onClick 被吞 |

### 强制排除

| 勿做 | 理由 |
|------|------|
| 关掉全部购买钳制交差 | 总价超余额会回潮；应修「误 max=0 / 清空后误钳」 |
| 要求用户先点别处再点数量 | 产品明确要再点也能清空 |
| 重开 Validate+\0 大翻修 | 易再弄坏 DigitStrip |
