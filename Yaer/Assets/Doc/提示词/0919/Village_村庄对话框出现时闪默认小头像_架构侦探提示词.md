> 村庄里一开对话，框先出来，左边已经有一张默认小脸，过一下才换成第一句该有的脸。

### 期望时序

```
对话框出现（可渐入）…… 此时：有框、无字、【无小头像】
  → 第一句真正显示 …… 此时：出字 + 出该句小头像（同一拍，不再先默认再换）
  → 后面每句按现网逻辑换脸
```

| 阶段 | 框 | 正文 | 小头像 |
|------|----|------|--------|
| 框刚出 / 淡入中 | ✅ | ❌ 空 | ❌ **须空** |
| 第一句真正显示 | ✅ | ✅ 第一句 | ✅ 跟第一句，不要先闪默认脸 |
| 用户看到的现状 | ✅ | 随后才有字 | ⚠ **先默认脸，再刷成第一句的脸** |

### 现网相关链路（预扫，须再证）

```
NormalDialogueUIAlphaAnimationTaskAction（框 FadeIn）
  → ClearSubtitleTextsForEmptyFrame()     // 清字，所以可能「有框无字」
  → 若 PrepareMaskAvatarOnFadeIn = true
       → DialogueMaskAvatarPresenter.Apply(role, face)  // 会提前亮一张脸
  → 第一句到来
       DialogueTMPUGUI → OnGetNewStatement → Presenter.Apply(本句 role, face)
       // 若提前亮的不是本句表情，玩家就看到「默认脸 → 再刷第一句」
```

| 组件 | 路径 | 嫌疑 |
|------|------|------|
| 框淡入任务 | `NormalDialogueUIAlphaAnimationTaskAction.cs` | 勾了预亮，或淡入时没把小头像藏干净 |

## 背景（策划白话）

村庄里的对话都有同一个问题，从村庄开场对话就有：

对话框刚显示出来时，左侧会先出现一张默认小头像，然后才刷新成第一句话该有的小头像。

这是错的。正确是：

- 对话框刚出现时，不要显示小头像。
- 小头像要和第一句话一起出现，并且直接就是这一句的表情，不要先闪默认脸再换。

开场对话 Prefab：`Assets/GameRes/Prefabs/Dialogue/Village_KenMuNiStart.prefab`  
村庄其它对话也要查。不要只修开场就停。

旧文档里「进村开场淡入时故意预亮小头像」作废。本次以用户这句话为准。

### A. 先钉开场（复现入口）

- `Village_KenMuNiStart` 里框淡入节点（`NormalDialogueUIAlphaAnimationTaskAction` 或现网等价节点）
- 黑板字段至少核对：`PrepareMaskAvatarOnFadeIn`、`MaskAvatarRole`、`MaskAvatarFace`（名字以代码为准，有别名就写别名）

### B. 再列村庄对话文件清单（本任务的交付重点）

扫描 `Assets/GameRes/Prefabs/Dialogue/` 下村庄相关对话（文件名含 `Village`，以及报告能证明「在村庄里播」的其它对话 Prefab）。

1. 有没有框淡入 / 预亮小头像  
2. 预亮的角色和表情是什么  
3. 第一句台词的角色和表情是什么  
4. 会不会出现「先默认脸，再换成第一句」  
5. **要不要改**；要改的话改 Prefab 字段，还是改共用脚本后这张图不用单独改

输出一张表，列全路径。不要只写「所有村庄对话」六个字。

同时说明这些**不要**算进本次村庄清单，除非证据表明它们共用同一个会误伤的开关：森林、战斗、新游戏开场、非村庄室内若只是碰巧用了同一面板。

### C. 共用代码会不会一次打中全部

优先读：

- `NormalDialogueUIAlphaAnimationTaskAction`（清字、预亮、淡入）
- `DialogueMaskAvatarPresenter`（Apply / HideAll）
- 雅儿及其它角色 Painting 的默认表情（`SetDefaultPainting` 一类）
- `DialogueTMPUGUI` 刷小头像的时序（第一句到来前有没有别的 Refresh）
- 母体 `NormalDialogueNewPanel` 里 Mask / Portrait 默认是否亮着

写清三种可能里实际是哪一种（可以叠加，但要标明主因）：

1. 每张村庄对话 Prefab 各自勾了预亮 → 清单里的文件都要改字段  
2. 淡入任务或 Painting 默认就会亮一张脸 → 改一处代码，Prefab 清单改成「回归时要看的场次」  
3. 母体面板默认亮着脸 → 改面板，并列出所有会跟着变的对话

### D. 推荐一种最小改法

必须同时满足：

1. 框出现到第一句出现之前，小头像不可见（不要默认脸）  
2. 第一句话出现的同一时机，显示该句小头像，中间不再闪另一张脸  
3. 后续句子换脸保持现网逻辑  
4. 不重导、不覆盖整张对话图  
5. 若村庄以外有对话仍依赖「框淡入就预亮头像」，默认不要改它们；若做不到隔离，写入 `OPEN_QUESTIONS.md` 并停在推荐，不要擅自扩范围
