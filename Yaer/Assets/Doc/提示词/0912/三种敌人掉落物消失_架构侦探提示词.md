### 现网掉落链（助手预扫）

```
怪 HP=0 → OnDead → Dead 动画
  → AnimationEvent「RemoveMonsterOnDead」
  → BaseMonster.MonsterDeadEndEvent()
       → hasDropItem && dropItem!=null → ShowDropItem()  // dropItem.SetActive(true)
       → 否则直接延迟删怪

玩家点击掉落物（DropItemSrc.Update）
  → OverlapPoint + 距离≤4
  → SetDropItemHasPickUp → PlayerBagData.AddMainItem(itemName)
  → 淡出 → RemoveDropItem → 删怪

Tips「获得道具」横幅：DropItemSrc 内 OpenTipsForm 现网多半是注释掉的
  → 「没横幅」≠「没进包」；侦探须分开验
```

**重要**：没有 Excel 掉落表；掉落靠 Prefab 子物体 `dropItem` + Inspector 引用 + `DropItemSrc.itemName`。

### 嫌疑优先级（可推翻）

| # | 嫌疑 | 表现 |
|---|------|------|
| **A** | Prefab `dropItem` 引用丢 / 子物体删了 / 父节点未激活 | 三种都没 |
| **B** | Dead.anim 缺 / 断 `RemoveMonsterOnDead` 事件 | 死了不刷掉落 |
| **C** | `hasDropItem` 被改 false（含木虫生成路径误伤常驻怪） | 部分或全无 |
| **D** | 存档 `recordMonsterHasDead` → 再进场景整怪隐藏 | 「重进后什么都没有」 |
| **E** | 掉落有，但拾取链坏（`monsterLogic` 空、碰撞、距离、Camera.main） | 看得见捡不了 / 或点了无进包 |
| **F** | Sorting / 图层 / 缩放导致「其实在脚下但看不见」 | 以为没掉 |
| **G** | 用户把「没 Tips 横幅」当成没掉落（Tips 被注释） | 包里其实有 |
