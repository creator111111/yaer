## 提示词助手预梳理（侦探须核实，勿当唯一真相）

### 产品白话

> 史莱姆活着跑已经贴地跑道了。  
> 打死以后尸体会高一截低一截，不好看。  
> 多半是打飞、跳着死的时候高度歪了，一死就冻在歪的位置。  
> 死的时候也要回到那条固定高度（场景常量），再当尸体躺着。

### 术语钉死

| 词 | 本案含义 |
|----|----------|
| **高低错落** | 多具尸体 / 死后本体 `position.y` 相对 `CombatAxisY`（−6.61）可见偏离，彼此不在一条水平线上 |
| **击飞死亡** | 击退/`KnockBack` 过程中或刚被打飞后致死；或致死帧仍带竖直位移残差；含 JumpAtk 空中被打死 |
| **贴常量轴** | `y = CombatAxisY`（−6.61），与活体 Snap 同一权威；**不是**玩家当前跳起高度 |
| **定格** | 现网 Dead：`FreezeAll` + kinematic + `canGravity=false`（保留，先 Snap 再冻） |

### 现网逻辑（助手预扫）

```
活体：Idle/Move/BornDown/JumpAtkDown → SnapToCombatAxisY() → 权威 CombatAxisY=-6.61

致死：
  OnDead → canGravity=false → ChangeState<SlimeDeadState>
  SlimeDeadState.Enter：
    StopMove / velocity=0 / FreezeAll / kinematic
    ★ 故意不调用 SnapToCombatAxisY（旧 OPEN：冻在「致死瞬间位」）

结果：
  击飞/跳攻把 Y 打离 −6.61 → 死瞬间冻在偏高/偏低 → 尸体高低错落（截图红框）
```

| 前案写法 | 本案裁定（用户钉死） |
|----------|----------------------|
| Dead 禁止 Snap（防跟玩家飞） | 权威已是 **常量** → Dead **必须** Snap 到常量，再 Freeze |
| 冻在致死点 | 仅允许 X（及面向）保留致死瞬间；**Y 必须回轴** |
