### 现网死亡链（助手预扫 · 须核实）

```
HP=0 → Slime.OnDead()
  → base.OnDead()：isDead、关 GroundCld、StopMoveOnPosX、recordMonsterHasDead …
  → // canGravity=false 现网已注释
  → bodyCld / footCld → isTrigger=true   ← 脚底可能不再「踩地」
  → 若 JumpAtk/Fall 子状态机：先 ExitCurrentSubStateMachine 再进 Dead
  → else：ChangeState<SlimeDeadState>
  → CldController.SetActiveAll(false)

SlimeDeadState.Enter：
  → isProtect=false；Cld 再全开
  → // BodyRg.constraints = FreezeAll 现网已注释   ← 与 TenWan/WoodWorm 对照

Dead.anim 末帧 AnimationEvent
  → RemoveMonsterOnDead:Slime
  → MonsterDeadEndEvent → ShowDropItem（dropItem 是子物体，跟父 Transform）

MoveComponent.OnFixedUpdate：
  → !IsGrounded && canGravity → Velocity += Gravity
```

**对照（助手预扫 · 关键差异）**

| 怪 | DeadState 冻刚体 | OnDead 关重力 |
|----|------------------|---------------|
| **TenWan** | `FreezeAll` + `isKinematic=true` | （无史莱姆同款注释） |
| **WoodWorm** | `FreezeAll` + `isKinematic=true` | `canGravity=false` **亦注释**，但 Dead 已冻死 |
| **Slime** | `FreezeAll` **整行注释** | `canGravity=false` **整行注释** |

→ 嫌疑：**史莱姆死后仍可受重力 + 碰撞变 Trigger → IsGrounded 失败 → 穿地下坠**；「概率」≈ 死时是否已在 Idle `FreezePositionY`。

### 与 0912「Y 轴同轴 Snap」的叠加嫌疑（须核实，勿甩锅）

0912 施工在 **Idle** Enter：`FreezePositionX|Y`；**Move / JumpAtk** 多为 `FreezeRotation` 并允许重力/竖直运动。

| 若死在… | 预判体感 |
|---------|----------|
| Idle（Y 已冻） | 尸体更可能留住 → 「多数正常」 |
| Move / JumpAtk / BornFall / 空中 | Y 未冻 + Trigger + canGravity → **易穿地掉屏** → 「有概率」 |
| 死后仍被 Snap / 残速 | 须查 Dead 是否误调 `SnapToCombatAxisY`（预扫：Dead 未调；仍须确认） |

### 嫌疑优先级（可推翻）

| # | 嫌疑 | 若成立的体感 |
|---|------|--------------|
| **A. Dead 未 Freeze / 未关重力（主嫌疑）** | `SlimeDeadState` 注释掉 `FreezeAll`；`OnDead` 注释掉 `canGravity=false`；Trigger 后穿地 | 空中/移动中击杀必现或高概率掉屏 |
| **B. 0912 Snap/Freeze 改动改变概率面** | Idle 更稳、Move/跳更险；非根因但放大「有时有有时无」 | 改同轴后更明显 |

| **E. 掉落物「没了」是连带** | `dropItem` 挂怪下，父物体掉屏外 → 以为没生成尸体也没掉落 | Hierarchy 里物体仍在但 Y 极低 |
| **F. 误判为立刻 Destroy / 对象池** | `MonsterDelayRemove` 仅在无掉落或捡完后；Dead 末才 `ShowDropItem` | 须用日志排除 |
| **G. 仅树上/高台实例** | 高 Y 开死后坠更显眼 | 地面同构则非摆放独有 |
| **H. 0912 掉落 Sprite 案残留误解** | Missing 已修，但仍把「看不见」当成本案 | 对照 Inspector：Sprite 有图但仍掉屏 → 非 H |
