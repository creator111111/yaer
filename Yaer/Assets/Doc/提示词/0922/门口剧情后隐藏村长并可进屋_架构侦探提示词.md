> **日期**：2026-09-22  
> **现象（用户 + 截图）**：剧情触发完后，村长家门口**别再摆人**——**村长应隐藏**；然后**门应可以再进去**  
> **场景**：`Village_KenMuNi1`；锚点 `Npc_Chief` / 合层 `村长` / `House_Chief` → `Village_Chief_House`  
> **对白**：`Village_村长家门口初次对话`（`ChiefNearDoorStoryTrigger`）  
> **不是**：改门口台本文案/立绘；改续聊台本内容；改送树屋戏；改相机闪滑  

把下面「侦探」整段交给 Agent。没对拍「播完当帧仍站门外」vs「出屋回村又看见村长」、没查清自动进屋开关与 `House_Chief` 门闩之前，不要施工。

## 提示词助手预梳理（须证伪）

### 产品钉死（本期改口，以用户原话为准）

| 项 | 要求 |
|----|------|
| 剧情后门口 | **不摆村长**（世界 NPC / 合层美术都不应再挡门） |
| 门 | **可以进屋**（`House_Chief` → `Village_Chief_House`） |
| 存档 | 同档再回村门口：村长仍隐、门仍可进（勿每进村又刷出来） |

### 与旧定案冲突（须显式裁定，勿假装不存在）

| 旧案 | 现网预扫 | 与本期关系 |
|------|----------|------------|
| 0831/0901/0902 | `ChiefNearDoorStoryTrigger.loadChiefHouseOnStoryEnd=true` → 对白结束**自动黑幕进屋** | 若仍自动进屋，玩家「站门口看见村长」可能是：**自动进屋失败/关掉**后的残留，或**出屋回村**未藏村长 |
| 门口戏与 `House_Chief` **解耦** | 门一直可手动进（理想） | 用户说「门应该可以再进去」→ 须查门是否被关/挡/Collider 被村长挡 |

侦探必答：**本期产品是「取消自动进屋、只藏村长+手进门」还是「保留自动进屋，但回村/失败路径必须藏村长且手进门可用」？**  
默认按用户原话施工倾向：**播完后门口无村长 + 门可进**；自动进屋是否保留写清利弊，**勿擅自拆自动进屋**除非复现证明必须或产品明确只要手进。

### 现网可疑（预扫）

| 物体 | 角色 |
|------|------|
| `Npc_Chief` + `ChiefNearDoorStoryTrigger` | 靠近播门口戏；现网**未见**播完藏村长 |
| 合层美术 `村长` | 装饰 SR，可能仍挡观感 |
| `House_Chief` | `SceneChangeDoor` 进屋；可能 Active/Collider/`TriggerWhenMoveIn`/被村长占位 |
| `GushaSidePortrait` | 对白结束会关侧面；**≠**藏村长 |

假说：

1. **从未实现「播完藏村长」** → `OnStoryFinished` / `OnEnterScene` 缺按 `CheckStoryUsed(门口初次对话)` 关 `Npc_Chief`+合层`村长`  
2. **自动进屋关了或失败**，人留门外，村长仍 Active  
3. **门被挡**：村长 Collider / 合层挡交互；或 `House_Chief` 未启用/`ShowLoadingUI` 错  
4. **读档/回村**未按已用剧情重新藏人  

### 强制排除

| 勿当主因 | 理由 |
|----------|------|
| 对话 Prefab 立绘 | UI 立绘 ≠ 门口世界村长 |
| 只藏侧面古莎 | 已有 `hideSideOnStoryEnd`；用户要藏的是**村长** |
| 删 `House_Chief` | 产品要能进门 |
| 改续聊 CSV | 无关门口显隐 |
