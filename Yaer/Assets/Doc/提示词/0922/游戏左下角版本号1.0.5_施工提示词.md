## 产品口径

| 项 | 要求 |
|----|------|
| 文案 | 固定显示 **`1.0.5`**（可带前缀 `v` / `Ver.` —— 侦探对拍有无 UI 规范；**无规范则默认纯 `1.0.5`**） |
| 位置 | 屏幕**左下角**（留安全边距，勿贴死裁切） |
| 可见范围 | **默认：进游戏后常驻**（主菜单 StartScene + 局内各场景均可见）。若现网更适合「仅挂在常驻 UI 根」，选能覆盖主菜单与局内的最小挂点 |
| 交互 | **不挡点击**（Raycast Target 关 / 放在不拦截层） |
| 样式 | 小字、低对比可读即可；勿做成大标题；勿用刺眼描边抢主 UI |
| 真源 | 显示字符串与工程版本应对齐：现网 `ProjectSettings.bundleVersion` 预扫为 **`0.1`** —— 施工时应改为 **`1.0.5`**，UI 优先读 `Application.version`（或统一常量），避免下次改版本要改两处 |

生活类比：角落贴一张小标签写现在是哪一版；标签不能挡按钮，菜单里和进村后都要看得到。

## 助手预扫（须复核）

| 项 | 预扫 |
|----|------|
| 现成版本 UI | **未扫到** VersionLabel / 常驻版本 Form |
| `bundleVersion` | `ProjectSettings/ProjectSettings.asset` → **`0.1`**（与产品 1.0.5 不一致） |
| UI 组 | `EUIGroup`：`System` / `Bottom` / `Middle` / `Top` —— 常驻角标倾向 **System** 或随 `GameEntry` 不随场景销毁的 Canvas |
| 启动链 | Init → StartScene（主菜单）→ 进局；版本应在换场后仍在 |

### 方案倾向（侦探拍板其一）

| 方案 | 做法 | 优点 | 风险 |
|------|------|------|------|
| **A（推荐）** | 新建极简常驻 UI Form（或挂 `GameEntry` 下 DontDestroy Canvas）左下 TMP/Text；文案=`Application.version`；并把 `bundleVersion` 改为 `1.0.5` | 一处改版本、全游戏可见 | 须选对 UI 组与开局时机 |
| **B** | 只在 `StartScene` 场景里摆死文字 | 最快 | **进局后消失**——默认不满足「游戏左下角」 |
| **C** | 塞进 FightingPanel / MenuPanel | 少新建 | 关 HUD/开菜单时可能被藏或挡操作 |

**默认否决 B**（除非产品只要标题画面有）。优先 **A**。

### 禁止

- 挡对话下一句、菜单、地图点击  
- 每换场景 Instantiate 一份导致叠多个「1.0.5」  
- 只改文档不改运行时显示  
- 大改 UI 框架 / 多语言整表（版本号三语可同显 `1.0.5`）

2. 常驻 UI 挂在哪最稳：`GameEntry` / `EUIGroup.System` 开一个轻量 Form / 现有常驻 Canvas。
