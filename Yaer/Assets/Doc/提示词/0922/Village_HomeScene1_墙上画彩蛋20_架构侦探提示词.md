```

@Assets/GameRes/Scenes/Village_HomeScene1.unity
@Assets/Scripts/Game/GameRuntime/GameSceneManager/Scene/Village_House/Village_HomeScene1SceneManager.cs

### A. 钉死 Hierarchy

确认路径与组件；现网是否双 Active；`画框` 是否独立（勿误关画框）。

### B. 挂点选型

| 方案 | 做法 | 倾向 |
|------|------|------|
| **A** | `画` 根挂 `RandomExclusiveChildActive`（名可改）：引用两子物体 + chance；OnEnable/进场景掷一次 | **推荐**（可复用、场景自包含） |
| **B** | 仅在 `Village_HomeScene1SceneManager.OnEnterScene` 里 Find 名字开关 | 少文件，但名字耦合、难复用 |
| **C** | 动画/Timeline 随机 | 过重，否决 |

拍板默认：**A + 每次进场景（OnEnable）重掷**；不写存档。

### C. 逻辑契约（写入报告）

```
roll = Random.value
if roll < 0.2:
  彩蛋画 Active=true；正常画 Active=false
else:
  彩蛋画 Active=false；正常画 Active=true
```

禁止两张同时 true。缺引用则打 Error 并回退「只开正常画」。

### D. 报告结构

① 结论一句话  
② Hierarchy / 现网双显风险  
③ 方案对比与推荐  
④ Inspector 字段表  
⑤ 要改文件路径级  
⑥ 验收表  
⑦ 开放问题（Q1 是否改存档）

写入：`Assets/Doc/执行文档/0922/Village_HomeScene1_墙上画彩蛋20_架构溯源报告.md`
```
