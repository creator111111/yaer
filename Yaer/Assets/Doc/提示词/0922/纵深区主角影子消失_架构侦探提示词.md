> **日期**：2026-09-22  
> **现象（用户原话）**：这人的影子一直都没有；**Z 轴移动的地方主角一直没有影子，会消失**  
> **用户截图**：户外绿地斜坡、前景虚化叶；角色白发蓝角披甲持剑（须裁定是 **雅尔换装** 还是 **古莎 NPC**；勿想当然）

## 提示词助手预梳理（须证伪）

### 产品钉死

| 项 | 要求 |
|----|------|
| 纵深区 | 主角**脚底影子**应常在；前后走（纵深）时**不消失** |
| 对照 | 纯左右若有影子、一走纵深就没 → 坐实与深度/排序/落地检测相关 |
| 边界 | 勿用「关掉纵深」治影子；勿把 EnvironmentShadow 压暗当脚底影子 |

### 两种「影子」（必须先分清）

| 类型 | 资源/脚本 | 观感 |
|------|-----------|------|
| **A. 脚底 Blob**（本案主诉高概率） | 角色子物体 `ShadowAnimator` + `showdowArea`；`ShadowComponent` 跟身 | 脚下椭圆/剪影 |
| B. 环境压暗 | `EnvironmentShadowCamera` + `CharacterEnvironmentShadow` + `_ShadowTex` | 人身上变暗，**不是**脚下投影 |

截图「人站草地上脚下无投影」→ 优先查 **A**。

### 现网可疑（预扫，勿当终裁）

| 项 | 线索 |
|----|------|
| 显隐 | `BaseEntityLogic.OnUnIsGround` → `showdowArea.SetActive(false)`；`OnGroundedEvent` → 再显示。纵深区若 **IsGrounded 抖/误判空中** → 影子被关掉 |
| 排序 | `TownPlayerLocomotion.ApplyDepthSortingFromWorldPosition` 只改 **`spriteForDepthSort` 一个 SR**；怪物会把影子 Order 跟身（`spriteSortIndex-2`）。主角影子若**不跟深度 Order** → 被草地/SceneObject 盖住 =「消失」 |
| 绑定 | `PlayerLogic` 找 `ShadowAnimator` → `showdowArea`；换装/古莎是否另套无影子 |
| 截图角色 | 白发蓝角持剑 → **古莎像**；若实为古莎 NPC，查其是否有 `ShadowAnimator`、是否走村纵深排序 |

假说：

1. **落地门闩**：纵深移动时 GroundCheck 抖动 → `OnUnIsGround` 藏影子  
2. **排序漏影子**：只刷身体 Order，影子 Order/Layer 落后被地片盖住  
3. **局部坐标**：纵深改权威 Y 后影子子节点未贴脚  
4. **角色搞错**：截图是古莎无影子 Prefab，与「主角」混报——须分表验收  
5. **误查 EnvironmentShadow**：场景无压暗相机 ≠ 脚下 Blob 缺失

### 强制排除

| 勿当主因 | 理由 |
|----------|------|
| 整场景关灯/无实时光 | 2D Blob 一般不靠实时 Shadowmap |
| 只改 EnvironmentShadow Layer | 那是压暗，不是脚底 |
| 改 WalkArea 当影子修 | 除非证伪落地检测绑在 Walk 上且为唯一因 |
| 全局 Sorting Layer 大挪 | 过大；优先影子跟身 Order |
