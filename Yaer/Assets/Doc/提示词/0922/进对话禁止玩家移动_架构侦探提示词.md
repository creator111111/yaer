# Cursor Agent Prompt · 进对话仍保持移动：应立刻禁止玩家移动

> **角色**：【架构侦探】只读；查「移动中触发剧情后对话期间人还在滑/走」  
> **日期**：2026-09-22  
> **现象（用户 + 截图）**：这地方（村·村长家门口三人戏，首句古莎「奶奶。」）**一直保持移动触发了剧情就会一直移动**；产品要求：**进对话就禁止玩家移动**  
> **对白锚点**：`Village_村长家门口初次对话`（`Village_KenMuNi1` / `ChiefNearDoorStoryTrigger` 一类）  
> **不是**：改门口台本/立绘/空头像案；改 0922 键族规则本身；改换场相机；改商店 ESC  

把下面「侦探」整段交给 Agent。没对拍「按住键进对话」vs「静止进对话」、没查清 `StoryTriggeredHandle` / `TownPlayerLocomotion` 是否清速度之前，不要施工。

## 提示词助手预梳理（须证伪）

### 产品钉死

| 项 | 要求 |
|----|------|
| 进对话 | **立刻**禁止玩家移动（含松手前的惯性/纵深滑） |
| 对话中 | 按住 WASD/方向键也**不得**位移 |
| 对话结束 | 恢复移动（非剧情锁区时） |
| 范围 | 以门口案复现为主；若根因在公共 `onStoryTriggered`，应一并修其它村/局内对白（报告写清影响面） |

### 现网可疑（预扫，勿当终裁）

| 项 | 线索 |
|----|------|
| 进故事 | `PlayerLogic.StoryTriggeredHandle`：`hasInStoryEventState=true` → `PauseGameHandle`/`SetAllowMove(false)` → `StopMove` → `SetSceneObjIsPause(true)` |
| 输入门闩 | `PlayerInputComponent.SetAllowMove`：若已在故事中强制 `value=false` |
| **村纵深** | `TownPlayerLocomotion` 注释写明：村里权威 Y 由本组件积分，**Combat Idle 的 StopMove 清不掉 `depthVelocity`** → 按住纵深/斜向进对话最易「还在滑」 |
| 门口链 | 黑幕 → `TriggerStory("Village_村长家门口初次对话")` → 开对话框（0902 文档） |

假说：

1. **主假说（村）**：`StopMove` / `SetAllowMove(false)` 已调，但 **Town 仍积分 `depthVelocity`/横移**，人在对白中继续滑  
2. **键仍读入**：0922 键族改动后，故事中仍有通道把输入灌进 Town  
3. **时序**：黑幕/`onStoryTriggered` 晚于物理帧，已积出一截位移；或门口 Trigger 在故事事件前未停步  
4. **仅门口**：该 Trigger/黑幕路径绕过 `onStoryTriggered`（须证伪；现网一般会 Invoke）

### 强制排除

| 勿当主因 | 理由 |
|----------|------|
| 对话 Prefab 文案/立绘 | 与位移无关 |
| 「改慢移动速度」当停步 | 产品要的是禁移，不是减速 |
| 只改门口一个 Trigger 脚本地硬锁、公共故事仍漏 | 除非证伪公共路径无问题 |
| 关掉整个 Town 纵深 | 过大 |
