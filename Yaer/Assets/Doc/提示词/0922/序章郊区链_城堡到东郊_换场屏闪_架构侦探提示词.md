# Cursor Agent Prompt · 序章郊区链：城堡→龙城郊→龙城东郊 换场屏闪（一并修）

> **角色**：【架构侦探】只读；对照 Stairs / 出店 / 东郊↔走廊 / 全量盘点，**一条链两段落点**一起查清、一起推荐修法  
> **日期**：2026-09-22  
> **产品原话**：城堡出来到龙城郊会屏闪；**刚到龙城东郊也会屏闪**——**写在一起修**  
> **用户截图（东郊）**：`ForestEastScene` 首次进场对白「一个人……也没有……独自旅行…」（`ForestEastSceneFirstEnter`）；主角半透明/残影感可作加重线索，须裁定是相机闪还是立绘/材质 Alpha  
> **场景链**：`HomeScene1`（城堡）→ `ForestScene`（龙城郊）→ `ForestEastScene`（龙城东郊）  
> **不是**：林恩可见运镜改没；整场景永久 `ForestScene.smoothTime→0`；回退东郊↔走廊已定格；改树洞爬行；改 Part3  

把下面「侦探」整段交给 Agent。没填两段落点复现矩阵、没分清「黑幕揭幕闪」vs「FirstEnter/林恩演出闪」之前，不要施工。

## 提示词助手预梳理（须证伪）

### 产品钉死

| 项 | 要求 |
|----|------|
| 出城→郊 | 揭幕贴玩家，无闪/可见平移 |
| 郊→东郊 | **刚到东郊**揭幕同样无闪（含首次 `ForestEastSceneFirstEnter` 对白段） |
| 林恩 | 门口可见推镜保留；**禁止** Forest 整场景 `smoothTime=0` 作终态 |
| 交付 | **同一报告 + 同一施工说明**；能共用 instantSnap / 进场定格工具则合并，勿拆成互不相关两票硬刚 |

### 现网预扫（对照，勿当终裁）

| 段 | 门 / 落点 | 目标 smoothTime | 备注 |
|----|-----------|-----------------|------|
| **① 城堡→郊** | HS1 `NextSceneName: ForestScene`；EnterPos `lastScene: HomeScene1` | Forest **0.3** | Stairs 同源高嫌疑；**不能**整景改 0 |
| **② 郊→东郊** | Forest `NextSceneName: ForestEastScene`；EnterPos `lastScene: ForestScene` | 东郊磁盘 **已 0**（0922 走廊案） | 若仍闪 → **另缝或加重**（FirstEnter / 默认机位 / 包体未含 0 / Alpha） |
| 走廊↔东郊 | 已修 | 双方 0 | **回归**勿回退 |

假说：

1. **段①**：`forceSnap` + Forest `0.3` + 早揭幕 = 经典闪滑  
2. **段②**：磁盘已 0 仍闪 → 查 `ForestEastSceneFirstEnter` 揭幕前后二次改相机 / UIAlpha / 锁镜；或运行包仍是旧 0.3；或「闪」实为角色半透明残影（截图）非相机平移  
3. **可合并修**：进场黑幕路径统一 instantSnap（0922 全量 A2 / 方案 B），段①受益；段②若已是 0 则 dig FirstEnter，勿再改东郊 smoothTime

### 强制排除

| 勿当主因 | 理由 |
|----------|------|
| Forest 整景 `smoothTime→0` 终态 | 林恩误伤；0912/0922 禁止 |
| 把东郊再改一遍 smoothTime | 已 0；无效则另缝 |
| 林恩 `OnDialogueEnd` 无黑幕收束 | 0912 另案；链上可共用工具，复现须分开 |
| 只拉长 hold | 否决作主修 |
| 走廊/树桥/西境 BOSS | 另票；本票只钉城堡→郊→东郊 |
