## 提示词助手预梳理（侦探须核实，勿当唯一真相）

### 产品需求（钉死）

| 项 | 期望 |
|----|------|
| 功能 | **一键**给当前存档玩家 **+9999** 金币（或设为便于测多位数；默认 **加 9999**） |
| 落盘 | 必须 `SavePlayerGold`，重开菜单 / 读档仍在 |
| 入口 | 开发期易点：优先 **`Tools / …` Editor 菜单**；可选 Play 内热键（侦探二选一或都做） |
| 显示 | 加完后若 Menu 已开，尽量刷新 Money 数字；否则提示「再 ESC 开一次菜单」 |
| 范围 | **仅开发/Editor**；禁止进正式发布包玩家可点的作弊 UI |

### 现网假说（2026-08-29）

| 项 | 预扫 |
|----|------|
| 现成刷金工具 | ❌ **无** Tools/热键 |
| 加金 API | `PlayerGoldData.AddGold(amount)` + `QuestManager.SavePlayerGold()` |
| 读金 | `QuestManager.getInstance().GetPlayerGoldData()` |
| 菜单刷新 | `MenuFormLogic` 开菜单时 `SetNumber(gold)`；加金后若菜单已开需 **再调一次刷新** 或关开菜单 |
| 样板 | `Tools/UI/Setup MenuPanel Money Digits` 等 Editor `MenuItem` |

### 入口方案（侦探必拍板）

| 方案 | 做法 | 优点 | 风险 | 倾向 |
|------|------|------|------|------|
| **A · Editor Menu 仅 Play 中可用** | `Tools/Debug/Add 9999 Player Gold`；`Application.isPlaying` 才执行 | 与现网 Tools 一致；不进包体逻辑 | 须从 InitScene 正规进游戏再点 | **✅ 推荐** |
| **B · Play 热键（如 F9）** | Debug 组件 / GSM 订阅 | 手不离键盘 | 易误触；须 `#if` 或开发开关 | 可选 P1 |
| **C · 菜单面板上加「作弊按钮」** | 永久 UI | — | 易进正式包 | ❌ |
| **D · 改存档 JSON 手改** | — | — | 非一键 | ❌ 不当工具 |

**Edit 模式未 Play**：Archive / QuestManager 通常不可用 → 工具应 **拒绝并弹窗**「请先 Play 并从 InitScene 进游戏」。

### 加金语义

| 问 | 默认 |
|----|------|
| +9999 还是 **设为** 9999？ | **AddGold(9999)**（累加）；若已有很多金则更高——测多位 DigitStrip 更好 |
| amount≤0 | AddGold 已忽略；工具写死 9999 |
| 直接改 `gold=` | ❌ 禁止绕过 AddGold（除非报告论证 Set API） |

### 严禁

- 侦探阶段改代码  
- 正式包暴露作弊按钮  
- UI 自建第二钱包变量  
- 不 Save 只改内存导致「菜单看着有、读档没有」
