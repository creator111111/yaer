### 预扫结论方向（可证伪）——侦探必须打假

| 层 | 预判 |
|----|------|
| 点击入口 | `RaycastComponentGSM` 鼠标左键 → 命中 `RaycastListener` → `OnClick(player)` |
| **占位门槛** | `RaycastListener.OnClick` 内 **`AreCollidersOverlapping(玩家 InteractiveCollider)`** 为真才 `onClickEvent`——**这就是「必须走近」** |
| E 键交互 | `GetFirstCanTouchEntiy` 同样 **bounds 相交** 才算可交互——与点击同源哲学 |
| NPC 能点 | 多半已走近，或 E；不是「全世界任意远点击」 |
| 物品方案 | **不要**把物品做成「人走近再点」的 NPC 克隆当唯一方案；应支持 **远程点击**（新 Flag / 子类 Listener / 跳过 overlap） |
| 对白侧 | 仍挂 `SimpleStoryTrigger` + Import CSV 生成 Prefab；**对话系统本身不用重写** |
| 场景侧 | 红框物体需实体：`InteractiveComponent` + `RaycastListener`（点得中）+ `SimpleStoryTrigger` + `sceneObjs` 登记；Hierarchy 可仿 `NpcChair` 的 Components/Clds/Body |

生活类比：现在点 NPC 像「走到柜台前按铃才受理」；物品交互要「隔着大厅指一下展柜就播讲解」，铃还是那个铃，只是取消「必须站在柜台前」。

## 背景

1. 开发者确认 NPC 有点击对话，但感觉必须玩家靠近（占位）。
2. 新需求：物品交互——远处鼠标点物体就播对话，走近不做硬门槛。
3. 对白内容已有 NPC1 物品 CSV；场景里桌/箱/袋要可点。
4. 本期查明：现网点击链路、占位卡在哪、物品最小怎么做（配置 vs 改判定）。

## 必查

### A. 现网「点击对话」完整链

```
鼠标左键 → RaycastComponentGSM → RaycastListener.OnClick
  → ? overlap 玩家 ?
  → InteractiveComponent.onClickInteractiveEvent
  → SimpleStoryTrigger.OnClickTriggerStory
  → TriggerStory(Prefab名)
```

钉死每一步文件/条件；E 键路径是否另一条但同样要靠近。

### B. 「玩家位置占位」证据

- `RaycastListener.OnClick` 是否强制 `AreCollidersOverlapping`？
- overlap 用的是哪个 Collider（Body？玩家脚？）？
- 远处点 NPC：**射线能打中但 OnClick 静默失败**？还是根本点不中？
- `canTouchWithPlayer` 是否另加门禁？

结论要写清：占位 = 代码门槛，不是策划误解。

### C. 物品交互目标行为

| 操作 | 期望 |
|------|------|
| 玩家站在门口远处，点红框木箱 | 立刻播对应物品对白 |
| 不按 E、不走近 | 仍可触发 |
| 对白 UI / 推进 | 与 NPC 对话相同 |
| 点空地 / UI | 不误触 |

### D. 方案对比（必选一个主方案）

| 方案 | 大意 | 利弊预扫 |
|------|------|----------|
| A | `RaycastListener` 增加「忽略玩家距离」开关；物品勾选 | 改动小；NPC 默认仍要靠近 |
| B | 新建 `RemoteRaycastListener` 子类，OnClick 不检查 overlap | 不碰旧 Listener 默认行为 |
| C | 仅放大物品 interactiveCollider 盖满房间 | **否决倾向**（脏、误触、不像需求） |
| D | 只用 E、走近 | **否决**（产品明确远处点击） |

钉死：主方案；改哪些类；NPC 默认行为是否保持「须靠近」。

### E. 场景 / 资源清单（配置侧）

对红框三类物体（可映射到已有 CSV）：

| 物体（现场） | 可能 CSV / Prefab 名 | 须有组件 |
|--------------|----------------------|----------|
| 木箱堆 | `Village_NPC1_物品交互_木箱` | 实体 + Raycast 可点 + StoryTrigger |
| 黄米/粮袋 | `…_黄米` | 同上 |
| 桌食/面包/饼干 | `…_一篮面包` / `…_一盘饼干` 等 | 同上 |

写清：

- 是否必须 `sceneObjs` 登记  
- Collider 是否 Is Trigger、Layer 是否被 Raycast 打到  
- Prefab 是否已 Import，还是只有 CSV  
- 是否与 Npc1「人」抢点击（排序 / 分离碰撞）

### F. 不要误伤

- 不改对话 UI / NodeCanvas 播放主链  
- 不把所有 NPC 改成远程点击（除非产品要求；默认 NPC 保持近距）  
- 不在 Update 里每帧扫全场景当主方案  
- 对话中是否禁点击：对拍现网 Pause / IsPointerOverGameObject
