## 必读 / 优先扫描线索

### A. 选项从哪冒出来（UI）
- NodeCanvas `MultipleChoiceNode`（编辑器名 Multiple Choice）
- `DialogueTree.RequestMultipleChoices` → `DialogueTMPUGUI.OnMultipleChoiceRequest`
- `NormalDialogueNewPanel` 内 `DialogueOptionsGroup` / `optionButton` 克隆
- 确认：**没有**独立「任务选项 Prefab / 任务选项表」驱动按钮列表

### B. 选项内容写在哪
- `Village_Aegir_QuestOffer`：Graph 内是否已有 MultipleChoice；选项文案是手填还是 CSV 导入残留
- CSV `Type=Choice` + `Extra`（如「我还有事|我会努力的」）与 Import 工具关系；历史「精简 CSV 无 Choice / 手改 Graph」是否仍属现网真相
- 哥布林 `WestRappRoadGoblinAndGusha`：选项是否同样纯 Graph

### C. 点「接」之后怎么接到任务
- Choice 出边 → Statement（如「我会努力的！」）→ **`QuestAcceptAction(questId)`** → `QuestManager.AcceptQuest`
- 「不接」出边：无连线 / END → 对话结束、不调 Accept
- `questId` 与 `QuestConfig` / `QuestDataTableRow` / json 的对应；Accept 时校验哪些字段
- 明确：`QuestConfig` **不负责**生成选项按钮文案

### D. 谁决定播「接任务对白」Prefab
- `AegirQuestStoryTrigger`（或等价）：按 `QuestState` 选 `Village_Aegir_QuestOffer` vs TurnIn
- 与 MultipleChoice 的分工：Trigger 选剧本；Choice 在剧本内分支
