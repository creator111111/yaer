# Cursor Agent Prompt · 对话结束后重复播放上一段最后一句语音（交互/转场/新演出）

> **角色**：【架构侦探】只读溯源；**禁止改代码 / Prefab / 音频资源 / Git 提交**  
> **日期**：2026-09-11  
> **现象（用户实测）**：  
> 1. **对话结束后**，再去做下列任一操作时，会 **重复播出上一段对白的最后一句语音**：  
>    - 与 **NPC** 交互  
>    - 与 **物体** 交互  
>    - **转场**  
>    - 播放 **新的演出/对白**  
> 2. 体感是「语音错位 / 串音」，像旧 VO 没停干净，或被再次触发  
> **产品期望（钉死）**：对白一结束（或切到下一剧情前），上一段人声 **必须停干净**；后续交互/转场/新演出 **不得**再播出上一段最后一句；新对白只播本句绑定的 Audio  
> **不是**：改台本文案；批量重导音频；改 BGM 混音曲线（除非根因在 SoundComponentGM 且证据指向）；不是改 Mask 小头像/大立绘案  
> **并行**：与 0911 立绘/头像案解耦——本案是 **对白 VO 生命周期 / 停播**  
> **报告落盘**：`Assets/Doc/执行文档/0911/对话结束重复最后一句语音_架构溯源报告.md`

把下面「侦探」整段复制给 Cursor Agent（Agent Mode）执行。施工 Prompt 见文末（根因拍板后再用）。

## 提示词助手预梳理（侦探须核实，勿当唯一真相）

### 产品白话

> 一段对话说完了，最后那句配音本该停。  
> 但你去点 NPC、捡东西、切场景、再开下一段戏时，**又冒出刚才最后那句人声**。  
> 要查：是没停掉、停错对象，还是别的系统又按了一次 Play。

### 复现矩阵（侦探须尽量钉 1～2 条最短路径）

| 前置 | 触发 | 是否复现（填） |
|------|------|----------------|
| 任意带 **最后一句有 Audio File** 的对白播完 | 再点附近 NPC 开新对白 | |
| 同上 | 与场景物体交互（门/箱子/提示等） | |
| 同上 | 转场（门/LoadScene） | |
| 同上 | 立刻 Trigger 下一段演出 | |
| 对照 | 最后一句 **无** Audio File 的对白后再交互 | 用于判断是否绑定 clip 残留 |

**优先用**：一句「有配音的收尾句」→ 立刻做交互/转场，听是否复读该句。

### 现网机制（助手预扫 · 高度可疑）

手册结论：对白节点 **Audio File** → 出字时播 VO（见 `Assets/Doc/策划手册/序章主角配音配置手册.md`）。

```
DialogueTMPUGUI 出字（有 audio）
  → 优先取 actor.transform 上的 AudioSource，否则用对话框 localSource
  → playSource.clip = audio; playSource.Play()
  → Wait(语音时长 or 按键) → Continue 下一句

对话树结束 OnDialogueFinished / OnDialoguePaused
  → playSource?.Stop()
  → （未见：清 clip、停「所有 Actor 上 AudioSource」、StoryComponentGSM.OnStoryEnd 内停声）
```

| 环节 | 预扫结果 | 若失败的体感 |
|------|----------|--------------|
| **播放挂点** | `DialogueTMPUGUI`：有 Actor 时 VO 打在 **Actor 的 AudioSource** 上，不是全局 SoundComponentGM | 对话 UI 关了，**场景里 Actor 源可能仍在响或仍挂着 clip** |
| **结束停声** | `OnDialogueFinished` / `Paused` 只 `playSource.Stop()` | 若 `playSource` 已换人/已空/未指到实际在播的源 → **停漏** |
| **Story 结束** | `StoryComponentGSM.OnStoryEnd`：清旗、广播 `onStoryEnd`、战斗立绘恢复；**未见停 VO** | 结束事件后交互仍可能碰到未停的源 |
| **下一段开场** | 同壳 `NormalDialogueNewPanel` 常复用 `GetUIForm` 再 `StartDialogue` | 若未统一 Stop 上一轮 Actor 源，新演出/交互时序下易「又响一句旧的」 |
| **交互/转场** | NPC/物体/`LoadScene` 可能 **SetActive**、Instantitate、或碰带 `AudioSource` 的物体 | Unity 常见：源上仍挂 **上一段 clip**，Enable/PlayOnAwake/其它脚本 `Play()` → **复读最后一句** |

### 假说表（须并列证伪）

| ID | 假说 | 证伪手段 |
|----|------|----------|
| **H1（首选）** | VO 播在 **Actor.AudioSource**；结束只 Stop 了 `playSource` 引用，**实际源未停或随后又 Play**；交互/转场 Activate 触发复读 | Hierarchy 对白结束瞬间看 Actor `AudioSource`：isPlaying、clip 名；交互瞬间是否变 isPlaying |
| **H2** | 结束路径 **没走到** `OnDialogueFinished`（异常结束、切场景拆树、Skip 分支）→ 从未 Stop | 打断方式对照：正常点完 vs ESC/黑幕强制结束 vs 转场中结束 |
| **H3** | `playSource` 在最后一句后被改写/置空，Stop 打空；**localSource 与 Actor 源不一致** | 日志记录每句 playSource 实例 ID；结束时 Stop 的是否同一 ID |
| **H4** | UniTask 出字协程在树结束后仍短暂存活，或重复 `Continue`/重入 `OnSubtitlesRequest` 再 Play 一次 | 结束前后是否二次进入出字；`[DialogueTMPUGUI]` 类日志 |
| **H5** | 交互提示音 / SFX / 转场音误用了同一 AudioSource 或同一 clip 引用 | 交互物体上 AudioSource.clip 是否等于上句 VO；SoundComponentGM 调用栈 |
| **H6** | 新演出 `StartDialogue` 未先 Stop 全局对白 VO，且旧 Story Prefab/Actor 未销毁仍持 clip | 新旧 `curStoryPrefab`、Actor 存活；StartDialogue 入口有无停声 |
| **H7** | BGM/混音闪避造成「像复读」（实为未停干净的尾音被推高） | 波形/静音 BGM 对照；是否完整一句而非尾噪 |

### 方案倾向（仅倾向，侦探可改口）

| 方案 | 做法 | 倾向 |
|------|------|------|
| **A** | 对白结束（Finished/Paused/StoryEnd/关壳）**统一停干净**：当前 playSource +（可选）本场 DialogueScene 内所有发言 Actor 的 AudioSource；并 `clip=null` 防 Activate 复播 | **首选方向**（若 H1/H2/H6） |
| **B** | VO 改为只打在对话框 `localSource`（或 SoundComponentGM 人声通道），不写 Actor 源 | 架构更干净，但改动面大；作备选 |
| **C** | 仅在交互/转场入口到处 Stop | 易漏、打补丁；**不推荐作终局** |
| **D** | 改音频资源 / 重导 | **禁止**当根因未证伪 |

### 侦探禁止事项

- 禁止改代码 / Prefab / `.wav`「先修再查」。  
- 禁止全局乱 `FindObjectsOfType<AudioSource>().Stop()` 当结论而不写清挂点。  
- 禁止借机改 BGM 系统设计或 Mask/立绘。  
- 禁止只测 DialogDebug 沙盒就结案——须至少一条 **真交互或真转场** 路径。

## 【架构侦探】执行段（复制给 Agent）

你是【架构侦探】。只读溯源，**禁止改代码**。

### 目标

查清：为何 **对白结束后**，在 NPC/物体交互、转场、新演出时会 **再次播出上一段最后一句语音**；定位播放挂点、应停未停点、以及「再次 Play」的触发源；给出最小修复建议（优先结束时统一停声，拒绝到处打补丁）。

### 必查清单

1. **播放调用链**  
   - 精读 `DialogueTMPUGUI`：出字播 VO、`playSource` 选择（Actor vs local）、句间是否 Stop、Finished/Paused 停声。  
   - 对照策划手册：Audio File 绑定方式。  
   - 写清：**最后一句的 clip 挂在哪个 GameObject 的哪个 AudioSource 上**。

2. **结束与销毁**  
   - `OnDialogueFinished` → `NormalDialogueFormNewLogic` / 树销毁 → `StoryComponentGSM.OnStoryEnd` 全链路：何处停声、何处未停。  
   - 强制转场/黑幕打断对白时，是否绕过 Finished。

3. **复现触发源**  
   - 对用户四类触发各查一条代表（NPC `SimpleStoryTrigger`/`Interactive`、物体交互、`LoadScene`、新 `TriggerStory`）：  
     - 是否 `SetActive`/Enable 带 VO clip 的源；  
     - 是否调用 `AudioSource.Play` / PlayOneShot / SoundComponentGM；  
     - 调用栈是否仍指向旧 clip 名。

4. **对照实验（写进报告）**  
   - 最后一句有 VO vs 无 VO；  
   - 正常点完 vs 中途转场；  
   - DialogDebug 只播完 vs 进村真机交互。  

5. **排除**  
   - 是否其实是打字机键音/提示音被误认（一句话证伪）。  
   - H7 混音错觉。

### 报告结构

1. 结论一句话（根因 + 主假说 ID）  
2. 证据链（脚本路径、方法、AudioSource 归属、clip 名、复现步骤）  
3. 假说表 H1～H7：成立 / 排除 / 待 Play  
4. 用户 1 分钟自查（结束瞬间看谁还在 isPlaying）  
5. 建议施工（统一停声挂点；禁止项）  
6. 剩余风险（多 Actor 同场、Skip、切场景销毁时序）  
7. 设计不清记 `OPEN_QUESTIONS.md`（VO 是否应禁止挂 Actor 源）  
8. 文末「可复制给施工员」5～10 条 bullet  

### 输出要求

- 中文；大白话；结论 → 原因 → 检查清单 →（可选）程序补充。  
- 报告：`Assets/Doc/执行文档/0911/对话结束重复最后一句语音_架构溯源报告.md`  
- 可引用：  
  - `Assets/Doc/策划手册/序章主角配音配置手册.md`  
  - `Assets/Scripts/Game/GameRuntime/NodeCanvas/NodeCanvasExtend/DialogueTMPUGUI.cs`  
  - `Assets/Scripts/Game/GameRuntime/GameSceneManager/Component/StoryComponentGSM.cs`  
  - 相关交互：`SimpleStoryTrigger`、门/LoadScene、各 SceneManager TriggerStory

## 【施工员】Prompt（根因拍板后再用 · 预稿）

> 仅当侦探确认停声缺口或复触发点后使用。

1. **优先 A**：在对白结束真源挂点（Finished/Paused + 必要时 `OnStoryEnd` / 关对话壳）**统一停止**本场对白 VO，并避免 Actor 源残留 clip 被再次 Play（按报告：Stop 和/或 `clip=null`）。  
2. 若 H1 成立：检查「只 Stop playSource」是否不够——应对 **实际播放过的 Actor 源** 做登记停声。  
3. **禁止**在每个 NPC/门上复制 Stop 补丁当终局；**禁止**未证伪就重导音频。  
4. 新 `StartDialogue` 开头可做一次防御性 Stop（若报告建议），但主修仍在结束路径。  
5. 施工说明：`Assets/Doc/施工说明/0911/对话结束停干净语音_施工说明.md`  
6. 验收：带 VO 收尾句的对白结束后 → NPC 交互 / 物体交互 / 转场 / 新演出 **均不再复读旧最后一句**；新对白首句 VO 正确；BGM 无异常切断。

## 给用户的一句话

> 很像对白把最后一句人声挂在角色身上的喇叭上，戏散了没关干净——你再点人、切场景或开下一段时，那句又被播了出来；先查结束时到底停的是哪一个 AudioSource。
