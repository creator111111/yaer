# Cursor Agent Prompt · 章节结束不要显示战斗立绘

> **角色**：【架构侦探】只读钉死「章末为何仍露战斗立绘」→ 【施工员】按证据最小改  
> **日期**：2026-09-24  
> **产品钉死**：章节结束流程中（大标题 / 黑幕开地图 / 滚动字幕 / 选关）**不得显示战斗立绘**（铠甲持剑大图，即 FightingPanel 的 `Illustration`）  
> **用户证据**：章末出地图时仍能看到战斗立绘叠在场景/UI 上  
> **场景**：序章/章末链 — `ChapterEndAction` → `ChapterEndPanel` → `MapPanel`（常见触发：离开龙宫/章末剧情 `ChapterEndStory_*`）  
> **不是**：关设置里「显示战斗立绘」全局默认；改战斗中正常显隐；删 `OnStoryEnd` 延迟机制交差（该延迟防闪，须保留，另加章末例外）；改章末字幕文案 / UnlockRoad  

**纪律**：Play 复现 + Console 过滤 `[ChapterEnd]` / 战斗立绘相关日志；禁止空口「关掉就行」无调用链。

## 提示词助手预梳理

### 产品白话

> 章节结束播大标题、开世界地图、滚字幕选关时，屏幕上**不要**再出现战斗用的大立绘。  
> 那是战斗 HUD 的 Illustration，不是章末美术。

### 现网高嫌疑链（侦探须核实）

| 环节 | 现网行为 | 章末风险 |
|------|----------|----------|
| 对白开始 | 常关战斗立绘 | OK |
| **`StoryComponentGSM.OnStoryEnd`** | 按设置 **延迟恢复** 战斗立绘（`UpdateBattleImageVisiable(…, fromStoryEndRestore: true)`） | 章末剧情一结束 → ~0.4s 后立绘又露出来，叠在章末/地图上 |
| `ChapterEndAction` | 只 `OpenUIForm(ChapterEndPanel)`，**未见**强制关 Illustration | 面板打开后 FightingPanel 可能仍在底层 |
| 村/林 GSM | 部分路径在未出门剧情时强制关立绘 | 章末若已 `homeDoorStoryComplete`，条件不挡恢复 |
| 图节点「战斗立绘显示控制」 | 可显可隐 | 章末 Prefab 是否漏关 / 误开 |

### 假说

| ID | 假说 |
|----|------|
| **H1** | 章末前一段 Story `OnStoryEnd` → 延迟恢复立绘；ChapterEnd 期间无人再关 → **主因候选** |
| **H2** | ChapterEndPanel / MapPanel sorting 低于 FightingPanel.Illustration，立绘「透」在上面 |
| **H3** | `ChapterEndStory_*` 图里节点把立绘设回 visible |
| **H4** | 章末打开时 FightingPanel 本身不该在场，却残留 Open |
| **H5** | 仅设置 `showBattleImage=true` 时出现；关设置则无 —— 仍须在「开设置」时章末不露 |
