# 项目记忆库

## 为什么这样设计？

### 玩家移动为什么用Rigidbody2D而不是Transform？
因为需要物理碰撞和重力，用Transform会穿透平台

### 为什么用状态机管理敌人？
因为敌人行为会变多（巡逻、追逐、攻击、受伤），状态机更容易扩展

### 为什么不用Unity自带动画事件？
因为动画事件不够精确，改用代码检测动画进度

## 踩过的坑
1. **问题**：跳跃时按下攻击会失去跳跃力
   **解决**：在攻击动画期间锁定跳跃输入
   
2. **问题**：敌人碰到玩家边缘会卡住
   **解决**：添加碰撞法线检测，根据碰撞方向决定是否反弹
